## 1. Kerkoporta: Injecting Structured-Output Backdoors in Reasoning Coding Agents  🆕

- **저자**: Georgios Syros, Blake Bullwinkel, Alina Oprea, Cristina Nita-Rotaru, Amanda Minnich et al.
- **키워드**: `backdoor`, `structured output`, `tool call`, `coding agent`, `SFT+RL`
- **출처**: arxiv recent
- **arxiv**: [2611.00138](https://arxiv.org/abs/2611.00138) (v1)
- **PDF**: [`./pdfs/2611.00138.pdf`](./pdfs/2611.00138.pdf)

**핵심 요약**:
기존 LLM 백도어는 채팅 출력에 국한되어 위험이 제한적이었지만, 에이전트는 명령을 직접 실행한다는 점에서 위협 모델이 달라진다. 저자들은 컨텍스트 어디에든 트리거가 있으면 공격자가 지정한 tool call을 내도록 하는 structured-output 백도어를 제안하고, 고품질 poison 샘플 구성 → SFT 주입 → 경량 RL로 유틸리티 복구하는 Kerkoporta 파이프라인을 설계했다. 최신 open-weight 추론 모델과 여러 하네스에서 최대 96.2% 공격 성공률을 달성했고, 하네스 일반화/단일 타깃 결박 모두 가능하다. 일부 모델은 클린 모델보다 유틸리티 벤치마크 성적이 높아 피해자가 채택할 유인까지 생긴다는 점이 특히 위협적이다.

## 2. J-Anchor: Defending Against Prefill Attacks via J-Space Selective Refusal Restoration  🆕

- **저자**: Running Yang, Beidi Zhao, Xiaoxiao Li
- **키워드**: `prefill attack`, `jailbreak`, `refusal`, `Jacobian lens`, `inference-time defense`
- **출처**: arxiv recent
- **arxiv**: [2611.01342](https://arxiv.org/abs/2611.01342) (v1)
- **PDF**: [`./pdfs/2611.01342.pdf`](./pdfs/2611.01342.pdf)

**핵심 요약**:
Prefill 탈옥은 공격자가 어시스턴트 응답의 앞부분을 채워 모델이 거절하지 못하게 만든다. 저자들은 Jacobian lens로 내부의 유해성/거절 신호를 추적해, prefill이 진행될수록 거절 신호만 benign 수준으로 떨어지고 유해성 신호는 남아 있는 'refusal-state erosion' 현상을 발견했다. 이를 바탕으로 공격 전 신호를 앵커로 삼아 J-space에서 약해진 거절만 선택적으로 복원하는 training-free 추론시점 방어 J-Anchor를 제안한다. 고정/딥 prefill 공격 모두에서 성공률을 크게 낮추며, 해석가능성 도구를 방어로 연결한 사례다.

**핵심 요약**:
툴 사용 에이전트는 도메인 정책이 금지한 행동을 실행하곤 한다. LeanGuard는 모든 tool call을 환경에 닿기 전에 Lean4로 작성한 정책(상태 술어 + 과거시제 시간 연산자)으로 검사하는 fail-closed 런타임이며, 결정 절차가 LeanLTL 의미론과 동치임을 증명한다. 거부된 호출은 피드백 또는 Lean 메타프로그래밍 기반 proof-guided repair로 수정한다. Tau-Bench에서 비가드 에이전트가 최소 33건의 금지 호출을 실행한 반면 LeanGuard는 0건이었고, DTap에서 직접 프롬프트 인젝션 성공률을 57.9%→5.9%로 낮췄다.

- **PDF**: [`./pdfs/2611.00606.pdf`](./pdfs/2611.00606.pdf)

**핵심 요약**:
TopK SAE의 attribution graph는 ablation 효과 예측과 시드 간 비교에 쓰이는데, 이 논문은 TopK 컷오프 경계에서 일어나는 feature 교차가 그래프 정확도를 좌우함을 보인다. Pythia 3개 모델의 SAE 5쌍에서 한 feature를 0으로 만들면 74% 이상의 경우 다음 층 feature가 컷오프를 넘나들고, 이 교차가 반응 에너지 대부분을 차지한다. 기존 활성 feature 기반 그래프는 상대 오차 중앙값이 0.247 이상인 반면, 1차 변화를 모든 preactivation에 더해 재랭킹하는 margin graph는 같은 비용으로 오차 0.033 이하를 달성한다. 시드 간 그래프 비교의 한계도 정량화했다(최대 모델 pythia-160m).

Circuit Oracle은 멀티에이전트 하네스와 전용 스킬을 갖춘 범용 LLM이 tool call로 그래프를 읽고 자연어 질문에 답하게 한다. 프로브 회로의 허위 feature 탐지에서 78.2±2.4% 정확도로 단일층 feature 랭킹 기준선을 앞섰으나, taboo 파인튜닝 모델의 비밀 추출에서는 Activation Oracle이 여전히 우세하고 거절 억제 탈옥에서도 결과가 엇갈린다. 해석가능성 자동화의 가능성과 한계를 솔직하게 보여주는 혼재된 결과다.

- **출처**: arxiv recent
- **arxiv**: [2610.41732](https://arxiv.org/abs/2610.41732) (v1)
- **PDF**: [`./pdfs/2610.41732.pdf`](./pdfs/2610.41732.pdf)

**핵심 요약**:
기존 LM 멤버십 추론 평가는 사후에 멤버/비멤버를 수집해 분포 이동이 성능에 섞인다. 저자들은 OLMo 2 1B의 50B 토큰 mid-training을 재실행하며 도메인·난이도가 매칭된 7,814쌍 중 동전던지기로 하나만 삽입하고, 같은 시드의 공식 모델을 반사실 기준으로 삼았다. 한 번의 노출은 우도를 평균적으로 높이지만 개별 문서 식별은 어렵다(reference ratio AUC 0.767이나 단일 임계값에서 FPR 1% 시 TPR 3.8%). 반면 매칭 13쌍이면 컬렉션 단위 학습 여부를 5% 유의수준에서 80% 검정력으로 탐지할 수 있어, 개별 문서가 아닌 컬렉션 수준 감사가 현실적임을 시사한다.

## 10. Probing Local Conditional Fit for Diffusion Model Membership Inference  🆕

- **저자**: ByungHee Cha, Naoki Murata, Yuhta Takida, Jong Chul Ye, Yuki Mitsufuji
- **키워드**: `membership inference`, `diffusion model`, `LoFIT`, `conditional prediction shift`, `auditing`
- **출처**: arxiv recent
- **arxiv**: [2611.02578](https://arxiv.org/abs/2611.02578) (v1)
- **PDF**: [`./pdfs/2611.02578.pdf`](./pdfs/2611.02578.pdf)

**핵심 요약**:
텍스트-이미지 확산 모델의 학습 데이터 사용 여부를 감사하는 멤버십 추론을 다룬다. 다른 텍스트 조건으로 바꿨을 때 예측 노이즈가 변하는 방향으로 움직이면 디노이징 손실이 낮아지는지가 신호이며, 멤버는 이런 국소적 개선 여지가 적다는 점을 발견했다. 이를 정량화한 LoFIT은 타깃 모델 gradient 없이 denoiser forward 쿼리만으로 여러 조건·확산 단계에 걸쳐 계산한다. 4개 데이터셋의 파인튜닝/사전학습 모델에서 판별력이 개선되었고, 파인튜닝 초기에는 단순 손실 기준이 우연 수준일 때도 멤버를 구분한다.
