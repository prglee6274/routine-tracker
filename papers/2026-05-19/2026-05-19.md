## 1. Model-Agnostic Lifelong LLM Safety via Externalized Attack-Defense Co-Evolution  🆕

- **저자**: Xiaozhe Zhang, Chaozhuo Li, Hui Liu, Shaocheng Yan, Bingyu Yan, et al.
- **키워드**: `red teaming`, `safety alignment`, `lifelong learning`, `attack-defense co-evolution`, `LLM guard`
- **출처**: arxiv recent (cs.CR) · 검색 화제 (LLM 안전 정렬 프레임워크 토픽)
- **arxiv**: [2605.13411](https://arxiv.org/abs/2605.13411) (v1, 2026-05-13)
- **PDF**: [`./pdfs/2605.13411.pdf`](./pdfs/2605.13411.pdf)

**핵심 요약**:
기존 LLM 안전 프레임워크가 red-teaming과 사후 학습(post-training)을 폐쇄적 정책 중심 루프로 묶어두는 탓에 새 공격 발견은 빨리 포화되고 방어는 모델별로 재학습이 필요하다는 한계를 지적. 저자들은 EvoSafety를 제안 — (1) 공격 정책에 "adversarial skill library"를 외부에 두어 라이브러리 확장만으로 새 취약점을 지속 발굴하고, (2) victim 모델을 직접 fine-tune하는 대신 memory retrieval로 보강된 경량 보조 방어 모델을 학습한다. 단일 학습으로 Steer 모드(피해 모델 내장 방어 활성화)와 Guard 모드(유해 입력 필터링) 둘 다 동작하며, Guard 모드에서 99.61% defense success rate(SOTA Qwen3Guard-8B 대비 +14.13%p, 파라미터는 37.5%만 사용)를 달성했다고 보고.

## 2. Why Do Aligned LLMs Remain Jailbreakable: Refusal-Escape Directions, Operator-Level Sources, and Safety-Utility Trade-off  🆕

- **저자**: Yu Chen, Yuanhao Liu, Qi Cao
- **키워드**: `jailbreak`, `mechanistic interpretability`, `refusal direction`, `operator-level decomposition`, `safety-utility trade-off`
- **출처**: arxiv recent (cs.CR) · 검색 화제 (mech-interp + safety 교차 토픽)
- **arxiv**: [2605.08878](https://arxiv.org/abs/2605.08878) (v1, 2026-05-09)
- **PDF**: [`./pdfs/2605.08878.pdf`](./pdfs/2605.08878.pdf)

**핵심 요약**:
"정렬된 LLM이 왜 여전히 jailbreak되는가"라는 구조적 원인을 연속 입력 변환 관점에서 분석. 핵심 개념인 RED(Refusal-Escape Direction) — 유해 입력 주변에서 모델 행동을 "거절→응답"으로 옮기지만 유해 의미 해석은 보존하는 국소 perturbation 방향 — 을 도입하고, RED를 모델 operator 구조(normalization, residual wiring, terminal layer 등) 단위로 정확히 분해한다. RED를 제거하려면 self-attention과 MLP가 이 analytically constrained 소스의 기여를 없애야 하는데 그러면 정상 응답 메커니즘까지 손상되므로, 안전성·유틸리티 trade-off가 구조적으로 발생함을 증명. 실험은 성공한 jailbreak가 주로 terminal-source 기여 방향으로 refusal→answer 전이를 일으킨다는 사실을 뒷받침한다.

## 3. Tool Calling is Linearly Readable and Steerable in Language Models  🆕

- **저자**: Zekun Wu, Ze Wang, Seonglae Cho, Yufei Yang, Adriano Koshiyama, Sahan Bulathwela, Maria Perez-Ortiz (UCL · Holistic AI · Imperial)
- **키워드**: `activation patching`, `linear probing`, `steering vector`, `agent safety`, `tool calling`
- **출처**: arxiv recent (cs.CL) · 검색 화제 (mechanistic interp / agent reliability)
- **arxiv**: [2605.07990](https://arxiv.org/abs/2605.07990) (v1, 2026-05-08)
- **PDF**: [`./pdfs/2605.07990.pdf`](./pdfs/2605.07990.pdf)

**핵심 요약**:
Gemma 3 / Qwen 3 / Qwen 2.5 / Llama 3.1 등 12개 instruction-tuned 모델(270M–27B)을 프로빙해, 에이전트가 "어떤 tool을 호출할지"라는 선택이 모델 내부에서 **선형적으로 읽히고 조향(steer) 가능**하다는 사실을 보인다. 두 tool의 평균 활성치 차이를 더하면 4B+ 모델에서 93–100% 정확도로 tool 선택을 뒤집을 수 있고, 뒤따르는 JSON arguments도 새 tool 스키마에 자동으로 맞춰진다. 또 top-1과 top-2 tool 사이 gap이 작은 쿼리는 잘못된 호출이 14–21배 더 많아, 동일한 per-tool mean이 사전 오류 감지에도 쓰일 수 있다. activation patching으로 인과적 효과는 중·후반 layer의 소수 attention head에 국한됨을 확인 — agent 안전성/감시 측면에서 매우 실용적인 mechanistic 발견.

## 8. ContextualJailbreak: Evolutionary Red-Teaming via Simulated Conversational Priming  🆕

- **저자**: (PDF 본문 참조)
- **키워드**: `multi-turn jailbreak`, `red-teaming`, `evolutionary search`, `contextual priming`, `black-box attack`
- **출처**: arxiv recent (cs.CR) · 검색 화제 (멀티턴 jailbreak)
- **arxiv**: [2605.02647](https://arxiv.org/abs/2605.02647) (v1)
- **PDF**: [`./pdfs/2605.02647.pdf`](./pdfs/2605.02647.pdf)

**핵심 요약**:
정렬된 LLM도 multi-turn 컨텍스트 priming(앞선 turn이 뒤 turn의 응답을 은밀히 편향시키는 방식) 앞에서는 무너진다는 점을 black-box red-teaming으로 체계화. ContextualJailbreak는 시뮬레이션된 다중턴 priming 대화 위에서 5개 의미적 mutation operator(roleplay / scenario / expand / troubleshooting / mechanistic)를 통한 진화 탐색을 수행해 single-turn manipulations보다 일관되게 더 높은 공격 성공률을 얻는다. 멀티턴 안전 평가 벤치마크가 더 필요하다는 주장을 뒷받침하는 작품.
