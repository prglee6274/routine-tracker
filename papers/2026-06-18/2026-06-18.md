## 1. RepSelect: Robust LLM Unlearning via Representation Selectivity  🆕

- **저자**: Sondej, Filip · Yang, Yushi · Mahdi, Adam
- **키워드**: `unlearning`, `representation engineering`, `robustness`, `fine-tuning attack`
- **출처**: HF Daily + arxiv recent (cs.CL)
- **arxiv**: [2606.17168](https://arxiv.org/abs/2606.17168) (v1)
- **PDF**: [`./pdfs/2606.17168.pdf`](./pdfs/2606.17168.pdf)

**핵심 요약**:
LLM이 특정 지식·가치관을 깊게 잊으면서도 일반 능력은 유지하는 unlearning은 여전히 난제다. 기존 기법은 fine-tuning이나 few-shot 프롬프트로 쉽게 되살아나 '얕은 망각'에 그치는데, 저자들은 그 원인을 retain set 및 공격자가 복원하는 부분공간과 공유되는 표현을 건드리기 때문이라 진단한다. RepSelect는 매 업데이트 전에 weight gradient의 상위 주성분을 제거해 forget-set 고유 표현만 분리·삭제하므로, 일반 능력을 보존하면서 fine-tuning으로 복원 가능한 범위를 제한한다. 생물학적 위험 지식·공격적 성향 두 범주와 Llama 3·Qwen 3.5·Gemma 4·DeepSeek V2 Lite 등 dense·MoE 4개 계열에서, 재학습 후 정답률 감소가 최강 베이스라인 대비 4~50배 크고 few-shot 공격에 거의 완벽히 강건했다.

## 2. A Red-Team Study of Anthropic Fable 5 & Opus 4.8 Models  🆕

- **저자**: Franco, Nicola
- **키워드**: `red-teaming`, `jailbreak`, `adversarial robustness`, `frontier LLM`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.18193](https://arxiv.org/abs/2606.18193) (v1)
- **PDF**: [`./pdfs/2606.18193.pdf`](./pdfs/2606.18193.pdf)

**핵심 요약**:
Anthropic의 프런티어 모델 Fable 5와 Opus 4.8을 10개 유해 카테고리·7,826개 유해 의도에 대해 4종 자동 jailbreak 공격으로 평가했다. HackAgent 프레임워크로 수십만 건의 공격을 생성하고, 성공으로 보이는 사례는 3개 심판 모델의 다수결로 재판정했다. 두 모델 모두 대부분의 공격을 막았으나 잔존 취약면은 적응형 반복 공격(tree-of-attacks)에 집중되어, Opus 4.8은 의도의 11.5%, Fable 5는 최악 6.1%에서 뚫렸다. 강화된 설정에서도 Opus 4.8 1,620건·Fable 5 702건의 심판 확인 유해 출력이 전 카테고리에서 나왔으며, 사람 전문가 없이 1~2회 정제만으로 저렴하게 발견됐다. 집계 성공률만 보고 안심해선 안 되며, 가장 잘 테스트된 프런티어 모델조차 지속적 자동 공격엔 안정적으로 뚫린다는 결론이다.

## 3. CheckMIABench: Firm Foundations For Membership Inference Attacks on Language Models  🆕

- **저자**: Wang, Jeffrey G. · Wang, Jason · Li, Marvin · Neel, Seth
- **키워드**: `membership inference`, `privacy benchmark`, `LLM evaluation`
- **출처**: arxiv recent (cs.LG)
- **arxiv**: [2606.17464](https://arxiv.org/abs/2606.17464) (v1)
- **PDF**: [`./pdfs/2606.17464.pdf`](./pdfs/2606.17464.pdf)

**핵심 요약**:
MIA(멤버십 추론)는 모델의 프라이버시 특성을 평가하는 대표 수단이지만, LLM 대상 평가에서는 member/non-member 집합 간 미묘한 분포 차이가 통계적 타당성을 훼손해 왔다(모델 접근 없는 'blind' 기법이 발표된 방법보다 더 잘 맞는 역설이 보고됨). 이 논문은 '학습 중 특정 시점 전후 데이터는 같은 분포에서 추출된다'는 통찰을 이용해 원칙적 MIA 벤치마크를 구성한다. 즉 중간 체크포인트와 공개 학습 데이터를 가진 오픈소스 모델은 모두 MIA 테스트베드로 변환 가능하다. Pythia·OLMo 계열(70M~7B)에 6종의 발표된 공격을 적용했고, 후속 프라이버시 연구를 위한 모듈식 라이브러리도 공개했다.

## 4. Loss Landscape Poisoning: Targeted Extraction of Unseen Training Data from LLMs  🆕

- **저자**: Mamun, Md Abdullah Al · Doan, Ngoc Phu · Zaree, Pedram · Alouani, Ihsen · Abu-Ghazaleh, Nael
- **키워드**: `training data extraction`, `data poisoning`, `differential privacy`, `memorization`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.17110](https://arxiv.org/abs/2606.17110) (v1)
- **PDF**: [`./pdfs/2606.17110.pdf`](./pdfs/2606.17110.pdf)

**핵심 요약**:
LLM이 의료·금융 기록, 비밀이 담긴 대화 등 민감 데이터로 학습되면서 추출 공격에 대한 프라이버시가 핵심 우려가 됐다. 저자들은 학습 데이터 일부를 오염시킬 수 있는 공격자가, 접근 권한 없는 별도의 타깃 레코드 유출을 유도할 수 있는지 묻고 가능함을 보인다. 핵심은 타깃 완성문 주변에 날카로운 손실 최소점을 만들고 인근 대안의 손실을 높여, 모델이 타깃을 유일한 저손실 해로 암기하게 만드는 poisoning이다. 구조 변경이 필요 없고 중앙·연합 학습 모두에 일반화되며, 언어 모델 최대 100%·비전-언어 모델 최대 90% 추출 성공을 보인다. DP 학습으로 막히지만, 손실 지형을 직접 탐침해 DP 방어마저 우회하는 새 공격도 함께 제시한다.

## 5. An Evaluation of Data Leakage Risks in Tool-Using LLM Agents in Realistic Scenarios  🆕

- **키워드**: `agent safety`, `data leakage`, `LLM agents`, `non-adversarial`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.17114](https://arxiv.org/abs/2606.17114) (v1)
- **PDF**: [`./pdfs/2606.17114.pdf`](./pdfs/2606.17114.pdf)

**핵심 요약**:
이메일·DB·문서에 접근하는 AI 에이전트가 확산되며 민감정보 유출 위험이 커졌으나, 기존 연구는 주로 prompt injection·jailbreak 같은 적대적 유출에 집중했다. 이 연구(싱가포르 AISI·한국 AISI 공동)는 적대적이지 않은 양성 요청에서도 유출이 생긴다는 점에 주목해, 고객지원·DevOps·웹 자동화·업무/개인 생산성 등 12개 현실 과제로 평가한다. 데이터 인지·청중 인지·정책 준수·데이터 최소화·접근 경계 인지 5개 위험 유형을 두 기관이 독립 환경에서 테스트했다. 3개 에이전트 모두 전 시나리오에서 완전히 정확하고 안전한 수행에 실패했고, 과제 성공이 불필요 정보 접근·부적절 수신자 노출 같은 데이터 처리 실패와 자주 동반돼 '능력'과 '데이터 처리 안전성'을 분리 평가해야 함을 보였다. 운영상 데이터 유출이 적대적 탈취와 구별되는 1차적 에이전트 안전 문제라는 결론이다.

## 6. TrustErase: Auditable Instant Machine Unlearning with Passport-Embedded Representations  🆕

- **저자**: Hendrix, Rutger · Russo, Leonardo G. · Spampinato, Concetto · Pennisi, Matteo · Bellitto, Giovanni
- **키워드**: `machine unlearning`, `auditable`, `data-free`, `privacy compliance`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.17122](https://arxiv.org/abs/2606.17122) (v1)
- **PDF**: [`./pdfs/2606.17122.pdf`](./pdfs/2606.17122.pdf)

**핵심 요약**:
프라이버시 규정 준수 수요로 machine unlearning 필요성이 커졌지만, 재학습·distillation 기반 기법은 검증 불가하고 계산 비용이 크다. TrustErase는 passport를 심은 표현을 활용한 검증 가능·데이터 불요(data-free) unlearning 프레임워크로, 즉각적·모듈식·감사 가능한 망각을 제공한다. passport를 파라미터 효율 적응 계층 내 암호 키처럼 다뤄, 재학습·fine-tuning·원본 데이터 접근 없이 단순 비활성화만으로 특정 클래스·데이터셋을 제거한다. 특이값 분해로 passport를 가중치에 숨겨 망각 동작이 투명하고 증명 가능하게 유지된다. MNIST·CIFAR10/100에서 DELETE·L2UL·Boundary Shrink 등 SOTA에 필적·상회하면서 엄격한 data-free 체제로 동작한다.

- **저자**: Dai, Yuyang · Dong, Yushun
- **키워드**: `model extraction`, `honeypot`, `API defense`, `LLM`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.15810](https://arxiv.org/abs/2606.15810) (v1)
- **PDF**: [`./pdfs/2606.15810.pdf`](./pdfs/2606.15810.pdf)

**핵심 요약**:
상용 API로 배포된 LLM은 모델 추출 공격에 취약하나 기존 방어는 너무 늦게 작동하거나 정상 사용자 효용을 떨어뜨린다. Knowledge Trap은 Honeypot Knowledge Graph(HKG)와 breadcrumb 유도 탐색으로 추출 공격을 전이성 낮은 지식 쪽으로 유인하는 방어다. 쿼리 차단·출력 교란 대신, 다운스트림 효용이 거의 없는 지식에 공격자의 제한된 쿼리 예산을 소진시키면서 양성 사용자 성능은 보존한다. 의료·금융 도메인 실험에서 대리(surrogate)모델 Agreement를 평균 6.2% 낮추면서도 정상 사용자 정확도는 떨어뜨리지 않아, 사용자 영향을 주는 기존 방어를 능가했다.

## 8. DoubtProbe: Black-Box Jailbreak Defense via Structural Verification and Semantic Auditing  🆕

- **저자**: Yin, Xuanyu · Jiang, Yilin · Zhou, Jun · Chen, Kai · Cao, Zhengfu · et al.
- **키워드**: `jailbreak defense`, `black-box`, `inference-time`, `structural verification`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.16527](https://arxiv.org/abs/2606.16527) (v1)
- **PDF**: [`./pdfs/2606.16527.pdf`](./pdfs/2606.16527.pdf)

**핵심 요약**:
LLM이 사용자 대면 시스템에 늘면서 black-box jailbreak 방어가 실무 문제가 됐다. 기존 방어는 알려진 공격 커버리지·프롬프트 의미 판단·런타임 제어에 의존해, 표현 재구성·구조 조작 앞에서 불안정해진다. 저자들은 다수 black-box jailbreak가 유해 목표를 없애지 않고 그것을 표현·실행하는 데 필요한 정보를 재조직할 뿐이라 관찰하고, 구조 검증과 의미 감사를 결합한 추론시 이중 분기 방어 DoubtProbe를 제안한다. 구조 분기는 요청을 구조화 표현으로 추출·재구성해 정보 보존 실패를 탐지하고, 의미 분기는 원 프롬프트를 직접 감사한다. Qwen2.5-72B에서 JBB 공격성공률 0.293→0.100, CodeAttack 0.152→0.001로 낮추면서 오탐률은 0.02 수준으로 유지했고, Llama-3.1-70B 전이에서도 패턴이 안정적이었다.

- **arxiv**: [2606.18062](https://arxiv.org/abs/2606.18062) (v1)

## 10. Contrastive-Difference CKA Reveals Concept-Specific Structural Alignment Across Language Model Architectures  🆕

- **저자**: Gao, Xueping
- **키워드**: `interpretability`, `representation analysis`, `CKA`, `cross-architecture`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2606.16897](https://arxiv.org/abs/2606.16897) (v1)
- **PDF**: [`./pdfs/2606.16897.pdf`](./pdfs/2606.16897.pdf)

**핵심 요약**:
서로 다른 LLM 아키텍처가 고수준 개념을 구조적으로 호환되게 부호화하는지 묻는다. 저자는 '기하-기능 보편성 분리(dissociation)'를 특성화하는데, 여러 개념 도메인·아키텍처 계열에서 중간 정도의 기하적 수렴과 거의 완벽한 기능적 전이가 공존한다. 샘플별 대조 차이에 커널 정렬을 계산하는 학습 불요 진단 CKA_Delta로 일반 유사성에서 개념 특화 수렴을 분리해, 표준 CKA가 못 하는 변별을 달성한다. 6개 개념 도메인 모두에서 재현됐고(5개 p≤0.017, safety는 수렴-기능 경향 p=0.08), code-vs-NL·reasoning-vs-recall 등 비지시 개념도 시스템 프롬프트 없이 검증했다. CKA_Delta를 절대 전이 정확도 예측기가 아닌 실용적 체제 분류기·아키텍처 이상치 탐지기(Gemma: d=1.08, AUC=0.79)로 자리매김한다.
