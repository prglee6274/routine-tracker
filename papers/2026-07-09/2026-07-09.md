## 1. Agent Data Injection Attacks are Realistic Threats to AI Agents  🆕

- **저자**: Woohyuk Choi, Juhee Kim, Taehyun Kang, Jihyeon Jeong, Luyi Xing et al.
- **키워드**: `prompt injection`, `indirect prompt injection`, `agent safety`, `data injection`, `LLM agent`
- **출처**: arxiv recent
- **arxiv**: [2607.05120](https://arxiv.org/abs/2607.05120) (v1)
- **PDF**: [`./pdfs/2607.05120.pdf`](./pdfs/2607.05120.pdf)

**핵심 요약**:
기존 AI 에이전트 보안 연구는 신뢰불가 데이터가 '지시'로 해석되는 명령어 주입(instruction injection)에 집중했고 방어도 그쪽에 맞춰졌다. 이 논문은 새로운 공격 범주인 에이전트 데이터 주입(ADI, agent data injection)을 제시한다 — 악성 데이터를 리소스 식별자·데이터 출처 같은 보안 임계 메타데이터나 도구 호출/응답 형식 같은 에이전트 컨텍스트 데이터로 위장해 주입하면, 에이전트가 이를 신뢰 데이터로 받아들여 공격자가 의도한 행동을 실행한다. ADI는 명령어 주입과 유사한 피해를 내면서도 기존 IPI 방어를 쉽게 우회한다. 저자들은 실제 상용 에이전트에서 취약점을 발견했다 — 웹 에이전트(Claude in Chrome, Antigravity, Nanobrowser)의 임의 클릭 공격, 코딩 에이전트(Claude Code, Codex, Gemini CLI)의 원격 코드 실행·공급망 공격. 근본 원인은 현행 에이전트가 신뢰/비신뢰 데이터를 격리하는 기본 보안 원칙을 지키지 않는다는 데 있다.

## 2. Controlling Tool Use with Heading-Specific Activation Steering  🆕

- **저자**: Yuqi Chen, Vincent Siu, Yang Liu, Dawn Song, Chenguang Wang
- **키워드**: `activation steering`, `steering vector`, `tool use`, `representation geometry`, `mechanistic interpretability`
- **출처**: arxiv recent
- **arxiv**: [2607.05790](https://arxiv.org/abs/2607.05790) (v1)
- **PDF**: [`./pdfs/2607.05790.pdf`](./pdfs/2607.05790.pdf)

**핵심 요약**:
도구 증강 LLM은 필요 없을 때도 도구를 호출하는 경향이 있다. 도구는 추론 시 컨텍스트에만 존재하고 모델 가중치에 인코딩되지 않으므로, 도구 사용 결정에 조작 가능한 안정적 내부 표현이 있는지는 자명하지 않다. 저자들은 heading-anchor 위치에서 추출한 steering vector가 5개 오픈소스 모델·3개 도메인에서 도구 호출을 양방향으로 인과 제어하며, 파라메트릭 추론만으로 충분한 도메인에서 불필요한 호출을 가장 잘 억제함을 보인다. 다만 기하 분석에서 이 인과적 효과는 깔끔한 선형 구조와 대응하지 않는다 — 도구 호출 단계는 억제 벡터와 일관된 음의 정렬 대신 분산·이중모드(bimodal) 정렬을 보이고, 도구 유형마다 겹침이 적은 별개의 내부 시그니처를 동원한다. 저자들은 이 기하적 불규칙성이 도구의 비파라메트릭 성격을 반영한다고 가설하며, 파라메트릭 개념의 steering vector와 구분된다고 본다.

## 3. Auditing of Unlearning Algorithms  🆕

- **저자**: Sahasrajit Sarmasarkar, Anastasia Koloskova, Sanmi Koyejo
- **키워드**: `machine unlearning`, `membership inference`, `auditing`, `differential privacy`, `epsilon lower bound`
- **출처**: arxiv recent
- **arxiv**: [2607.05898](https://arxiv.org/abs/2607.05898) (v1)
- **PDF**: [`./pdfs/2607.05898.pdf`](./pdfs/2607.05898.pdf)

**핵심 요약**:
언러닝 알고리즘이 학습 데이터의 영향을 정말로 제거하는지 평가하는 것은 여전히 미해결 과제다. 저자들은 멤버십 추론 공격(MIA)을 이용해 언러닝 파라미터 ε에 대한 데이터 의존적 하한(lower bound)을 계산하는 실용적 감사기(auditor)를 제안한다. 여러 알고리즘을 평가하니 뚜렷한 분리가 나타났다 — 모델 클리핑, rewind-to-delete처럼 엄밀한 보장을 갖는 방법은 매우 작은 ε 하한(자신의 언러닝 보장을 반증하지 않음)을 보인 반면, Hessian 기반 언러닝·상승-하강 교번·forget set 경사상승·retain set 파인튜닝 같은 경험적 방법은 큰 하한(부실한 언러닝)을 보였다. 이 감사기는 가설검정 틀로 언러닝 주장을 경험적으로 반증하는 도구이며, CIFAR-100과 Shakespeare 텍스트에서 검증했다.

## 4. Dithered Gaussian Mechanism for Randomness-Efficient Differential Privacy  🆕

- **저자**: Nikita P. Kalinin, Rasmus Pagh
- **키워드**: `differential privacy`, `Gaussian mechanism`, `floating-point vulnerability`, `randomness efficiency`, `DP-SGD`
- **출처**: arxiv recent
- **arxiv**: [2607.06320](https://arxiv.org/abs/2607.06320) (v1)
- **PDF**: [`./pdfs/2607.06320.pdf`](./pdfs/2607.06320.pdf)

**핵심 요약**:
저자들은 이산 가우시안 메커니즘의 대안으로 dithered 가우시안 메커니즘을 제안한다 — 잡음 분포 자체가 아니라 사적 출력을 이산화하는 방식이다. 이 이산화를 가우시안 메커니즘의 후처리로 해석함으로써 표준 가우시안의 프라이버시 보장을 그대로 상속하면서, 유한정밀도 부동소수점 출력이 유발하는 취약점을 회피한다. 또한 provably randomness-efficient 함을 보인다 — 이산화된 출력값을 직접 샘플링해 프라이버시에 필요한 고품질 난수 비트 수를 크게 줄이고 잡음 크기와 무관하게 만든다. 핵심은 난수원을 둘로 분리하는 것이다: 프라이버시 임계 샘플링에 쓰는 고품질 소스와, 적(adversary)에게 알려져도 되는 고성능 공개 소스(무작위 이산화용). 이 분리 덕에 암호학적으로 안전한 난수를 큰 성능 손실 없이 쓸 수 있다. DP-SGD 응용에서 부동소수점 취약점 노출을 줄인 안전한 잡음 생성을 적당한 오버헤드로 달성한다.

## 5. TILDE: TILt-based Distributional Erasure for Concept Unlearning  🆕

- **저자**: Naveen George, Naoki Murata, Yuhta Takida, Konda Reddy Mopuri, Yuki Mitsufuji
- **키워드**: `concept unlearning`, `diffusion models`, `distributional alignment`, `GFlowNet`, `representation`
- **출처**: arxiv recent
- **arxiv**: [2607.06432](https://arxiv.org/abs/2607.06432) (v1)
- **PDF**: [`./pdfs/2607.06432.pdf`](./pdfs/2607.06432.pdf)

**핵심 요약**:
텍스트-이미지 확산 모델의 개념 언러닝(concept unlearning)은 프라이버시·저작권·상표·안전 규제 대응에 필수지만, 대상 개념을 지우면서도 양성(benign) 생성의 품질·다양성·의미 커버리지를 보존해야 한다. 기존 소거 목적함수는 언러닝 후 어떤 분포를 목표로 삼아야 하는지 명시하지 않아 보존이 업데이트 규칙의 암묵적 부산물에 그친다. TILDE는 언러닝을 분포 정렬 문제로 정식화한다 — 망각 제약 하에서 사전학습 모델로부터 최소 편차(minimum-deviation)를 갖는 조건분포를 목표로 하는, energy-tilted·anchor-free 타깃을 설정한다. 이 타깃은 개념을 표현하는 이미지를 억제하되 각 프롬프트의 양성 상대질량은 보존한다. 이를 residual ∇-GFlowNet 학습으로 구현해 forget 에너지가 사전학습 확산 모델 대비 유도하는 score 보정을 학습하며, 객체·화풍·캐릭터 전반에서 강한 망각과 동시에 기존 베이스라인보다 향상된 보존·분포 충실도를 달성한다.

## 6. DT-Guard: Intent-Driven Reasoning-Active Training for Reasoning-Free LLM Safety Guardrail  🆕

- **저자**: He Liu, Changtao Miao, Xinjie Yang, Tianle Song, Yin Wu et al.
- **키워드**: `safety guardrail`, `content moderation`, `LLM safety`, `reasoning distillation`, `defense mechanism`
- **출처**: arxiv recent
- **arxiv**: [2607.06326](https://arxiv.org/abs/2607.06326) (v1)
- **PDF**: [`./pdfs/2607.06326.pdf`](./pdfs/2607.06326.pdf)

**핵심 요약**:
개방형 응용에 배포되는 LLM은 복잡한 위험에 견고하면서도 저지연 실시간 모더레이션이 가능한 안전 가드레일이 필요하다. 기존 가드레일은 경량 분류 모델(효율적이나 은폐된 의도·모호한 의미·경계 판정에 약함)과 추론 기반 가드(판단은 좋으나 토큰 생성·추론 지연이 큼) 사이의 트레이드오프에 갇혀 있다. DT-Guard는 '학습 시 추론 활성화, 추론 시 추론 없음'(Reasoning-Active Training, Reasoning-Free Inference) 패러다임을 쓴다 — 학습 때는 추론 감독을 주되 추론 시에는 구조화된 안전 라벨만 출력한다. 안전 판정을 의도→범주→안전(Intent-Category-Safety)의 점진적 결정 과정으로 정식화하고, 의도·위험범주·안전라벨·구조화 추론 궤적을 담은 데이터셋을 구성한다. hard-case 견고성을 위해 RG-PHO(멀티 롤아웃 일관성으로 숙달/실패/불안정 샘플을 구분해 표적 SFT·선호최적화)를 제안한다. 결과적으로 4B 백본만으로 prompt/response 양측 평균 F1 0.878을 달성해 8B 가드 베이스라인을 능가하며, 추론 감독을 저지연 판별에 내재화할 수 있음을 보인다.

## 7. Doomed from the Start: Early Abort of LLM Agent Episodes via a Recall-Controlled Probe Cascade  🆕

- **저자**: Kai Ruan, Zihe Huang, Ziqi Zhou, Qianshan Wei, Xuan Wang et al.
- **키워드**: `probing`, `hidden activations`, `LLM agent`, `failure prediction`, `inference efficiency`
- **출처**: arxiv recent
- **arxiv**: [2607.06503](https://arxiv.org/abs/2607.06503) (v1)
- **PDF**: [`./pdfs/2607.06503.pdf`](./pdfs/2607.06503.pdf)

**핵심 요약**:
멀티스텝 과제를 푸는 LLM 에이전트는 실패가 예정된 궤적에 조기 커밋하고도 실패가 관측되기 전까지 상당한 추론 연산을 소모한다. 저자들은 에이전트의 내부 표현으로부터 실패를 조기에 예측할 수 있음을 보인다 — 은닉 활성값에 대한 경량 라운드별 프로브가 첫 상호작용 라운드부터 최종 에피소드 실패를 예측하는 반면, 관측 가능한 행동만 읽는 스코어러는 우연 수준을 겨우 넘는다. 이 신호를 실용적 abort cascade로 전환한다 — 라운드마다 분포 무관 보정 게이트를 하나씩 두되, 결국 성공할 에피소드가 모든 게이트를 사용자 지정 전역 확률로 통과하도록 라운드별 recall 예산을 공동 탐색한다(오abort 위험이 게이트를 거치며 누적되므로 에피소드 수준 보장이 배포에서 중요). TextCraft의 두 에이전트 모델에서 90~97% recall 목표를 모두 충족하고, 90% 목표에서 추론 연산을 47.1%±10.3%(Qwen-2.5-7B)·37.2%±8.8%(Llama-3.2-3B) 절감(최적 단일 게이트의 1.6~1.7배). 행동만 읽는 동일 cascade는 절반 정도만 절약하고, 프로브에 행동 특징을 더해도 이득이 없다 — 은닉 상태가 행동이 드러내는 정보를 이미 포착함을 뜻한다.

## 8. Two Sides of the Same Coin: Learning the Backdoor to Remove the Backdoor  🆕

- **저자**: Qi Zhao, Christian Wressnegger
- **키워드**: `backdoor defense`, `data poisoning`, `anti-backdoor learning`, `reference model`
- **출처**: arxiv recent
- **arxiv**: [2607.05748](https://arxiv.org/abs/2607.05748) (v1)
- **PDF**: [`./pdfs/2607.05748.pdf`](./pdfs/2607.05748.pdf)

**핵심 요약**:
데이터 포이즈닝으로 심어진 신경망 백도어를 학습 단계에서 제거하는 방어법들은, 모델이 독성 샘플을 양성 샘플보다 쉽게 학습한다는 관찰에 기대 학습손실 임계값으로 분리하거나 양성 샘플 식별용 참조 모델(오라클)을 반복 학습한다. 특히 후자가 anti-backdoor learning에 효과적이었다. 저자들의 방법 HARVEY는 유사하지만 결정적으로 다른 접근을 쓴다 — 양성이 아니라 '독성' 샘플을 학습하는 오라클을 만든다. 백도어가 심긴 참조 모델을 학습하는 것이 양성 데이터로 참조 모델을 학습하는 것보다 훨씬 쉽기 때문에, 기존 방법이 양성 샘플을 식별하는 것보다 독성 샘플을 훨씬 정확히 식별할 수 있다. 이 차이가 near-perfect 백도어 제거를 가능케 해, 자연 정확도 손실을 거의 없이 하면서 공격 성공률을 최소로 낮추고, 공격 유형·데이터셋·아키텍처 전반에서 관련 연구를 크게 앞선다.

## 9. Differentially Private Natural Gradient Descent  🆕

- **저자**: Pan Li, Kai Chen, Shuai Chang, Shengzhi Zhang, Peizhuo Lv et al.
- **키워드**: `differential privacy`, `DP-SGD`, `natural gradient`, `second-order optimization`, `privacy-utility tradeoff`
- **출처**: arxiv recent
- **arxiv**: [2607.05866](https://arxiv.org/abs/2607.05866) (v1)
- **PDF**: [`./pdfs/2607.05866.pdf`](./pdfs/2607.05866.pdf)

**핵심 요약**:
고정된 프라이버시 예산에서 DP 학습의 효용은 결국 최적화 효율이 좌우한다. DP-SGD 같은 표준 1차 옵티마이저는 국소 그래디언트에만 의존하고 손실 곡률을 무시해, ill-conditioned 지형에서 심한 지그재그를 일으키며 예산을 비효율적 반복에 낭비한다. 자연 경사하강(NGD)은 곡률로 그래디언트를 전처리해 업데이트를 손실 기하에 정렬, 잡음 섞인 매 스텝에서 더 효율적 신호를 뽑아 프라이버시-효용 병목을 깰 원리적 경로를 제공한다. 그러나 NGD를 DP와 직접 결합하면 근본적 난제가 생긴다 — 곡률 추정 자체가 막대한 예산을 소모하고, 등방(isotropic) DP 연산이 NGD의 비등방 스케일링과 충돌하며, 역곡률이 평탄 방향의 업데이트를 폭증시켜 학습을 불안정화한다. DP-NGD는 곡률 추정을 사적 데이터에서 분리하고, whitened-space 메커니즘으로 등방 DP 제약과 비등방 2차 최적화를 조화시키며, 곡률을 동적으로 클램핑해 안정화함으로써 이를 체계적으로 해결한다. 표준 벤치마크 실험에서 1차 베이스라인의 효용 한계를 넘어 SOTA 정확도와 동일 예산 대비 최대 10배 수렴 가속을 달성한다.

## 10. Prompt Robustness Is Task-Dependent: Comparing Objective and Belief-Style Questions in LLM Evaluation  🆕

- **저자**: Sadia Kamal, Arefa Patwary, Anthony Marchiafava, Atriya Sen, Sagnik Ray Choudhury
- **키워드**: `prompt robustness`, `LLM evaluation`, `adversarial robustness`, `value probing`, `safety eval`
- **출처**: arxiv recent
- **arxiv**: [2607.05554](https://arxiv.org/abs/2607.05554) (v1)
- **PDF**: [`./pdfs/2607.05554.pdf`](./pdfs/2607.05554.pdf)

**핵심 요약**:
설문형 LLM 평가는 프롬프트에 대한 응답을 모델의 가치·신념 척도로 간주하는데, 응답을 정치적 가치·사회적 태도·신념의 증거로 읽을 때 이 가정은 특히 취약하다. 저자들은 프롬프트 견고성이 정답이 정해진 객관식 질문과 의견·가치를 묻는 주관식 질문 사이에서 다른지 묻는다. 4개 instruction-tuned 모델 계열을 3개 객관 데이터셋(MMLU·ARC·CulturalBench)과 3개 주관 데이터셋(Political Compass Test·ValueBench·World Values Survey)에서 평가하고, 각 질문/진술에 표현·프레이밍·형식 변형을 가해 변형 간 응답 일관성을 측정했다. 이항 GEE(일반화 추정방정식) 분석 결과 모델·데이터셋·프롬프트 범주와 그 상호작용이 모두 유의했으며, 특히 데이터셋 유형×프롬프트 범주 상호작용이 컸다. 즉 프롬프트 견고성은 질문 유형, 프롬프트 변형 방식, 모델에 따라 달라진다 — 가치·신념 평가를 단일 프롬프트로 읽는 관행에 경종을 울린다.
