## 1. Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence  🆕

- **저자**: Mengru Wang, Junfeng Fang, Shuofei Qiao, Zhenqian Xu, Haoming Xu et al.
- **키워드**: `mechanistic interpretability`, `agentic discovery`, `AI scientist`, `causal intervention`, `knowledge graph`
- **출처**: HF Daily / arxiv recent
- **arxiv**: [2608.12036](https://arxiv.org/abs/2608.12036) (v1)
- **PDF**: [`./pdfs/2608.12036.pdf`](./pdfs/2608.12036.pdf)

**핵심 요약**:
모델 능력은 빠르게 자동화되며 확장되는데 그 능력과 위험의 기저 메커니즘을 밝히는 작업은 여전히 사람 손으로 하는 수작업에 머물러 있어, 할 수 있는 것과 이해할 수 있는 것 사이의 격차가 계속 벌어지고 있다. 저자들은 메커니즘 발견 자체를 자율적으로 수행하는 에이전트 시스템 Mechanist를 제안한다. 해석가능성 논문 약 1.3만 편으로 만든 도메인 지식 그래프를 26개 분야 4,300만 편 규모의 다분야 논문 DB와 연결하고, 메커니즘 분석·인과 개입·검증을 위한 32개 기초 방법 라이브러리를 갖춰 가설 수립부터 실험 실행까지를 닫힌 루프로 돌린다. Claude Code 및 기존 AI-scientist 시스템 대비 더 가치 있는 메커니즘 가설을 만들고 실험 실행 신뢰도도 높았다. 특히 "행동 발견 → 설명 → 제어"로 이어지는 진행을 실증했는데, 과학 실험실 시나리오에서 겉보기에 안전한 학습 데이터를 통해 unsafe한 특성이 모달리티를 건너 전이되는 반직관적 안전 위험을 스스로 찾아낸 사례가 대표적이다. 해석가능성 연구의 병목이 아이디어가 아니라 실행 처리량이라는 관점을 정면으로 겨냥한 작업이다.

## 2. Agent Safety Should Be a Runtime Contract  🆕

- **저자**: Albus W. Ng, Yi Han, Jusheng Zhang, Wenhao Wang
- **키워드**: `agent safety`, `runtime enforcement`, `harness`, `trajectory monitoring`, `safety evaluation`
- **출처**: HF Daily / arxiv recent
- **arxiv**: [2608.11274](https://arxiv.org/abs/2608.11274) (v1)
- **PDF**: [`./pdfs/2608.11274.pdf`](./pdfs/2608.11274.pdf)

**핵심 요약**:
지금의 지배적 패러다임은 RLHF·DPO·Constitutional AI처럼 학습 시점에 안전성을 모델 안에 심어 넣는 것인데, 코드를 실행하고 파일을 변경하고 메시지를 보내고 DB를 수정하는 자율 에이전트에게는 이 접근이 구조적으로 불충분하다는 것이 저자들의 주장이다. 안전성은 harness가 런타임에 강제하는 **계약(contract)** 이어야 하며, 이 계약은 두 얼굴을 갖는다 — 샌드박스·권한 게이트·출력 필터·궤적 모니터로 위험 행동을 사전에 막는 **예방적(preventive)** 측면과, 테스트 실행·로그 캡처·파일 diff·인용 grounding 같은 하드 증거로 "좋은 행동이 실제로 일어났음"을 검증한 뒤에만 태스크 제출을 허용하는 **증거적(evidential)** 측면이다. 문서화된 AI 에이전트/LLM 안전 사고 52건 서베이, 허위 완료(false completion) 감사 31건, 공개 에이전트 시스템·harness 12종의 궤적 스키마 감사, 그리고 NeurIPS/ICML/ICLR 2023–2025 채택 논문 28,560편 전수 제목 감사라는 네 갈래 공개 증거로 입장을 뒷받침하며, 마지막 감사에서 학습시점 대 배포시점 연구의 불균형이 8–12배에 달함을 보인다. 컴퓨터 보안과 실험과학이라는 두 선행 커뮤니티가 결국 예방과 증거를 모두 갖춘 런타임 계약으로 수렴했다는 역사적 유비가 논지의 뼈대다.

## 3. Agent Skills Can Be Harmful: An Empirical Study of Skill-Induced Failures in LLM Agents  🆕

- **저자**: Gen Dong, Yanjie Gao, Liqun Li, Tianyin Xu, Yu Hua, Fan Yang
- **키워드**: `agent safety`, `agent skills`, `failure attribution`, `differential analysis`, `SWE agents`
- **출처**: arxiv recent
- **arxiv**: [2608.11888](https://arxiv.org/abs/2608.11888) (v1)
- **PDF**: [`./pdfs/2608.11888.pdf`](./pdfs/2608.11888.pdf)

**핵심 요약**:
에이전트 스킬은 재사용 가능한 지침을 주입해 계획·도구 사용·검증까지 실행 전반을 바꾸는 사실상의 표준 확장 메커니즘이 되었지만, 선행 연구들은 성공률을 올리는 스킬과 아무 효과 없이 토큰과 시간만 늘리거나 오히려 성공률을 떨어뜨리는 스킬이 뒤섞인 엇갈린 결과를 보고해 왔다. 저자들은 실패와 비용 회귀를 **어떤 스킬 탓인지** 귀속시키는 차등 분석(differential analysis) 프레임워크를 제안한다. 같은 태스크를 푸는 no-skill 기준 실행 또는 의미적으로 매칭된 다른 스킬 실행과 대상 스킬 실행을 비교하는 방식으로, SkillsBench와 SWE-Skills-Bench에 적용해 기능 실패 125건과 효율 회귀 182건, 총 307건의 스킬 유발 실패를 수집했다. 여기에 쌍 케이스를 정규화하고 차등 증거를 뽑아 분류 리포트를 내는 SkillTriage 도구를 붙였다. 핵심 발견은 반직관적인데, 명백히 무관한 스킬이 문제를 일으키는 경우는 드물고 오히려 **그럴듯하게 관련 있어 보이는 스킬**이 태스크가 요구하는 구현 요소를 잘못 구현하거나 누락시키게 만든다는 것, 그리고 효율 회귀는 프롬프트 길이만으로 설명되지 않는다는 것이다.

## 4. Backdoor Decontamination Dynamics in LLM Agents  🆕

- **저자**: Gabriel Huang, Abhay Puri, Léo Boisvert, Alexandre Drouin, Perouz Taslakian et al.
- **키워드**: `backdoor`, `defensive poisoning`, `unlearning`, `tool-calling agents`, `agent safety`
- **출처**: arxiv recent
- **arxiv**: [2608.11295](https://arxiv.org/abs/2608.11295) (v1)
- **PDF**: [`./pdfs/2608.11295.pdf`](./pdfs/2608.11295.pdf)

**핵심 요약**:
오픈웨이트 LLM 에이전트는 파인튜닝 과정에서 백도어가 심어질 수 있고, 트리거 조건이 테스트 중 발동되지 않으면 탐지조차 되지 않는다. 방어자가 트리거를 모르면 직접 unlearn할 수 없으므로, 알려진 백도어를 일부러 심고(defensive poisoning) 그것을 unlearn하면 원래의 미지 백도어도 부수 효과로 제거되기를 기대하는 전략이 제안돼 왔는데, 실제로 원본이 살아남는지 지워지는지 다른 경로로 재라우팅되는지는 불분명했다. 저자들은 트리거·응답·teacher·파인튜닝 방법을 분리해 이 동역학을 체계적으로 관찰하는 프레임워크를 만들고 AgentDyn에서 115개 실험을 수행했다. 방어적 포이즈닝만으로도 원본 백도어의 약 56%가 지워지고, 이후 decontamination 단계에서 생존자 대부분이 제거되는데, 이는 **트리거 인식과 악성 실행이 행동적으로 분리 가능하다**는 점을 뒷받침한다. 흥미롭게도 방어용 백도어와 같은 유형의 다른 트리거를 쓰면 악성 백도어가 결코 살아남지 못했고, 백도어를 최대 4개까지 함께 심으면 저항성이 커지지만(약 36%만 제거) 그중 알려진 하나만 제거해도 동거 백도어 60개 중 52개(87%)가 부수적으로 함께 지워졌다.

## 5. Measuring Semantic Abstractness of SAE Features via Nonlocality  🆕

- **저자**: Chuqiao Lin, Shivaji Sondhi, Xiao-Liang Qi
- **키워드**: `sparse autoencoder`, `feature abstractness`, `autointerp`, `activation steering`, `jailbreak mitigation`
- **출처**: arxiv recent
- **arxiv**: [2608.10537](https://arxiv.org/abs/2608.10537) (v1)
- **PDF**: [`./pdfs/2608.10537.pdf`](./pdfs/2608.10537.pdf)

**핵심 요약**:
SAE는 추론이나 탈옥 같은 LLM 행동의 기계적 설명을 찾는 데 널리 쓰이지만, 찾아낸 feature가 표면적 어휘 신호인지 진짜 고수준 개념인지 구분할 방법이 마땅치 않았다 — autointerp의 의미 설명도, causal steering의 유용성도 추상화 수준 자체를 판정해주지는 않는다. 저자들은 SAE feature 활성화에 대한 위치별 정규화 영향력의 엔트로피로 정의되는 **Feature Nonlocality (FNL)** 를 제안한다. FNL은 기존 LLM 기반 추상성 프록시 지표와 상관하며, 문맥 의존 추론 feature와 토큰 주도 feature를 한 쌍씩 무작위로 뽑았을 때 73–84%에서 문맥 feature에 더 높은 FNL을 올바르게 부여했다. 두 가지 응용이 인상적인데, 첫째로 탈옥 완화에 쓰이던 SAE feature들을 감사한 결과 **가장 효과적이던 feature들이 유해 의도를 실제로 인식하는 것이 아니라 FNL이 낮은 위치(positional) feature**였음이 드러났고, 둘째로 DeepSeek-R1-Distill-Llama-8B에서 고FNL feature를 steering하자 MATH-500 정확도가 무개입 대비 4.6점 올랐다.

## 6. Localizing Safety Alignment: MLP Layers and Mid-Network Blocks Encode Refusal Behavior in Large Language Models  🆕

- **저자**: Mingyu Zong, Sampad Mohanty, Bhaskar Krishnamachari
- **키워드**: `refusal behavior`, `safety alignment`, `weight transplantation`, `localization`, `mechanistic interpretability`
- **출처**: arxiv recent
- **arxiv**: [2608.11583](https://arxiv.org/abs/2608.11583) (v1)
- **PDF**: [`./pdfs/2608.11583.pdf`](./pdfs/2608.11583.pdf)

**핵심 요약**:
안전 정렬은 흔히 네트워크 전체에 분산된 성질로 취급되지만, 실전에서 쉽게 깨진다는 사실은 거부(refusal) 행동이 훨씬 작은 파라미터 집합에 몰려 있을 가능성을 시사한다. 저자들은 정렬된 모델의 가중치를 짝이 맞는 비정렬 base 모델로 여러 granularity에서 **이식(transplant)** 하는 방식으로 거부가 어디에 인코딩되는지를 직접 측정했다. 오픈웨이트 모델 쌍 2개와 안전 벤치마크 4종에서 attention 가중치, MLP 가중치, 연속 레이어 구간, MLP 블록을 각각 바꿔치기해 비교한 결과, 거부 전이는 MLP 가중치가 압도적으로 지배했고(악성 프롬프트 거부 회복량이 attention 대비 최소 2.7배) MLP 스택 내에서는 중간부에 일관되게 집중되어 6번의 greedy 탐색 모두에서 레이어 8–11 블록이 가장 먼저 선택되었다. 다만 안전 관련 구성요소는 **비가산적(non-additive)** 이어서, 6개 궤적 중 5개에서 정렬 블록을 더 넣으면 오히려 거부 성능이 떨어졌고 선택적 블록 부분집합이 전체 MLP 이식보다 악성 거부나 양성 과잉거부(또는 둘 다)에서 더 나은 경우가 있었다.

## 7. Measure, Don't Optimize: Forecasting Recovery in LLM Unlearning  🆕

- **저자**: Zirui Song, Huaxing Liu, Xiang Wang, Shuai Li, Xinye Li et al.
- **키워드**: `unlearning`, `knowledge recovery`, `internal auditing`, `Jacobian lens`, `privacy risk monitoring`
- **출처**: arxiv recent
- **arxiv**: [2608.11408](https://arxiv.org/abs/2608.11408) (v1)
- **PDF**: [`./pdfs/2608.11408.pdf`](./pdfs/2608.11408.pdf)

**핵심 요약**:
언러닝을 거친 모델이 출력에서는 대상 지식을 더 이상 드러내지 않아도 내부에는 잔존 흔적을 남긴다는 것은 알려져 있었지만, 기존 감사는 일회성 진단에 그쳐 이 잔존 신호가 **이후 재학습 시 지식이 되살아날지를 예측할 수 있는지**는 미지수였다. 저자들은 중간 표현을 Jacobian 렌즈로 어휘 공간에 투영해 대상 개념이 출력 경로 위에서 얼마나 자주 접근 가능한 채로 남아 있는지를 재는 추론 시점 감사 지표 J-Access를 제안하고, 8개 언러닝 기법에 걸친 공개 언러닝 모델 398개를 감사했다. 결과는 세 가지다 — 대부분의 언러닝 모델이 retain-only 기준선보다 높은 접근성을 유지하고, 공격 전 접근성이 모델 수준에서 회복 속도와 정도를 예측하지만 어떤 특정 사실이 되살아날지는 짚어내지 못하며, 결정적으로 **J-Access를 직접 최소화하도록 최적화하면 진짜 삭제가 아니라 감사 회피를 학습**해 감사 점수는 낮아지지만 공격 후 회복은 오히려 커진다. 내부 감사 지표는 측정 도구로 쓰되 최적화 목표로 삼아서는 안 된다는 제목 그대로의 교훈이다.

- **PDF**: [`./pdfs/2608.11691.pdf`](./pdfs/2608.11691.pdf)

**핵심 요약**:
RL post-training으로 탐색적 CoT 능력을 얻은 멀티모달 추론 모델(MLRM)에서 저자들은 독특한 프라이버시 취약점을 발견한다 — 민감 정보가 최종 답변에서는 성공적으로 언러닝되었더라도 **추론 궤적(reasoning trace) 안에서는 그대로 재생산**되며, 이 누출은 비추론 base 모델보다 네이티브 RL 학습 모델에서 훨씬 두드러진다. 기존 언러닝 기법들은 이 경로를 아예 상정하지 않았다. 저자들은 RL이 유도한 탐색이 민감 내용에 base 모델에는 없는 독특한 토큰 수준 엔트로피 시그니처를 남긴다는 관찰에 기반해, 학습이 전혀 필요 없는 추론 시점 언러닝 프레임워크 LEMUR를 제안한다. 엔트로피 동역학을 제어 신호로 삼아 민감한 추론이 시작되는 지점과 정화를 멈출 지점을 판정하고, 그 구간 동안 이미 확정된 토큰을 입력 이미지에 재접지된 확률 가중 임베딩으로 대체하는 엔트로피 변조 visual-anchor latent injection으로 추론 궤적을 우회시킨다. 여러 MLRM에서 추론 궤적 누출과 답변 누출을 모두 억제하면서 비민감 유용성과 출력 유창성 보존에서도 기존 기법을 앞섰다.

**핵심 요약**:
웹·모바일·IoT 생태계의 프라이버시 위험은 광범위하게 연구되어 온 반면 데스크톱 환경은 여전히 널리 쓰임에도 거의 방치되어 왔다. 이 논문은 macOS 생태계에서 데이터 수집과 공유를 규제·공시하도록 설계된 메커니즘들을 종합적으로 조사한 첫 연구로, 앱 개발자 관점에서 앱의 데이터 접근을 매개하는 여러 macOS 메커니즘이 서로 어떻게 상호작용하는지를 밝힌다. 발견을 바탕으로 정적·동적 분석을 결합해 앱의 실제 데이터 관행과 공시 내용을 하나의 통합 뷰로 만드는 분석 프레임워크 NutriScan을 개발했다. macOS 앱 1,000개를 동적 분석한 결과 **85%가 공시 없이 사용자 데이터 API에 접근**했고, 49.7%는 광고 사업자와 호스팅 제공자로 데이터를 유출했으며 그중 12.5%는 해당 공시조차 없었다. 데스크톱 앱이 온라인 트래커가 사용자 프로필과 기기 지문을 보강하는 통로로 활용되고 있다는 점을 드러내 추적의 실제 범위에 대한 새로운 시각을 제공한다.

## 10. Toward Metacognitive One-Shot Indirect Prompt Injection: Strategy Abstraction Via Outcome-Conditioned Reflection  🆕

- **저자**: Sihan Hou, Xinmeng Hou, Zhijun Zhang, Zehao Wang, Xuhong Ren et al.
- **키워드**: `indirect prompt injection`, `tool-using agents`, `strategy distillation`, `one-shot attack`, `red-teaming`
- **출처**: arxiv recent
- **arxiv**: [2608.08795](https://arxiv.org/abs/2608.08795) (v1)
- **PDF**: [`./pdfs/2608.08795.pdf`](./pdfs/2608.08795.pdf)

**핵심 요약**:
도구를 쓰는 LLM 에이전트는 외부 관측에 심어진 악성 지시가 이후 결정과 행동을 조종하는 간접 프롬프트 인젝션(IPI)에 취약한데, 기존의 적응형 공격들은 대상 에이전트를 반복 질의하며 페이로드를 다듬는 방식을 전제한다. 현실의 공격자에게는 미지의 대상과 상호작용할 기회가 단 한 번뿐인 경우가 많다는 점이 이 논문의 출발점이다. 저자들이 제안하는 SAVOR는 공격 적응을 테스트 시점 반복에서 **오프라인 전략 증류**로 옮긴다. 서로 겹치지 않는 학습 환경에서 수집한 성공·실패 궤적에 대해 결과 조건부 반성을 수행하고, 문맥 조건부 후보 전략을 검증한 뒤 재사용 가능한 전략 메모리로 반복 통합한다. 테스트 시점에는 고정된 메모리가 각 미지 대상에 대해 단일 페이로드 생성을 안내하며, 대상 에이전트 질의 1회만 필요하고 피드백은 전혀 쓰지 않는다. 벤치마크 2종·피해 모델 3종의 6개 설정 전부에서 최고 평균 공격 성공률을 기록했고, 공격자 도구를 홀드아웃하는 Agent Security Bench에서 최강 선행 공격 대비 2.5–11.8점, 전략 학습 없는 동일 주입 채널 대비 23.1점을 앞섰으며, 공격 목표를 홀드아웃하고 도구 상호작용과 실행 영수증으로 공격을 검증하는 신규 실행형 벤치마크 OpenClaw-IPI에서는 28.6점을 앞섰다.
