## 1. Undetectable Backdoors in Model Parameters: Hiding Sparse Secrets in High Dimensions  🆕

- **저자**: Sarthak Choudhary, Atharv Singh Patlan, Nils Palumbo, Ashish Hooda, Kassem Fawaz et al. (University of Wisconsin–Madison / Princeton)
- **키워드**: `backdoor`, `supply-chain attack`, `provable undetectability`, `model security`
- **출처**: arxiv recent (cs.CR) · SNS
- **arxiv**: [2605.04209](https://arxiv.org/abs/2605.04209) (v1, 2026-05-05)
- **PDF**: [`./pdfs/2605.04209.pdf`](./pdfs/2605.04209.pdf)

**핵심 요약**:
공개 모델 저장소(HF 등)를 통한 supply-chain 백도어 공격에서, 기존 공격은 모두 매개변수 단위 탐지기와 경험적으로 공진화해 왔을 뿐 "어떤 효율적 알고리듬으로도 탐지 불가"라는 증명이 없었음. 본 논문의 Sparse Backdoor는 사전학습된 다층 분류기(CNN, ViT 포함)의 fully-connected 층 일부 컬럼에 구조화된 sparse perturbation을 주입하고, 독립 isotropic 가우시안 dither로 마스킹해 사전학습 가중치를 기준점으로 한 reference 분포에서 탐지 불가능함을 형식적으로 증명함. mild margin 조건 하에서 dithered reference가 원본 분류기와 기능적으로 동치임을 보이고, 백도어 모델과 reference의 구분이 계산적으로 어려움을 환원으로 증명. Hugging Face 생태계 위협 모델에 직접적인 의의가 있는 첫 다층 모델용 증명 가능 백도어.

## 2. XL-SafetyBench: A Country-Grounded Cross-Cultural Benchmark for LLM Safety and Cultural Sensitivity  🆕

- **저자**: Dasol Choi, Eugenia Kim, Jaewon Noh, Seo Sang, Eunmi Kim et al. (AIM Intelligence / Microsoft / Korea AISI / KT / BMW Group / Coinbase 외)
- **키워드**: `safety benchmark`, `multilingual jailbreak`, `cultural alignment`, `red-teaming`
- **출처**: arxiv recent (cs.CL) · SNS
- **arxiv**: [2605.05662](https://arxiv.org/abs/2605.05662) (v1, 2026-05-07)
- **PDF**: [`./pdfs/2605.05662.pdf`](./pdfs/2605.05662.pdf)

**핵심 요약**:
기존 LLM 안전 벤치마크가 영어 중심 + 단순 번역 위주여서 국가별 위해와 문화적 민감도를 포착하지 못한다는 문제를 정면으로 다룸. 10개 국가-언어 쌍에 걸쳐 5,500개 케이스의 XL-SafetyBench를 구축 — 국가별 적대적 prompt(Jailbreak Benchmark)와 무해해 보이는 요청에 지역적 민감도를 내포한 Cultural Benchmark의 두 축. LLM 보조 발굴 + 자동 검증 게이트 + 국가당 두 명의 native annotator로 구성된 다단계 파이프라인 사용. ASR 외에 Neutral-Safe Rate (NSR), Cultural Sensitivity Rate (CSR) 두 지표를 함께 도입해 "원칙 있는 거절"과 "이해 실패"를 구분. 10개 frontier + 27개 로컬 모델 평가에서 (1) jailbreak 강건성과 문화 인식이 frontier 모델에서 비독립이고, (2) 로컬 모델의 ASR–NSR 거의 선형 trade-off (r=−0.81)는 안전성이 진짜 alignment가 아닌 생성 실패에서 온다는 사실을 드러냄.

## 3. Exposing LLM Safety Gaps Through Mathematical Encoding: New Attacks and Systematic Analysis  🆕

- **저자**: Haoyu Zhang, Mohammad Zandsalimy, Shanu Sushmita (Northeastern University, Ansys)
- **키워드**: `jailbreak`, `mathematical encoding`, `formal logic attack`, `LLM safety`
- **출처**: arxiv recent (cs.CR) · SNS
- **arxiv**: [2605.03441](https://arxiv.org/abs/2605.03441) (v1, 2026-05-05)
- **PDF**: [`./pdfs/2605.03441.pdf`](./pdfs/2605.03441.pdf)

**핵심 요약**:
LLM 안전 메커니즘이 의미 패턴 매칭에 의존하는 사실을 이용해, 유해 prompt를 집합론·형식 논리·양자역학 같은 수학적 형식으로 변환하면 8개 모델·2개 벤치마크 평균 ASR 46–56%로 안전 필터를 우회. 핵심 발견은 "수학 표기 자체"가 아니라 helper LLM이 유해 내용을 진짜 수학 문제로 깊이 재구성하는지가 결정적이라는 점 — 단순 규칙 기반의 수학 포맷팅은 베이스라인과 동등 수준에 그침. 새로 제안한 Formal Logic 인코딩은 Set Theory와 동등한 ASR을 달성, 취약성이 특정 수학 분야가 아닌 형식적 추론 일반에 걸쳐 일반화됨을 보임. GPT-5/GPT-5-Mini는 구버전보다 강건하지만 여전히 취약. 안전성이 표면 의미가 아니라 수학 구조에 대해 추론해야 한다는 주장.

## 4. MultiBreak: A Scalable and Diverse Multi-turn Jailbreak Benchmark for Evaluating LLM Safety  🆕

- **저자**: Jialin Song, Xiaodong Liu, Weiwei Yang, Wuyang Chen, Mingqian Feng, Xuekai Zhu, Jianfeng Gao (Microsoft Research)
- **키워드**: `multi-turn jailbreak`, `safety benchmark`, `active learning`, `red-teaming`
- **출처**: arxiv recent (cs.CL) · SNS
- **arxiv**: [2605.01687](https://arxiv.org/abs/2605.01687) (v1, 2026-05-03)
- **PDF**: [`./pdfs/2605.01687.pdf`](./pdfs/2605.01687.pdf)

**핵심 요약**:
실제 대화 환경의 다회차 jailbreak가 single-turn보다 안전 정렬 LLM을 훨씬 쉽게 우회하지만, 기존 multi-turn 벤치마크는 규모가 작거나 템플릿에 의존해 다양성이 부족함. MultiBreak은 다양한 유해 의도를 통합하고 active learning 파이프라인으로 high-quality multi-turn 적대적 prompt를 확장 — generator가 불확실성 기반 정제 신호로 반복 fine-tune되어 더 강한 공격 후보 생성. 결과: 10,389개 multi-turn 프롬프트 / 2,665개 distinct 유해 의도 / 가장 다양한 토픽 커버리지. 실험에서 차순위 데이터셋 대비 DeepSeek-R1-7B에서 +54.0%, GPT-4.1-mini에서 +34.6% 더 높은 ASR을 달성하며, single-turn에서는 무해해 보이는 카테고리가 multi-turn에서 훨씬 강한 공격력을 보임을 입증.

## 5. Null-Space–Constrained Contrastive Visual Forgetting for MLLM Unlearning  🆕

- **저자**: Yuhang Wang, Zhenxing Niu, Haoxuan Ji, Guangyu He, Linlin Zhang, Haichang Gao (Xidian University, Xi'an Jiaotong University)
- **키워드**: `machine unlearning`, `MLLM`, `visual privacy`, `null-space projection`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2605.05909](https://arxiv.org/abs/2605.05909) (v1, 2026-05-07)
- **PDF**: [`./pdfs/2605.05909.pdf`](./pdfs/2605.05909.pdf)

**핵심 요약**:
MLLM의 unlearning은 시각·텍스트 모달리티가 얽혀 있어 LLM 단독보다 어려움 — 목표는 target 시각 지식만 잊고 non-target 시각 + 모든 텍스트 지식은 보존. LLM backbone은 freeze하고 visual module만 fine-tune. (1) Contrastive Visual Forgetting (CVF)으로 target/retained 시각 지식을 분리하고 target 표현을 적절한 영역으로 유도, (2) retained 지식의 null space를 식별해 unlearning 업데이트를 그 공간으로 제약 → 보존 지식 손상 최소화, (3) 정적 unlearning을 넘어 forgetting 요청이 순차적으로 도착하는 continual unlearning까지 확장. 다양한 벤치마크에서 효과적 forgetting과 강건한 retention의 균형을 달성.

## 6. Beyond Accuracy: Policy Invariance as a Reliability Test for LLM Safety Judges  🆕

- **저자**: Shihao Weng, Yang Feng (Nanjing University), Xiaofei Xie (Singapore Management University)
- **키워드**: `LLM-as-judge`, `agent safety evaluation`, `policy invariance`, `evaluation reliability`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2605.06161](https://arxiv.org/abs/2605.06161) (v1, 2026-05-07)
- **PDF**: [`./pdfs/2605.06161.pdf`](./pdfs/2605.06161.pdf)

**핵심 요약**:
LLM-as-a-Judge가 사실상 agent 안전 평가의 표준이 됐지만, 기존 벤치마크는 judge의 평결을 ground-truth로 신뢰할 뿐 평결이 정말 agent 행동에 의존하는지, 아니면 평가 정책의 표현 방식에 좌우되는지 점검하지 않음. "policy invariance"라는 신뢰성 최소 조건을 제안 — (i) 의미 등가 재작성에 대한 rubric-semantics 불변성, (ii) 의도적 strict↔lenient 전환에 대한 임계 불변성, (iii) ambiguity-aware calibration. ASSEBench/R-Judge trajectory에 대해 4개 agent-class judge로 stress test한 결과, 오늘날 judge들은 의미를 보존하는 재작성에서도 최대 9.1%의 평결이 뒤집히고, 모든 평결 변동의 18–43%가 unambiguous 케이스에서 발생 — 즉 안전 점수가 "agent가 한 일"과 "evaluator가 어떻게 prompt 됐는지"를 혼동. Policy Invariance Score와 Judge Card 리포팅 프로토콜을 공개해 향후 안전 벤치마크가 평가자 자체를 audit하도록 함.

## 7. Sparse Tokens Suffice: Jailbreaking Audio Language Models via Token-Aware Gradient Optimization  🆕

- **저자**: Zheng Fang, Xiaosen Wang, Shenyi Zhang, Shaokang Wang, Zhijin Ge
- **키워드**: `audio jailbreak`, `multimodal attack`, `sparse adversarial`, `ALM safety`
- **출처**: arxiv recent (cs.CR) · SNS
- **arxiv**: [2605.04700](https://arxiv.org/abs/2605.04700) (v1, 2026-05-06)
- **PDF**: [`./pdfs/2605.04700.pdf`](./pdfs/2605.04700.pdf)

**핵심 요약**:
오디오 LLM (ALM)에 대한 기존 jailbreak는 전체 waveform을 dense하게 갱신하지만, 본 연구는 token-aligned gradient 분석을 통해 gradient energy가 audio token 사이에 매우 비균일하게 분포한다는 사실을 발견. 즉 일부 token에 대응하는 영역만이 최적화 신호를 지배. 이에 착안한 Token-Aware Gradient Optimization (TAGO)는 high-gradient-energy token에 정렬된 waveform 그라디언트만 유지하고 나머지를 매 iteration마다 마스킹하는 sparse jailbreak 최적화 방법. 3개 ALM에서 베이스라인 능가; Qwen3-Omni에서 token retention ratio 0.25만으로도 ASR 86%를 유지(전체 retention 87% 대비). dense waveform 갱신이 대체로 redundant함을 보이며, 향후 audio jailbreak·safety alignment 연구가 token-level gradient 구조를 활용하도록 제언.

## 8. Multilingual Safety Alignment via Self-Distillation  🆕

- **저자**: Ruiyang Qin, Qingzhuo Wang, Dongrui Liu, Qiang Li, Zhihua Wei, Wen Shen (Tongji University, Shanghai AI Laboratory)
- **키워드**: `multilingual safety`, `self-distillation`, `cross-lingual transfer`, `low-resource jailbreak`
- **출처**: arxiv recent (cs.LG)
- **arxiv**: [2605.02971](https://arxiv.org/abs/2605.02971) (v1, 2026-05-03)
- **PDF**: [`./pdfs/2605.02971.pdf`](./pdfs/2605.02971.pdf)

**핵심 요약**:
LLM은 영어 등 고자원 언어에선 강한 안전 장치를 갖지만 저자원 언어(Javanese 등)에선 jailbreak에 매우 취약. 기존 정렬 방법은 언어별 고품질 응답 데이터에 의존해 비용이 큼. Multilingual Self-Distillation (MSD): 응답 데이터 없이 multilingual query만으로 LLM 내재된 안전 능력을 고자원→저자원 언어로 이전하는 cross-lingual safeguard transfer 프레임워크. on-policy / off-policy MSD 두 변형 제공. Dual-Perspective Safety Weighting (DPSW)는 teacher와 student 양쪽 관점을 동시에 고려한 divergence 측정으로 안전 critical token에 적응적으로 더 큰 페널티를 부여. 다양한 multilingual jailbreak·utility 벤치마크에서 일관되게 우수한 성능, 더 어려운 데이터셋 + unseen 언어로 일반화하면서 일반 능력은 보존.

## 9. E-MIA: Exam-Style Black-Box Membership Inference Attacks against RAG Systems  🆕

- **저자**: Zelin Guan, Shengda Zhuo, Zeyan Li, Jinchun He, Wangjie Qiu et al.
- **키워드**: `membership inference`, `RAG privacy`, `corpus leakage`, `black-box attack`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2605.00955](https://arxiv.org/abs/2605.00955) (v1, 2026-05-01)
- **PDF**: [`./pdfs/2605.00955.pdf`](./pdfs/2605.00955.pdf)

**핵심 요약**:
RAG 시스템에서는 retrieval 코퍼스 자체가 민감 자산이 되며, black-box adversary가 query–response만으로 어떤 후보 문서가 RAG 지식베이스에 ingest됐는지 추론(document-level membership inference)할 수 있어 코퍼스 커버리지·민감 토픽 존재 여부가 누출됨. 기존 RAG-MIA는 (1) semantic similarity 같은 "soft" 신호로 멤버/비멤버 분포가 겹치고 임계값이 불안정하거나, (2) 의도가 뚜렷한 explicit confirmation probe로 거절·탐지에 취약. E-MIA는 target 문서의 검증 가능 hard evidence(세부 사실, 고유명사/전문용어, 정의문, 메타데이터, 인과/제약 관계)를 4가지 객관 채점 가능한 시험 문항(FB/SC/MC/T·F)으로 변환하고, 다수 evidence-targeted 문항의 집계 점수를 멤버십 신호로 사용. 다양한 데이터셋·RAG 구성에서 엄격한 설정에서도 멤버/비멤버 분리도를 개선하며, 자연스러운 stealthy query를 유지.

## 10. Unlearning What Matters: Token-Level Attribution for Precise Language Model Unlearning  🆕

- **저자**: Jiawei Wu, Doudou Zhou
- **키워드**: `machine unlearning`, `token attribution`, `gradient SNR`, `privacy compliance`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2605.00364](https://arxiv.org/abs/2605.00364) (v2, 2026-05-06)
- **PDF**: [`./pdfs/2605.00364.pdf`](./pdfs/2605.00364.pdf)

**핵심 요약**:
LLM 기계 학습 해제는 프라이버시·안전·규제 대응의 핵심 능력이지만, 기존 방법은 sequence 단위로 모든 토큰에 균일한 업데이트를 적용 — 실제로는 일부 토큰만이 제거 대상 지식을 인코딩하므로 불필요한 gradient noise가 발생하고 utility가 떨어짐. TokenUnlearn은 (i) masking 기반 knowledge-aware 신호와 (ii) entropy-aware 신호를 결합한 token-level attribution으로 중요 토큰을 선별하고, hard selection(고중요도 토큰에만 unlearning 적용)과 soft weighting(중요도 가중 gradient) 두 전략을 제공해 기존 unlearning 방법을 token-level 변형으로 확장. 이론적으로 token-level 선택이 gradient SNR을 개선함을 보이고, TOFU·WMDP에서 3개 모델 아키텍처에 걸쳐 sequence-level baseline 대비 forgetting과 utility 보존 양쪽에서 일관된 개선을 확인. (이번이 v2로 abstract 업데이트.)
