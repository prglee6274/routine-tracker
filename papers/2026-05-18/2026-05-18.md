## 1. Re-Triggering Safeguards within LLMs for Jailbreak Detection  🆕

- **저자**: (저자명 미확인, arxiv 메타 직접 확인 권장)
- **키워드**: `jailbreak`, `prompt-level defense`, `embedding disruption`, `internal safeguard`
- **출처**: arxiv recent · SNS 화제 (X에서 jailbreak detection 관련 다수 언급)
- **arxiv**: [2605.10611](https://arxiv.org/abs/2605.10611) (v1)
- **PDF**: [`./pdfs/2605.10611.pdf`](./pdfs/2605.10611.pdf)

**핵심 요약**:
LLM에 이미 학습된 안전 정렬(safety alignment)이 jailbreak 프롬프트 앞에서 자주 무력화되는 문제를 해결하기 위해, 입력 임베딩을 미세하게 교란시키는 "embedding disruption" 기법으로 모델 내부의 잠재된 안전 메커니즘을 다시 켜는 방식을 제안한다. 외부 분류기가 아니라 LLM 자체의 내장 방어를 활용한다는 점이 핵심이고, 기존 standalone detector 대비 우회 공격(adaptive attack)에 강건한 jailbreak 탐지 성능을 보였다.

## 5. SoftSAE: Dynamic Top-K Selection for Adaptive Sparse Autoencoders  🆕

- **저자**: (저자명 미확인)
- **키워드**: `sparse autoencoder`, `mechanistic interpretability`, `dynamic top-K`, `monosemanticity`
- **출처**: arxiv recent (cs.LG) · 검색 화제 (interp 커뮤니티)
- **arxiv**: [2605.06610](https://arxiv.org/abs/2605.06610) (v1)
- **PDF**: [`./pdfs/2605.06610.pdf`](./pdfs/2605.06610.pdf)

**핵심 요약**:
표준 Top-K SAE 는 토큰마다 동일한 sparsity K 를 강제해 dead neuron, polysemantic feature 등 문제가 잔존한다. SoftSAE 는 입력 활성에 따라 K 를 동적으로 조절하는 "soft" top-K 게이트를 도입해 LLM / ViT 양쪽에서 monosemantic feature 분해 품질을 개선했다. 같은 reconstruction error 에서 더 적은 dead feature, 더 높은 자동 해석 가능성 점수를 얻었다고 보고.
