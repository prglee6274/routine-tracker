## 1. Do Sparse Autoencoders Learn Meaningful Concept Hierarchies?  🆕

- **저자**: Nils Grandien, David Steinmann, Felix Friedrich, Kristian Kersting
- **키워드**: `sparse autoencoder`, `mechanistic interpretability`, `concept hierarchy`, `evaluation protocol`
- **출처**: arxiv recent (cs.LG)
- **arxiv**: [2606.22994](https://arxiv.org/abs/2606.22994) (v1)
- **PDF**: [`./pdfs/2606.22994.pdf`](./pdfs/2606.22994.pdf)

**핵심 요약**:
SAE는 대형 모델의 비지도 개념 발견 도구로 자리잡았고 최근에는 특징 공간에 (명시적·암묵적으로) 계층 구조를 부여하려는 시도가 늘었지만, "의미 있는 계층"이 무엇인지에 대한 합의된 요건도 일관된 정량 평가 프로토콜도 없어 비교가 어려웠다. 저자들은 시맨틱 네트워크·분류학(taxonomy) 연구와 기존 SAE 연구를 종합해 일반화/특수화 계층이 만족해야 할 핵심 요건을 도출하고 이를 구체적 평가 프로토콜로 정식화한다. 현행 SAE들에 적용한 결과 기존 방법이 만드는 계층이 이 요건을 충분히 충족하지 못함을 보여 "SAE가 실제로 의미 있는 개념 위계를 학습하는가"에 비판적으로 답한다. 계층적 SAE 해석가능성을 평가할 표준 척도를 제안한 점이 기여.

## 2. MuPPET: A Benchmark for Contextual Privacy of LLM Assistants in Multi-Party Conversations  🆕

- **저자**: Elena Sofia Ruzzetti, Cornelius Emde, Sangdoo Yun, Seong Joon Oh, Martin Gubri
- **키워드**: `contextual privacy`, `LLM agents`, `benchmark`, `multi-party`, `data leakage`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2606.23217](https://arxiv.org/abs/2606.23217) (v1)
- **PDF**: [`./pdfs/2606.23217.pdf`](./pdfs/2606.23217.pdf)

**핵심 요약**:
LLM 에이전트가 그룹 채팅 같은 다자(multi-party) 환경에 배치되면 사적 정보 한 번의 노출이 모든 그룹원에게 동시에 도달해, 1:1 설정보다 통제가 구조적으로 훨씬 어렵다(모든 정보가 모든 수신자에게 적절해야 함). 그러나 기존 맥락적 프라이버시 벤치마크는 전부 단일 상대 설정만 다뤄 다자 위험을 측정하지 못했다. 저자들은 다자 대화에서의 맥락적 프라이버시를 평가하는 MuPPET(Multi-Party Privacy Exposure Testing) 벤치마크를 제안한다. 실험 결과 모델들은 1:1 평가가 시사하는 것보다 다자 환경에서 훨씬 많은 정보를 누출했고, 프런티어 모델조차 취약했다.

## 3. When AUC 0.998 Is Not Enough: A Candidate Evaluation Protocol for Hidden-State Probes of Indirect Prompt Injection in Multimodal Computer-Use Agents  🆕

- **저자**: Yanhang Li, Zhichao Fan, Zexin Zhuang
- **키워드**: `hidden-state probing`, `indirect prompt injection`, `computer-use agents`, `interpretability`, `evaluation`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.22864](https://arxiv.org/abs/2606.22864) (v1)
- **PDF**: [`./pdfs/2606.22864.pdf`](./pdfs/2606.22864.pdf)

**핵심 요약**:
히든 스테이트 프로빙(동결된 VLM 내부 활성에 얹는 선형 분류기)은 멀티모달 컴퓨터-유즈 에이전트가 손상된 행동을 내놓기 전에 간접 프롬프트 인젝션(IPI)을 잡아내는 평가 도구로 각광받는다. 저자들은 단일 백본 사례연구(Qwen2.5-VL-7B, Mind2Web, teacher-forced replay)를 통해 깨끗vs공격 분리에서의 높은 AUC(0.998)가 그 자체로는 "악성 콘텐츠를 탐지했다"는 증거가 아님을 경고한다. 텍스트 인젝션에 대한 쌍 구성 스칼라 베이스라인과 시각 오버레이의 동일-스텝 잡음 정합 통제라는 두 사후 진단을 제안해, 높은 AUC가 의미론적 탐지가 아니라 표면 단서에 기인할 수 있음을 드러낸다. 프로브 기반 안전 평가의 신뢰성을 점검하는 통제 세트(리포팅 프로토콜)를 제시한 것이 기여.

## 4. AgentLens: Interpretable Safety Steering via Mechanistic Subspaces for Multi-Turn Coding Agent  🆕

- **저자**: Weidi Luo, Qiming Zhang, Yihao Quan, Mingyu Jin, Jie Cai et al.
- **키워드**: `mechanistic interpretability`, `activation steering`, `agent safety`, `coding agents`, `white-box defense`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.22673](https://arxiv.org/abs/2606.22673) (v1)
- **PDF**: [`./pdfs/2606.22673.pdf`](./pdfs/2606.22673.pdf)

**핵심 요약**:
LLM 기반 코딩 에이전트는 자율성이 높지만 외부 환경과의 다중 턴 상호작용에서 안전·오용 위험이 크고, 기존 외부 가드레일은 실행 중 세밀한 행동 제어가 어렵다. 한편 LLM 안전을 위한 기계적 해석가능성 기법들도 대부분 단일 턴·탈옥형 QA에 국한돼 다중 턴 에이전트의 진화하는 위험 동역학을 포착하지 못한다. 저자들은 내부(화이트박스) 관점에서 다중 턴 코딩 에이전트의 안전을 분석하고, 기계적 부분공간(mechanistic subspace)에서 런타임 안전 탐지와 표현 조향(steering)을 수행하는 화이트박스 방어 프레임워크 AgentLens를 제안한다. 해석가능성을 실행 시점의 안전 개입으로 연결한 점이 핵심 기여.

## 5. Have You Ever Seen Them? Entity-level Membership Inference through Interrogating Large Language Models  🆕

- **저자**: Yiran Zhu, Ziqi Yang
- **키워드**: `membership inference`, `privacy`, `LLM`, `training data`, `black-box`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.23030](https://arxiv.org/abs/2606.23030) (v1)
- **PDF**: [`./pdfs/2606.23030.pdf`](./pdfs/2606.23030.pdf)

**핵심 요약**:
LLM의 프라이버시 누출·저작권 준수 우려가 커지는 가운데 멤버십 추론은 위험 평가의 핵심 도구지만, 기존 연구는 특정 샘플(또는 샘플 기반 단위)의 학습 사용 여부에만 집중했다. 저자들은 LLM이 사람의 기억처럼 특정 샘플을 그대로 외우지 않아도 흩어진 언급들로부터 실세계 엔티티에 대한 지식을 축적·노출한다는 점에 주목한다. 이에 사람을 인터뷰하듯 LLM을 심문(interrogate)하여 특정 엔티티 관련 정보가 학습에 쓰였는지를 판별하는 "엔티티 수준" 멤버십 추론을 제안한다. 라벨만 주어지는 블랙박스 설정에서 이 과제를 연구해, 샘플 단위 MIA가 놓치는 새로운 누출 차원을 드러낸다.

VLM이 소비자·의료·금융·기업 응용에 폭넓게 배치되면서 멀티모달 QA·어시스턴트 응답·교차모달 합성 등 안전 표면이 넓어졌고, 모더레이션 정책은 제품·지역·배포 단계마다 달라진다. 대부분의 가드레일은 고정된 분류체계나 좁은 상호작용 설정에 묶여 배포 시점에 안전 규칙이 바뀌면 적응하기 어렵다. 저자들은 활성 정책을 런타임 입력으로 받아 자연어 규칙별로 대상 콘텐츠를 점검하는 정책 적응형 멀티모달 가드레일 모델군 SingGuard를 제시한다. 규칙별 위반 판정과 근거를 동적 추론으로 산출해, 정책이 바뀌어도 재학습 없이 대응하는 유연성이 기여.

## 7. "What Happens Locally, Leaks Globally": Detecting Privacy Leakage Risks in MCP Servers  🆕

- **저자**: Biwei Yan, Minghui Xu, Yijun Yang, Boyang Ma, Xuelong Dai et al.
- **키워드**: `privacy leakage`, `MCP`, `LLM agents`, `static analysis`, `PII`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.21338](https://arxiv.org/abs/2606.21338) (v1)
- **PDF**: [`./pdfs/2606.21338.pdf`](./pdfs/2606.21338.pdf)

**핵심 요약**:
MCP(Model Context Protocol)가 LLM과 외부 자원을 잇는 사실상의 표준이 되면서, 기존 도구로는 잡기 힘든 새로운 부류의 프라이버시 위험이 생겼다. 일반적 유출 버그와 달리 MCP 서버의 누출은 대체로 프로토콜에 내재되어 있어, 자격증명·API 키·PII가 도구 핸들러 안에서 반환·로깅·예외로 떠오르기만 해도 명시적 외부 요청 없이 로컬/LLM 경계를 넘는다. 저자들은 다국어 MCP 서버에서 이런 누출을 탐지하는 맥락 인식 교차언어 정적분석 프레임워크 MCPPrivacyDetector를 제안한다. 이기종 코드를 통합 프로그램 표현으로 올린 뒤 분석해 프로토콜 유발 누출을 체계적으로 발견한다.

## 8. Think Twice Before You Act: Protecting LLM Agents Against Tool Description Poisoning via Isolated Planning  🆕

- **저자**: Shanghao Shi, Xiao Wang, Chaoyu Zhang, Hao Li, Wenjing Lou et al.
- **키워드**: `tool poisoning`, `prompt injection`, `LLM agents`, `agent safety`, `defense`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.20922](https://arxiv.org/abs/2606.20922) (v1)
- **PDF**: [`./pdfs/2606.20922.pdf`](./pdfs/2606.20922.pdf)

**핵심 요약**:
외부 도구 통합은 LLM 에이전트의 능력을 크게 늘렸지만 프롬프트 인젝션을 넘어선 새 공격면을 연다. 특히 교차 도구 설명 오염(cross-tool description poisoning)은 플래너가 보는 도구 메타데이터를 조작해, 오염된 도구가 끝내 선택되지 않아도 에이전트의 경로를 틀어버릴 수 있다. 저자들은 기존 프롬프트 인젝션 방어들이 이 위협에 잘 전이되지 않음을 확인하고, 오염된 설명이 계획 맥락에 단계 간 잔존하며 지속적으로 영향을 준다는 핵심 관찰을 제시한다. 이를 막기 위해 "격리된 계획(isolated planning)"이라는 새 개념에 기반한 시스템 수준 방어 Tool-Guard를 제안한다.

## 9. Amplify, Don't Create: Temporal Accumulation for Slow-Burn Prompt Injection  🆕

- **저자**: J Alex Corll
- **키워드**: `prompt injection`, `agent security`, `temporal detection`, `control-plane attack`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.20746](https://arxiv.org/abs/2606.20746) (v1)
- **PDF**: [`./pdfs/2606.20746.pdf`](./pdfs/2606.20746.pdf)

**핵심 요약**:
대부분의 프롬프트 인젝션 탐지기는 단일 이벤트/메시지를 점수화하지만, 도구 사용 에이전트에 대한 제어면(control-plane) 공격은 약한 지시를 한 궤적에 분산시켜 각 이벤트를 임계값 아래로 유지할 수 있다. 저자들은 프록시 측 시간 누적기(temporal accumulator)가 동결된 이벤트별 점수를 피크·CUSUM 지속 통계로 환원해 이 "슬로우번" 신호를 복원하는지 검증한다. 순환논증을 피하기 위해 별도의 클로킹 타깃으로 공격(graft)을 생성한 뒤 기록 탐지기(char-ngram SVM + 임베딩 대조 헤드)로 재채점하고, 임계값 아래이면서 실행된 행동 엣지에 결속된 것만 평가에 넣는다. 집중 공격에서 궤적 수준 누적이 이벤트별 기준선을 능가함을 보인 경계(boundary) 결과로, 배포형 탐지기가 아닌 개념 검증이라고 명시한다.

## 10. OTTER: A Red-Teaming System for Toxicity-Evading Jailbreak Prompt Optimization  🆕

- **저자**: Jerry Wang, Hsin-Ling Hsu, Yi-Cheng Lai, Nai-Chia Chen, Fang Yu
- **키워드**: `jailbreak`, `red-teaming`, `toxicity evasion`, `adversarial`, `LLM`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2606.21077](https://arxiv.org/abs/2606.21077) (v1)
- **PDF**: [`./pdfs/2606.21077.pdf`](./pdfs/2606.21077.pdf)

**핵심 요약**:
운영 LLM은 독성 기반 모더레이션 필터를 1차 방어로 삼으며, 해로운 의도가 표면적 독성과 상관된다고 가정한다. 저자들은 이 가정이 근본적으로 취약함을 보인다: 토큰 5개 정도만 바꿔도 표면 독성과 적대적 의도를 분리할 수 있다. 이들은 표준 API 접근만 요구하는 블랙박스 레드팀 프레임워크 OTTER(Obfuscated Toxicity-Evading Token Evolution for Rewriting)를 제안한다. AdvBench 457개 프롬프트·4개 GPT 모델 평가에서 평균 공격성공률(ASR)을 7.0%→84.0%로 끌어올렸고, 독성-우회 관계의 첫 정량 분석과 함께 운영 환경 분류기 강화를 위한 실행 가능한 권고를 제시한다.
