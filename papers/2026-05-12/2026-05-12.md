## 1. Position: Mechanistic Interpretability Must Disclose Identification Assumptions for Causal Claims  🆕

- **저자**: Zezheng Lin, Fengming Liu
- **키워드**: `mechanistic interpretability`, `causal identification`, `circuits`, `monosemanticity`, `position paper`
- **출처**: arxiv recent (cs.AI) · SNS
- **arxiv**: [2605.08012](https://arxiv.org/abs/2605.08012) (v1, 2026-05-08)
- **PDF**: [`./pdfs/2605.08012.pdf`](./pdfs/2605.08012.pdf)

**핵심 요약**:
mechanistic interpretability 논문이 circuits·mediators·causal abstraction·monosemanticity 같은 인과 용어를 점점 더 사용하지만, 이런 주장에 필요한 식별(identification) 가정을 명시적으로 적은 논문이 거의 없다는 비판적 position 논문. 4개 방법론 줄기(activation patching, SAE, causal abstraction, probing+ablation)에 걸친 10편 + n=30 이중 코더 audit 결과, 어떤 논문도 "Identification Assumptions" 섹션을 두지 않고 faithfulness·completeness·monosemanticity·ablation effect 같은 validation 지표를 그대로 인과 근거로 치환하는 패턴이 반복됨을 보임. 저자는 (i) 주장이 인과적인지 명시, (ii) 식별 전략 이름 지정, (iii) 가정 열거, (iv) 최소 1개 stress-test, (v) 가정 위배 시 결론이 어떻게 흔들리는지 기술하는 5단계 disclosure norm을 제안하고, 각 방법론별 templates까지 함께 제공. "Validation is not identification." — interpretability 분야의 인식론적 위생을 강제하려는 시도.

## 2. Why Does Agentic Safety Fail to Generalize Across Tasks?  🆕

- **저자**: Yonatan Slutzky, Yotam Alexander, Tomer Slor, Yoav Nagel, Nadav Cohen (Tel Aviv University 추정)
- **키워드**: `agent safety`, `task generalization`, `Lipschitz bound`, `H∞ robustness`, `safety theory`
- **출처**: arxiv recent (cs.LG) · SNS
- **arxiv**: [2605.06992](https://arxiv.org/abs/2605.06992) (v1, 2026-05-07)
- **PDF**: [`./pdfs/2605.06992.pdf`](./pdfs/2605.06992.pdf)

**핵심 요약**:
멀티태스크 agent에서 "task 실행 능력"은 unseen task로 잘 generalize하지만 "안전한 실행 능력"은 그렇지 못한 현상에 대해, 이를 학습 기법의 결함이 아닌 안전성 자체의 내재적 성질로 설명하는 이론+실험 논문. linear-quadratic + H∞-robustness 제어 문제에서 task 명세 → 최적 controller로의 mapping이 안전 요구를 추가했을 때 Lipschitz constant가 *높아짐*을 증명 — 즉 safety는 capability보다 더 가파른 함수이므로 같은 데이터로 학습해도 더 빠르게 OOD에서 무너짐(독립적 의의를 갖는 Lipschitz bound). neural-net agent의 quadcopter 시뮬 navigation과 LLM agent의 CRM 시나리오에서 같은 결론을 실증. 결국 현재의 agent 안전 향상 시도들이 근본적으로 부족할 수 있고, 다른 접근(예: task-aware safety layer)이 필요함을 시사하는 영향력 있는 결과.

- **PDF**: [`./pdfs/2605.04454.pdf`](./pdfs/2605.04454.pdf)

**핵심 요약**:

- **arxiv**: [2605.07630](https://arxiv.org/abs/2605.07630) (v1, 2026-05-08)
- **PDF**: [`./pdfs/2605.07630.pdf`](./pdfs/2605.07630.pdf)

**핵심 요약**:
phone-use agent가 유해 행동을 "안 하는" 결과만으로 안전하다고 평가하는 기존 관행을 비판 — 위험을 인지해 안전한 선택을 한 것일 수도, 단순히 화면을 이해 못 하거나 어떤 행동도 못 한 것일 수도 있는데, 둘은 원인과 해결책이 다름에도 task success/refusal/final harm으로 묶여 평가됨. 130+ 앱의 실제 phone interaction에서 추출한 700개 risk moment로 구성된 PhoneSafety 벤치마크 제안 — 각 instance는 다음 한 step의 의사결정을 격리해 (safe action / unsafe action / "do nothing useful") 3분류. 8개 대표 agent 평가에서 두 가지 패턴 발견: (1) 일반 phone-use 능력이 강해도 위험 순간의 안전 선택률은 반드시 높아지지 않으며, (2) "do nothing"은 시각적/조작적으로 까다로운 화면에 집중되어 안전 신호가 아닌 capability 신호처럼 행동. 즉 무해한 결과는 안전 증거로 불충분하며, "unsafe judgment"와 "inability to act"를 분리해 평가해야 함을 실증.

- **키워드**: `safety alignment`, `LoRA`, `catastrophic forgetting`, `Mixture of Experts`, `weight translation`
- **출처**: arxiv recent (cs.CR / cs.LG)
- **arxiv**: [2605.04992](https://arxiv.org/abs/2605.04992) (v1, 2026-05-06)
- **PDF**: [`./pdfs/2605.04992.pdf`](./pdfs/2605.04992.pdf)

**핵심 요약**:
공개 LoRA 어댑터를 기본 LLM에 결합할 때 base 모델의 safety alignment가 catastrophic forgetting되고, safety 데이터로 다시 fine-tune하면 어댑터의 전문 지식이 무너지는 양면 실패를 zero-resource 환경에서 해결하려는 시도. Neural Weight Translation (NeWTral)은 unsafe→safe 어댑터 쌍 corpus로 사전학습된 비선형 translation 모듈로, 파라미터 공간에서 직접 unsafe domain adapter를 safe alignment manifold로 매핑. adaptive MoE 라우팅으로 "외과적 변환" 전문가와 "공격적 정렬" 전문가를 자동 혼합. Llama·Mistral·Qwen·Gemma 4개 패밀리, 최대 72B 파라미터, 8개 도메인 평가에서 unsafe expert의 평균 ASR 70%를 13%까지 떨어뜨리면서 90% 지식 유지율 달성. NeWTral 자체가 standalone downloadable asset로 배포되어 — 비유하자면 군중이 만든 어댑터 위에 군중이 다시 깔 수 있는 "안전 패치" 모듈.

## 7. Beyond Steering Vector: Flow-based Activation Steering for Inference-Time Intervention  🆕

- **저자**: Zehao Jin, Ruixuan Deng, Junran Wang, Xinjie Shen, Chao Zhang
- **키워드**: `activation steering`, `flow matching`, `inference-time intervention`, `AxBench`
- **출처**: arxiv recent (cs.LG) · SNS
- **arxiv**: [2605.05892](https://arxiv.org/abs/2605.05892) (v1, 2026-05-07)
- **PDF**: [`./pdfs/2605.05892.pdf`](./pdfs/2605.05892.pdf)

**핵심 요약**:
AxBench 등 대규모 평가에서 활성화 스티어링이 단순 in-context prompting보다 자주 뒤지고 unseen 개념에 일반화도 약하다는 문제를 진단 — 원인을 "고정·단일 step·위치 불변" 같은 검증되지 않은 단순화 가정에 둠. FLAS(Flow-based Activation Steering)는 unsteered → steered 활성을 옮기는 일반 concept-conditioned velocity field $v_t(h,t,c)$를 학습해 이 가정들을 모두 제거. AxBench에서 per-concept tuning 없이 prompting을 일관되게 능가한 *최초의* 학습 기반 방법 — Gemma-2-2B-IT에서 held-out harmonic mean 1.015, 9B-IT에서 1.113. 학습된 flow가 곡선이며 multi-step + token-varying trajectory를 그린다는 점은 기존의 activation 공간 기하학 가설(단일 direction, 위치 불변 transform)이 불완전함을 시사 — 향후 steering·표상 공학 연구가 더 풍부한 동역학을 가정해야 한다는 의미.

- **arxiv**: [2605.03907](https://arxiv.org/abs/2605.03907) (v1, 2026-05-05)
- **PDF**: [`./pdfs/2605.03907.pdf`](./pdfs/2605.03907.pdf)

**핵심 요약**:
prompt steering(시스템 prompt로 행동 조절)이 활성화 스티어링보다 잘 작동하는 이유를 "prompt steering도 활성화 스티어링의 일종"으로 재formulation해 정량 분석한 뒤, 그 메커니즘을 더 단순한 해석 가능 모델로 distill. 핵심 관찰: 인기 있는 활성화 스티어링 방법들이 prompt steering이 실제 만들어내는 "일부 token엔 강한 개입·다른 token엔 거의 무개입"의 sparse intervention 구조를 충실히 재현하지 못함. 이에 Prompt Steering Replacement (PSR) 모델 — 활성으로부터 token-specific 스티어링 계수를 추정하고 prompt-기반 개입을 모방하도록 학습 — 을 도입. 3개 스티어링 벤치마크 × 다중 모델에서 기존 활성화 스티어링을 능가하며, 특히 high-coherence completion 제약 하에서 이점이 두드러지고 AxBench와 persona steering에서도 prompting과 호각. interpretability + steering 연결 고리를 강화하는 결과.

- **저자**: Divyam Anshumaan, Sarthak Choudhary, Nils Palumbo, Somesh Jha (University of Wisconsin–Madison)
- **키워드**: `differential privacy`, `LLM agent`, `multi-turn`, `metric DP`, `root sanitization`
- **출처**: arxiv recent (cs.CR) · SNS
- **arxiv**: [2605.03188](https://arxiv.org/abs/2605.03188) (v1, 2026-05-04)
- **PDF**: [`./pdfs/2605.03188.pdf`](./pdfs/2605.03188.pdf)

**핵심 요약**:
LLM agent가 여러 서비스를 거치며 사적 데이터를 다회 release하면 metric DP 기반 sanitizer는 매 release를 독립으로 다뤄 — 적이 turn에 걸쳐 release를 조합하면 개인 속성을 복원할 수 있고, 매 release마다 privacy가 *근본적으로* 저하됨을 정량화. 특히 사적 속성이 computation graph의 root이고 derived value에 독립적으로 noise를 더하면, 비선형 함수의 Lipschitz constant $L$이 nominal privacy parameter를 초과하면서 root의 distinguishability를 증폭시킴(의료/금융 워크플로에서 큰 문제). RootGuard는 root value를 한 번만 sanitize하고 이후 derive를 deterministic하게 처리 — post-processing 정리에 따라 privacy 보장이 turn 수·adversary 함수에 무관해지고 derived value는 marginal cost 0으로 privacy 상속. 구조적 도메인 지식(BMI = f(키,몸무게) 등)으로 root 간 예산 분배까지 최적화. NHANES 8개 의료 진단 템플릿, ε=0.1에서 RootGuard가 target error를 독립 noise 대비 2.3–3.0× 낮추고(7.6% vs 17.1% wMAPE), turn이 늘수록 RootGuard는 그대로지만 독립 noise는 더 약해지는 *이중 비대칭*까지 보임.

## 10. MIPIAD: Multilingual Indirect Prompt Injection Attack Defense with Qwen–TF-IDF Hybrid and Meta-Ensemble Learning  🆕

- **저자**: Al Muhit Muhtadi, Mostafa Rifat Tazwar
- **키워드**: `indirect prompt injection`, `multilingual`, `defense`, `ensemble learning`, `LoRA`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2605.07269](https://arxiv.org/abs/2605.07269) (v1, 2026-05-08)
- **PDF**: [`./pdfs/2605.07269.pdf`](./pdfs/2605.07269.pdf)

**핵심 요약**:
RAG / tool-using LLM 시스템에서 indirect prompt injection은 영어 외 언어로 가면 더 까다로워지는데, 기존 defense 대부분이 영어 중심으로 평가됨을 지적. MIPIAD는 영어/벵골어 환경을 함께 평가하는 defense — (i) Qwen2.5-1.5B를 LoRA로 fine-tune한 sequence classifier(XLPID), (ii) TF-IDF lexical feature, (iii) late fusion · stacking · gradient boosting을 결합한 validation-tuned meta-ensemble. BIPIA 템플릿(email/table/QA/abstract/code 5개 task family) 위에 만든 143만 샘플 규모 synthetic benchmark + 학습/평가에서 attack category mutually-exclusive split. 결과: TF-IDF+SVM 단독으로도 F1 0.77로 lexical 신호가 강함이 확인되고, XLPID+TF-IDF 하이브리드가 F1 0.9205로 최고, Boosting Ensemble이 AUROC 0.9378로 최고. ensemble은 standalone neural 모델 대비 영-벵 cross-lingual gap을 일관되게 줄이고, NLLB-200/XLPID 백본이 200+ 언어로 확장 가능하도록 설계 — 단, 현재 empirical 검증은 영어·벵골어에 한정.
