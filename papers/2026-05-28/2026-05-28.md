## 1. Mechanistically Interpreting the Role of Sample Difficulty in RLVR for LLMs  🆕

- **저자**: Yue Cheng, Jiajun Zhang, Xiaohui Gao, Weiwei Xing, Zheng Wang, Zhanxing Zhu
- **키워드**: `mechanistic interpretability`, `RLVR`, `temporal sparse autoencoder`, `reasoning`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2605.28388](https://arxiv.org/abs/2605.28388) (v1)
- **PDF**: [`./pdfs/2605.28388.pdf`](./pdfs/2605.28388.pdf)

**핵심 요약**: RLVR(Reinforcement Learning with Verifiable Reward)에서 샘플 난이도가 학습에 어떻게 작용하는지를 mechanistic 시각으로 분석한다. 난이도가 RLVR에 비단조(non-monotonic) 효과를 가지며, 쉬운/중간 문제는 안정적 추론 향상을, 지나치게 어려운 문제는 답 반복·계산 생략 같은 퇴행 행동을 유발해 기존 능력을 깎을 수 있음을 보인다. Temporal Sparse Autoencoder(T-SAE)로 내부 feature 동역학을 추적해 쉬운 문제는 직답·기본계산 feature를, 어려운 문제는 추론 feature를 활성화하지만 성공 trajectory를 샘플링했을 때만 유의미함을 관찰하고, 이를 활용한 backward-reasoning reformulation과 T-SAE-guided 보상 dense화 전략을 제안한다.

## 2. Blind PRNG Hijacking: An Undetectable Integrity-Preserving Attack Against LLM Watermarking  🆕

- **저자**: Ziyang You, Huilong He, Xiaoke Yang, Xuxing Lu
- **키워드**: `watermarking`, `supply-chain attack`, `PRNG`, `content provenance`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2605.28632](https://arxiv.org/abs/2605.28632) (v1)
- **PDF**: [`./pdfs/2605.28632.pdf`](./pdfs/2605.28632.pdf)

**핵심 요약**: KGW·Unigram·DipMark 등 주류 LLM 워터마킹의 보안 근거인 PRNG 신뢰 가정을 공격하는 SeedHijack을 제시한다. (i) 키·detector·logit 무지(blind), (ii) 워터마크 신호를 지우지 않고 오히려 증폭(integrity-preserving), (iii) content-side detector 통계와 직교(증폭+회피 동시 성립)라는 세 성질을 동시에 만족한다. 텍스트를 손상시키지 않고 supply-chain 단계에서 PRNG를 교체해 green-list 선택을 편향시키며, 세 워터마킹 스킴 × 세 오픈소스 LLM에서 6/6 SOTA 통계 detector를 모두 우회하면서 z-score를 최대 2.42×까지 부풀린다. QRNG 대응책이 효과적임을 보여 PRNG 무결성을 콘텐츠 출처 시스템의 1급 보안 요건으로 격상해야 한다고 주장한다.

## 3. MRMMIA: Membership Inference Attacks on Memory in Chat Agents  🆕

- **저자**: Kai Chen, Yan Pang, Tianhao Wang
- **키워드**: `membership inference`, `agent memory`, `privacy leakage`
- **출처**: arxiv recent (cs.CR/cs.LG)
- **arxiv**: [2605.27825](https://arxiv.org/abs/2605.27825) (v1)
- **PDF**: [`./pdfs/2605.27825.pdf`](./pdfs/2605.27825.pdf)

**핵심 요약**: MIA(Membership Inference Attack) 연구는 주로 학습 corpus나 검색 DB를 다뤄왔지만, chat agent의 영속 memory 역시 사용자 상호작용·선호·검색된 사실을 담고 있어 누설 표적이 된다. 후보 memory unit이 agent memory store에 속하는지 추론하는 task를 정의하고, 다중 recall probe로 black/gray/white-box 모두에서 멤버십 신호를 뽑아내는 Multi-Recall Memory MIA(MRMMIA)를 제안한다. 다양한 chat agent 구성에서 baseline을 일관되게 능가하며, agent 메모리에 대한 첫 표준 평가 프레임을 제공한다.

## 4. Refusal Before Decoding: Detecting and Exploiting Refusal Signals in Intermediate LLM Activations  🆕

- **저자**: Matteo Gioele Collu, Riccardo Conte, Alberto Giaretta, Denis Kleyko, Mauro Conti, Matteo Zavatteri, Roberto Confalonieri
- **키워드**: `linear probe`, `refusal direction`, `jailbreak`, `AutoDAN`
- **출처**: arxiv recent (cs.AI/cs.CR)
- **arxiv**: [2605.28553](https://arxiv.org/abs/2605.28553) (v1)
- **PDF**: [`./pdfs/2605.28553.pdf`](./pdfs/2605.28553.pdf)

**핵심 요약**: 각 transformer 블록의 residual stream에서 학습한 linear probe만으로 LLM의 refusal 행동이 최종 layer 한참 전부터 선형으로 decode 가능하다는 사실을 보인다. 이 신호를 공격에 직접 활용하기 위해 Mechanistic AutoDAN을 도입 — 유전 알고리즘 기반 prompt 탐색의 fitness를 풀-forward 대신 부분 forward + probe 점수로 대체한다. ASR은 vanilla AutoDAN과 비슷하거나 우위이면서 iteration당 시간은 최대 72% 줄이고 cross-model transfer도 일부 설정에서 더 좋다. probe-guidance의 유용성은 모델 규모가 커질수록 증가하며, refusal이 출력 수준의 행동만이 아니라 actionable한 구조적 내부 신호임을 입증한다.

- **키워드**: `sparse autoencoder`, `optimal transport`, `circuit analysis`, `feature matching`
- **출처**: arxiv recent (cs.LG)
- **arxiv**: [2605.28567](https://arxiv.org/abs/2605.28567) (v1)
- **PDF**: [`./pdfs/2605.28567.pdf`](./pdfs/2605.28567.pdf)

**핵심 요약**: SAE 해석에서 어려운 두 과제 — 다층에서 의미적으로 유사한 feature 매칭, 대형 feature circuit을 supernode로 압축 — 가 사실은 "서로 다른 activation manifold 위의 SAE feature 간 semantic distance 추정"이라는 동일한 문제임을 보인다. feature를 단일 decoder 벡터가 아니라 그것을 발화시키는 hidden state 위 activation-weighted 분포로 표현하고, 공유 reference 공간으로 projection 후 Wasserstein 거리로 비교하는 분포적 프레임워크를 제안한다. activation rescale 불변·perturbation에 안정·유한 샘플 마진 하 true match 회복을 증명하고, decoder 벡터·LLM 기반 baseline을 능가하며 circuit을 자동으로 해석 가능한 supernode로 압축한다.

## 6. Got a Secret? LLM Agents Can't Keep It: Evaluating Privacy in Multi-Agent Systems  🆕

- **저자**: Aman Priyanshu, Supriti Vijay, Esha Pahwa
- **키워드**: `multi-agent privacy`, `contextual integrity`, `social pressure`, `safety benchmark`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2605.27766](https://arxiv.org/abs/2605.27766) (v1)
- **PDF**: [`./pdfs/2605.27766.pdf`](./pdfs/2605.27766.pdf)

**핵심 요약**: 기존 LLM 안전성 평가는 모델을 고립시켜 평가하지만 실제 agent는 다른 agent와 한 달 단위 영속 상호작용을 한다. 수천 agent가 커뮤니티 단위로 상호작용하는 Moltbook-style 시뮬레이션을 구축해 사회적 압력 하 프라이버시 침해를 측정한다. 단일 턴(CI-Memories 19.95%) 대비 다중 턴 사회 평가에서 45.30%로 침해율이 폭증, leakage가 사회적으로 전염되어 동료 agent의 폭로를 본 뒤에는 8× 더 자주 민감정보를 노출하며, 명시적 프라이버시 지시도 효과는 있으나 안전장치 적용 후에도 leakage가 37.8% 이상 잔존함을 보인다. 정적 챗 기반 벤치마크가 agentic 배포 위험을 체계적으로 과소평가함을 시사한다.

## 7. RULER: Representation-Level Verification of Machine Unlearning  🆕

- **저자**: Georgina Cosma, Axel Finke
- **키워드**: `machine unlearning`, `verification`, `representation residual`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2605.27569](https://arxiv.org/abs/2605.27569) (v1)
- **PDF**: [`./pdfs/2605.27569.pdf`](./pdfs/2605.27569.pdf)

**핵심 요약**: 기존 machine unlearning 검증은 membership inference·retain accuracy·forget accuracy 같은 출력 수준 지표에 의존하지만, 모델은 출력 수준 평가를 모두 통과하면서도 forgotten 레코드를 내부 표현에 유지할 수 있다. RULER는 (i) 재학습된 oracle 모델 대비 forget-set 위치를 비교하는 oracle-comparative 지표 M2와 (ii) oracle 없이 내부 유사도 구조만으로 residual을 탐지하는 M4로 구성된다. 4개 근사 unlearning 기법이 모두 출력 평가를 통과하지만 12개 조건 중 10개에서 M2가 유의한 residual을 검출(p<0.05); face-recognition에서는 어떤 기법도 ID-수준 기억을 완전히 지우지 못함을 확인한다. 사전 진단용 oracle-free 지표로도 활용 가능하다.

- **출처**: arxiv recent (cs.CL/cs.AI/cs.LG)
- **arxiv**: [2605.27997](https://arxiv.org/abs/2605.27997) (v1)
- **PDF**: [`./pdfs/2605.27997.pdf`](./pdfs/2605.27997.pdf)

**핵심 요약**: 재학습이나 출력 필터링 없이 toxicity가 모델 내부 어디에 살고 있는지를 밝히고 제거하는 두 프레임워크 Meow2X·TRNE를 제시한다. toxic vs neutral prompt의 activation 차이를 분석해 특정 layer·뉴런으로 toxicity를 국소화한 뒤, inference-time scaling 또는 rank-one weight edit으로 gradient 없이 억제한다. 5개 LM × 2개 벤치마크 × 90개 설정에서 일관된 toxicity 감소와 언어 모델링 품질 유지가 확인되며, toxicity가 초기 MLP 층에 불균형하게 인코딩되어 있고 아키텍처마다 다르다는 점, 단일 evaluator로는 위험을 체계적으로 과소평가한다는 점을 드러낸다.

## 9. Plant, Persist, Trigger: Sleeper Attack on Large Language Model Agents  🆕

- **저자**: Yongxiang Li, Moxin Li, Zhixin Ma, Fengbin Zhu, Dongrui Liu, Wenjie Wang, Fuli Feng
- **키워드**: `agent safety`, `sleeper attack`, `prompt injection`, `cross-interaction`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2605.28201](https://arxiv.org/abs/2605.28201) (v1)
- **PDF**: [`./pdfs/2605.28201.pdf`](./pdfs/2605.28201.pdf)

**핵심 요약**: 기존 외부 prompt injection 평가는 "한 사용자 요청 안에서 즉시 발현되는 단일-상호작용 공격"을 가정해 왔지만, 실제로는 adversarial content가 agent 상태(세션 context·메모리·재사용 가능한 스킬)에 잠복해 후속 양성 요청에서 발현될 수 있다. 이를 Sleeper Attack으로 정식화하고, 6개 실세계 유해 결과 × 3개 공격 전략 × 3개 상태 타깃을 가로지르는 1,896-instance 벤치마크를 구축한다. 7개 오픈/클로즈드 LLM 전부 단일-상호작용 ASR이 낮아도 Sleeper Attack에는 취약 — 예컨대 LIP의 ASR이 11.1%→39.9%, PIE는 0.6%→41.6%로 급등하며 cross-interaction 위협의 검출·완화 난이도를 정량화한다.

## 10. Mind the Gap: Mixtures of Gaussians in Approximate Differential Privacy  🆕

- **저자**: Huikang Liu, Aras Selvi, Wolfram Wiesemann
- **키워드**: `differential privacy`, `Gaussian mixture mechanism`, `low-privacy regime`
- **출처**: arxiv recent (cs.CR/cs.LG/stat.ML)
- **arxiv**: [2605.28078](https://arxiv.org/abs/2605.28078) (v1) — ICML 2026 style preprint
- **PDF**: [`./pdfs/2605.28078.pdf`](./pdfs/2605.28078.pdf)

**핵심 요약**: 알려진 sensitivity의 스칼라 query에 대해 (ε, δ)-DP를 만족하는 새로운 additive noise mechanism 계열을 설계한다. 분산은 같고 평균·가중치만 다른 여러 Gaussian의 혼합으로 구성한 mixture mechanism은, analytic Gaussian (Balle & Wang 2018)에 sensitivity 의존 평균을 가진 추가 Gaussian을 더한 convex combination으로 해석된다. (ε, δ)-DP를 위한 tight한 분산 조건과 효율적 계산 알고리즘을 도출하고, analytic Gaussian 대비 기대 잡음(l1)과 분산(l2)이 모두 유의하게 작으며, 특히 moderate/low-privacy 영역에서는 최적성에 근접해 analytic Gaussian의 optimality gap을 거의 메운다.
