## 1. LiSA: Lifelong Safety Adaptation via Conservative Policy Induction  🆕

- **저자**: Minbeom Kim, Lesly Miculicich, Bhavana Dalvi Mishra, Mihir Parmar, Phillip Wallis
- **키워드**: `agent safety`, `guardrail`, `policy induction`, `LLM agent`
- **출처**: HF Daily · arxiv recent · SNS
- **arxiv**: [2605.14454](https://arxiv.org/abs/2605.14454) (v1)
- **PDF**: [`./pdfs/2605.14454.pdf`](./pdfs/2605.14454.pdf)

**핵심 요약**:
도구를 호출하고 다단계 워크플로를 실행하는 AI agent에서 가드레일 실패는 단순 응답 품질 문제가 아니라 비밀 누설·무단 액션 인가로 직결되며, 적절성이 조직별 정책·사용자 기대에 의존해 사전 사양화가 어렵다. LiSA는 고정된 base 가드레일을 구조화된 메모리로 보완하는 보수적 정책 유도 프레임워크로, 드물게 들어오는 실패 보고를 재사용 가능한 정책 추상으로 변환하고 충돌 인식 로컬 룰로 과일반화를 막으며 posterior lower bound 기반의 신뢰도 게이팅으로 메모리 재사용을 제어한다. PrivacyLens+·ConFaide+·AgentHarm에서 sparse·noisy(라벨 플립 20%) 피드백 하에도 강한 메모리 베이스라인을 일관되게 능가했고, latency–performance 프런티어를 backbone 모델 스케일링 너머로 밀어냈다.

- **PDF**: [`./pdfs/2605.15183.pdf`](./pdfs/2605.15183.pdf)

**핵심 요약**:
기계적 해석성에서 "두 회로가 같은 계산을 한다"를 검증하는 것은 핵심 전제임에도, 기존 유사도는 행동 기반(OOD 메커니즘 무시)이거나 파라미터 기반(weight-space 대칭성 무시) 어느 한쪽에만 갇혀 있었다. 저자들은 tensor 기반 모델군에 대해 가중치 자체에 정의되며 그러한 대칭성에 불변인 새로운 metric "tensor similarity"를 제안하고, 효율적 재귀 알고리듬으로 cross-layer 메커니즘까지 포함한 전역 함수적 동치를 포착한다. 실증적으로 grokking·backdoor 삽입 같은 학습 동역학을 기존 metric보다 충실히 추적해, 유사도 측정과 충실성 검증을 경험적 근사에서 대수적 문제로 환원하는 길을 연다.

## 3. MetaBackdoor: Exploiting Positional Encoding as a Backdoor Attack Surface in LLMs  🆕

- **저자**: Rui Wen, Mark Russinovich, Andrew Paverd, Jun Sakuma, Ahmed Salem
- **키워드**: `backdoor`, `positional encoding`, `LLM security`, `system prompt leakage`
- **출처**: arxiv recent
- **arxiv**: [2605.15172](https://arxiv.org/abs/2605.15172) (v1)
- **PDF**: [`./pdfs/2605.15172.pdf`](./pdfs/2605.15172.pdf)

**핵심 요약**:
기존 LLM backdoor는 모두 콘텐츠 기반 트리거(입력 텍스트 변경)에 의존했는데, 본 논문은 그 가정 자체가 불필요하다는 것을 보인다. MetaBackdoor는 Transformer가 토큰 위치를 반드시 내부 표현에 인코딩한다는 사실을 이용해, 텍스트는 시각·의미적으로 깨끗하게 두면서 길이 같은 위치 정보만으로 backdoor를 발화시킨다. 시연으로 길이 조건이 충족되면 시스템 프롬프트 같은 내부 비밀을 LLM이 토해내게 만들 수 있고, 정상적인 멀티턴 대화가 자연스레 trigger 영역으로 흘러들어가 공격자 입력 없이도 악성 tool-call을 유발하는 self-activation 시나리오도 가능하다. 콘텐츠 기반 백도어와 직교 결합도 가능해 더 정밀하고 탐지가 어려워지며, 위치 인코딩을 새로운 공격 표면으로 정의해 텍스트 검출 위주의 방어 패러다임에 도전한다.

## 4. Forgetting That Sticks: Quantization-Permanent Unlearning via Circuit Attribution  🆕

- **저자**: Saisab Sadhu, Pratinav Seth, Vinay Kumar Sankarapu
- **키워드**: `machine unlearning`, `quantization`, `circuit attribution`, `mechanistic verification`
- **출처**: arxiv recent · SNS
- **arxiv**: [2605.15138](https://arxiv.org/abs/2605.15138) (v1)
- **PDF**: [`./pdfs/2605.15138.pdf`](./pdfs/2605.15138.pdf)

**핵심 요약**:
표준 unlearning 평가는 풀 정밀도·학습 직후 행동 억제만 측정하지만 실제 배포 모델은 모두 양자화된다. 저자들은 4-bit PTQ가 unlearning을 되돌리는 현상이 우연이 아니라 체계적 이중 실패(그래디언트 방법은 양자화 후 망각이 풀리고, 양자화에 강한 방법은 모델을 거의 안 바꿈)이며, per-parameter 업데이트가 NF4 양자화 빈 폭의 47~828배 작아 수십억 파라미터에 흩어진 업데이트가 빈 경계를 넘지 못한다는 sparsity–permanence trade-off로 형식화한다. 제안 MANSU는 인과 회로 attribution으로 forget-set 최소 부분그래프를 격리하고 회로 한정 null-space 사영 + 대각 Fisher retain bound + per-parameter 크기 floor를 결합해 양자화 후에도 망각이 사라지지 않도록 설계하며, 행동 억제와 구조적 소거를 구분하는 Circuit Attribution Divergence(CAD) metric을 함께 제시한다. 다양한 모델·해저드 벤치마크에서 처음으로 의미 있는 망각·retain 유지·non-positive PTQ gap·구조적 소거를 모두 동시에 만족한다.

## 5. WARD: Adversarially Robust Defense of Web Agents Against Prompt Injections  🆕

- **저자**: Tri Cao, Yulin Chen, Hieu Cao, Yibo Li, Khoi Le
- **키워드**: `prompt injection`, `web agent`, `guard model`, `adversarial training`
- **출처**: arxiv recent
- **arxiv**: [2605.15030](https://arxiv.org/abs/2605.15030) (v1)
- **PDF**: [`./pdfs/2605.15030.pdf`](./pdfs/2605.15030.pdf)

**핵심 요약**:
웹 agent는 HTML/시각 인터페이스에 심긴 prompt injection에 취약하지만 기존 가드 모델은 도메인·공격 패턴 일반화, 정상 콘텐츠에 대한 오탐, 매 스텝 지연, 가드 자체를 노린 적응 공격 등 한계를 동시에 안고 있다. WARD는 719개 고트래픽 URL/플랫폼에서 모은 약 17.7만 샘플의 WARD-Base와 가드 모델을 직접 노린 prompt injection 전용 WARD-PIG로 학습되고, 메모리 기반 attacker–guard 공진화로 적응 공격 내성을 키우는 A3T 학습 프레임워크를 도입한다. OOD 벤치마크에서 거의 완벽한 recall, 낮은 FPR로 agent 효용 보존, 가드 표적·적응 공격에 대한 강건성을 보이며 agent와 병렬 실행되어 추가 지연 없이 동작한다.

## 7. Privacy Auditing with Zero (0) Training Run  🆕

- **저자**: Tudor Cebere, Mathieu Even, Linus Bleistein, Aurélien Bellet

- **출처**: arxiv recent · SNS
- **arxiv**: [2605.14591](https://arxiv.org/abs/2605.14591) (v1)
- **PDF**: [`./pdfs/2605.14591.pdf`](./pdfs/2605.14591.pdf)

**핵심 요약**:
기존 differential privacy 감사 방법은 모델을 여러 번 재학습하거나 데이터 포함을 무작위화하는 등 학습 파이프라인에 개입할 수 있어야 해서 foundation model 같은 대규모 배포 시스템에는 비현실적이다. 저자들은 학습 후 두 개의 고정 데이터셋(학습 멤버 / 비멤버)만으로 사후 감사하는 Zero-Run 프레임워크를 제안한다. 관측 체제에서는 membership이 무작위가 아니어서 멤버/비멤버 간 분포 차가 leakage로 오인될 수 있는데, 인과추론 시각에서 이 confounding을 형식화하고 (i) 분포 shift+leakage를 적응 합성으로 보수적으로 보정하는 글로벌 방법과 (ii) 관측 데이터에 조건부로 포인트별 membership 추정을 조정해 더 날카로운 instance-dependent bound를 주는 방법, 두 보완 접근을 제시한다. 합성·대규모 모델 실험에서 재학습이 불가능한 환경에서도 유효한 프라이버시 평가가 가능함을 보인다.

## 8. ReMIA: A Powerful and Efficient Alternative to Membership Inference Attacks against Synthetic Data Generators  🆕

- **저자**: Davide Scassola, Andrea Coser, Sebastiano Saccani
- **키워드**: `membership inference`, `synthetic data`, `privacy metric`, `tabular SDG`
- **출처**: arxiv recent
- **arxiv**: [2605.14686](https://arxiv.org/abs/2605.14686) (v1)
- **PDF**: [`./pdfs/2605.14686.pdf`](./pdfs/2605.14686.pdf)

**핵심 요약**:
표 형식 합성 데이터 생성기(SDG)에 대한 SOTA MIA는 강력하지만 수백 번의 shadow training과 원본의 수 배 크기의 보조 데이터를 요구해 실무 적용이 어렵고, distance-to-closest-record 같은 빠른 프록시는 민감도가 낮다. ReMIA는 "어떤 레코드가 학습셋에 있었는가"를 직접 예측하는 대신, 두 개의 source dataset로 각각 합성셋을 만든 뒤 임의 레코드가 어느 source에서 나왔는지를 분류기가 맞힐 수 있는가로 누출을 측정하는 상대적 MIA다. 단 두 번의 SDG 학습과 원본 이하 크기의 보조 데이터만 필요하며, 여러 표 데이터/SDG에서 SOTA MIA에 견줄 만한 민감도를 훨씬 실용적인 비용으로 달성한다. SDG가 전통적 노이즈 기반 익명화보다 더 나은 privacy–utility 곡선을 그릴 수 있음도 함께 관찰했다.

## 10. Mechanistic Interpretability of EEG Foundation Models via Sparse Autoencoders  🆕

- **저자**: William Lehn-Schiøler, Magnus Ruud Kjær, Rahul Thapa, Magnus Guldberg Pedersen, Anton Storgaard Mosquera
- **키워드**: `sparse autoencoder`, `mechanistic interpretability`, `EEG foundation model`, `concept steering`
- **출처**: arxiv recent · SNS
- **arxiv**: [2605.13930](https://arxiv.org/abs/2605.13930) (v1)
- **PDF**: [`./pdfs/2605.13930.pdf`](./pdfs/2605.13930.pdf)

**핵심 요약**:
EEG foundation model은 임상 성능은 SOTA지만 내부 계산이 불투명해 임상 신뢰 도입의 병목이 된다. 저자들은 아키텍처가 다른 세 EEG transformer(SleepFM, REVE, LaBraM)에 TopK SAE를 적용해 sparse feature dictionary를 뽑고, 임상 분류 체계(이상·연령·성별·약물)로 grounding해 monosemanticity와 entanglement를 벤치마크한다. concept steering 기반 "target vs. off-target" probe 면적 metric으로 (i) 선택적 조향 가능 (ii) 인코딩되었으나 얽힘 (iii) 비인코딩의 세 운영 영역을 가르고, 전체 성능을 무너뜨리는 wrecking-ball 개입과 연령–병리 얽힘 같은 임상적 confounding을 노출한다. spectral decoder를 통해 잠재 개입을 amplitude spectrum(병적 slow-wave 억제, α-band 복원 등) 같은 생리학적으로 해석 가능한 주파수 시그니처로 사상한다. SAE 해석성의 임상 다영역 일반화 가능성을 보여주는 사례.
