## 1. Segment-Level Coherence for Robust Harmful Intent Probing in LLMs  🆕

- **저자**: Xuanli He, Bilgehan Sel, Faizan Ali, Jenny Bao, Hoagy Cunningham, Jerry Wei (UCL · Virginia Tech · Anthropic)
- **키워드**: `harmful intent probing`, `streaming probe`, `CBRN`, `jailbreak detection`, `adversarial fine-tuning`
- **출처**: arxiv recent (cs.CL cross-listed cs.CR)
- **arxiv**: [2604.14865](https://arxiv.org/abs/2604.14865) (v1)
- **PDF**: [`./pdfs/2604.14865.pdf`](./pdfs/2604.14865.pdf)

**핵심 요약**: 기존 LLM activation 기반 streaming harmful intent probe는 일부 고-스코어 토큰에만 의존해 CBRN 용어가 등장하는 양성 문맥에서도 잘못된 알람을 자주 발생시킴. 저자들은 단일 토큰 스파이크가 아니라 여러 evidence 토큰이 일관되게 같은 결론을 지지해야 출력이 통과하는 segment-level coherence 목적함수를 제안. 1% FPR 고정 조건에서 TPR을 기존 강한 baseline 대비 35.55% 상대 향상시켰고, AUROC도 거의 포화 상태(97.40%)에서 추가 개선. Attention / MLP activation을 probe할 때 residual-stream보다 일관되게 우월하며, character-level cipher 같은 우회를 위해 adversarial fine-tuning한 모델에도 plug-and-play로 적용해 AUROC 98.85% 이상을 유지함.

## 2. Model Organisms Are Leaky: Perplexity Differencing Often Reveals Finetuning Objectives  🆕

- **저자**: Mohammed Abu Baker, Luca Baroni, Daniel Wilhelm (Meridian Visiting Researcher Programme)
- **키워드**: `model organisms`, `alignment auditing`, `perplexity diffing`, `backdoor detection`, `synthetic document finetuning`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2605.00994](https://arxiv.org/abs/2605.00994) (v1)
- **PDF**: [`./pdfs/2605.00994.pdf`](./pdfs/2605.00994.pdf)

**핵심 요약**: AI safety 연구에서 인터프리트/감사 메소드를 평가하기 위해 의도적으로 특정 행동을 학습시킨 "model organism" 시리즈가 표준이 되어 가는데, 이 논문은 이런 모델들이 의외로 "leaky"하다는 것을 보임. 일반 corpus의 짧은 prefix로 다양한 completion을 생성한 뒤 reference 모델 대비 finetuned 모델의 perplexity gap이 큰 순서로 정렬하기만 해도 상위 결과가 finetuning objective를 사실상 드러냄. 0.5B~70B 76개 model organism (백도어, synthetic document finetuning, adversarially-trained, emergent misalignment 등 다양)에서 광범위하게 작동. 모델 internal access나 prior 가정 없이 next-token logprob만으로 가능해 API 모델에도 적용 가능. 모델 organism / alignment audit 평가 프로토콜의 기반을 흔드는 결과.

## 3. Mitigating Misalignment Contagion by Steering with Implicit Traits  🆕

- **저자**: Maria Chang, Ronny Luss, Miao Liu, Keerthiram Murugesan, Karthikeyan Ramamurthy, Djallel Bouneffouf (IBM Research)
- **키워드**: `misalignment contagion`, `multi-agent`, `activation steering`, `implicit traits`, `social dilemma`
- **출처**: arxiv recent (cs.AI / cs.CL)
- **arxiv**: [2605.02751](https://arxiv.org/abs/2605.02751) (v2)
- **PDF**: [`./pdfs/2605.02751.pdf`](./pdfs/2605.02751.pdf)

**핵심 요약**: 기존 정렬 연구는 대부분 단일 LM × 단일 user 가정인데, 다중 에이전트 워크플로우에서는 "misalignment contagion" — 즉 한 모델의 비정렬 행동이 상호작용을 통해 다른 모델로 전파되는 현상이 발생함을 Prisoner's Dilemma · Chicken · Stag Hunt 3-player iterated 게임 환경에서 확인. 단순히 system prompt를 반복해서 reinforcing하는 것은 효과가 없거나 오히려 해로움. 대신 "Steering with Implicit Traits (SIT)" — 모델 초기 trait을 강조하는 문장을 system prompt에 간헐적으로 주입 — 이 black-box 환경에서 친사회적 행동 유지에 훨씬 효과적임을 보임. Multi-agent 안전성 문헌에서 거의 다루지 않은 새로운 위협 모델 정립.

## 4. Hijacking Large Audio-Language Models via Context-Agnostic and Imperceptible Auditory Prompt Injection  🆕

- **저자**: Meng Chen, Kun Wang, Li Lu, Jiaheng Zhang, Tianwei Zhang (Zhejiang Univ · NUS · NTU); IEEE S&P 2026 accepted
- **키워드**: `auditory prompt injection`, `LALM`, `multimodal attack`, `imperceptible perturbation`, `tool-use hijacking`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2604.14604](https://arxiv.org/abs/2604.14604) (v1)
- **PDF**: [`./pdfs/2604.14604.pdf`](./pdfs/2604.14604.pdf)

**핵심 요약**: 실시간 음성 비서가 LALM(Large Audio-Language Model) 기반으로 빠르게 확산되는 가운데, 기존 audio jailbreak는 공격자가 user 본인일 때를 가정. 본 연구는 "audio data-only" 즉 audio 채널에만 접근 가능한 제3자 공격자가, 사용자에게 들리지 않을 정도로 자연스러운 reverberation 형태로 변조된 적대적 오디오를 환경음에 섞어 LALM을 인질화하는 AudioHijack을 제안. Sampling-based gradient estimation + attention supervision + 다중 context 학습으로 end-to-end 최적화하며, 13개 SOTA LALM에서 6개 misbehavior 카테고리에 대해 unseen context에서도 79–96% hijack 성공률 달성. Mistral AI · Microsoft Azure 상용 음성 에이전트가 사용자 모르게 무권한 액션을 실행하는 실제 시연까지 포함.

- **키워드**: `LLM router attack`, `adversarial suffix`, `black-box attack`, `cost-inflation attack`, `model stealing`
- **출처**: arxiv recent (cs.CR / cs.CL)
- **arxiv**: [2604.15022](https://arxiv.org/abs/2604.15022) (v1)
- **PDF**: [`./pdfs/2604.15022.pdf`](./pdfs/2604.15022.pdf)

**핵심 요약**: OpenRouter, GPT-5-Auto 등 cost-aware LLM 라우터가 보편화되면서, 라우터가 비용이 비싼 강력 모델로 query를 보내도록 유도하는 새로운 attack surface가 생김. 본 R²A는 black-box 라우터에 대해 hybrid ensemble surrogate 라우터를 학습한 뒤, 이 ensemble에 맞춘 suffix optimization 알고리즘을 통해 적대적 suffix를 생성. 다양한 query distribution과 open-source / 상용 라우팅 시스템에서 단순 query에 대해서도 비싼 모델로 라우팅되는 비율을 크게 상승시킴. 결과적으로 서비스 측 비용 폭증과 라우팅 정책 무력화를 발생시키는 새로운 LLM-system-level 보안 위협 카테고리.

## 6. H-Probes: Extracting Hierarchical Structures From Latent Representations of Language Models  🆕

- **저자**: Cutter Dawes, Aryan Sharma, Angelos Ioannis Lagos, Shivam Raval (SPAR · Yale · Harvard)
- **키워드**: `linear probes`, `hierarchical structure`, `latent geometry`, `mechanistic interpretability`, `reasoning trace`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2605.00847](https://arxiv.org/abs/2605.00847) (v2)
- **PDF**: [`./pdfs/2605.00847.pdf`](./pdfs/2605.00847.pdf)

**핵심 요약**: LLM이 syntax나 단순 concept만이 아니라 "추론 과정 자체의 계층 구조"를 잠재 공간에서 어떻게 표상하는지를 묻는 interpretability 연구. depth와 pairwise distance를 추출하는 linear probe 집합인 H-probes를 정의하고, 합성 tree traversal 태스크에서 hierarchy를 포함하는 subspace가 (i) low-dimensional, (ii) causally important, (iii) in/out-of-domain 일반화됨을 ablation으로 보임. 수학 reasoning trace 같은 실제 hierarchical context에서도 더 약하지만 유사한 구조를 확인. CoT reasoning model의 내부 작동 메커니즘을 표현 수준에서 해석하는 데 직접 활용 가능.

## 7. A Theoretical Game of Attacks via Compositional Skills  🆕

- **저자**: Xinbo Wu, Huan Zhang, Abhishek Umrawal, Lav R. Varshney (UIUC · Stony Brook)
- **키워드**: `jailbreak`, `game theory`, `compositional skill`, `best-response attack`, `defense equilibrium`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2605.01034](https://arxiv.org/abs/2605.01034) (v1)
- **PDF**: [`./pdfs/2605.01034.pdf`](./pdfs/2605.01034.pdf)

**핵심 요약**: 기존 adversarial prompting 연구는 대부분 empirical인 반면, 본 논문은 공격자–방어자 게임으로 jailbreak를 formal하게 모델링. 공격자 전략을 "intent → k-skill composition"의 조건부 분포 p(S^(k)|I)로 정의하고, affirmative instruction · 저자원 언어 prompting · persona · 가상 시나리오 등 기존 공격을 fixed-skill 또는 optimization-based 공격으로 통합. 이 game에서 best-response attack을 정의하고 그것이 fixed-skill / optimization 공격의 upper bound임을 증명, 균형점 분석으로 공격자가 inherent advantage를 가짐을 보임. 동시에 그 분석을 바탕으로 prompt+response filtering을 갖춘 provably optimal defense를 제시하고, 그 실용적 인스턴스화가 다양한 LLM / 벤치마크에서 기존 적대적 prompting을 능가함을 실증.

## 8. No More Guessing: a Verifiable Gradient Inversion Attack in Federated Learning  🆕

- **저자**: Francesco Diana, Chuan Xu, André Nusser, Giovanni Neglia (Université Côte d'Azur · Inria · CNRS · I3S)
- **키워드**: `federated learning`, `gradient inversion attack`, `verifiable reconstruction`, `ReLU leakage`, `tabular privacy`
- **출처**: arxiv recent (cs.LG cross-listed cs.CR)
- **arxiv**: [2604.15063](https://arxiv.org/abs/2604.15063) (v1)
- **PDF**: [`./pdfs/2604.15063.pdf`](./pdfs/2604.15063.pdf)

**핵심 요약**: Federated Learning에서 gradient inversion attack은 vision/언어 영역에서는 인간 검수로 복원 품질을 확인할 수 있지만 tabular 데이터에는 그런 방법이 없어 "tabular는 안전하다"는 인식이 있었음. 저자들은 fully-connected layer의 ReLU 활성 경계가 입력 공간에 hyperplane을 정의한다는 기하학적 관점을 이용, hyperplane으로 둘러싸인 영역에 정확히 한 개의 레코드만 들어가는지를 algebraic subspace test로 인증하는 "Verifiable GIA(VGIA)"를 제안. 인증 통과 시 분석적으로 feature 벡터를 복원한 뒤 가벼운 optimization으로 타깃을 재구성. 큰 batch size에서도 정확한 복원이 가능하며, 기존 geometric 공격보다 더 적은 hyperplane query로 더 빠르게 복원함. Tabular FL 프라이버시 평가의 기준을 재설정.

## 9. A framework for analyzing concept representations in neural models  🆕

- **저자**: Burin Naowarat, Hao Tang, Sharon Goldwater (Univ of Edinburgh CSTR)
- **키워드**: `concept subspace`, `probing`, `concept erasure`, `LEACE`, `disentanglement`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2605.01381](https://arxiv.org/abs/2605.01381) (v1)
- **PDF**: [`./pdfs/2605.01381.pdf`](./pdfs/2605.01381.pdf)

**핵심 요약**: Linear concept subspace를 다루는 probing 계열과 concept erasure(LEACE 등) 계열이 서로 다른 가정에 기대왔다는 점을 짚고, "containment(개념이 subspace에 fully 표현되는가)"와 "disentanglement(다른 개념과 분리되는가)" 두 축으로 통합 평가 프레임워크를 제시. 다섯 가지 추정 방법을 동일 기준으로 비교한 결과, (1) 추정기 선택이 containment·disentanglement에 큰 영향, (2) SOTA인 LEACE가 두 axis 모두에서 강하지만 seen data 외에서는 leakage가 남음, (3) HuBERT 음성 표현에서 phone 정보는 speaker 정보와 잘 분리/포함되지만 그 반대는 어렵다는 비대칭성을 확인. Steering·erasure·feature attribution 연구의 공통 평가 기반 제공.

## 10. A Systematic Exploration of Text Decomposition and Budget Distribution in Differentially Private Text Obfuscation  🆕

- **저자**: Stephen Meisenbacher, Angelo Kleinert, Florian Matthes (Technical University of Munich)
- **키워드**: `differential privacy`, `text obfuscation`, `privacy budget allocation`, `text decomposition`, `NLP privacy`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2605.01065](https://arxiv.org/abs/2605.01065) (v1)
- **PDF**: [`./pdfs/2605.01065.pdf`](./pdfs/2605.01065.pdf)

**핵심 요약**: DP 기반 텍스트 obfuscation은 word/token 단위 perturbation으로 환원되지만, 실제 문서 단위에서는 ε 예산을 컴포넌트(단어·구·n-gram·문장)별로 어떻게 분할하느냐가 결과를 좌우. 본 논문은 (i) 동적인 텍스트 분해 방식과 (ii) ε 예산 분배 방식을 직교 축으로 두고 다섯 단계 디컴포지션 × 다양한 budget 분배 전략을 두 데이터셋·세 ε 수준에서 체계적으로 평가. 동일 ε에서도 조합에 따라 privacy–utility tradeoff가 크게 갈리며, naive uniform 분배는 거의 항상 sub-optimal임을 정량적으로 보임. PII / 학습 데이터 noising 같은 다운스트림 LLM 학습용 데이터 전처리에서 ε 예산을 최적화할 실용적 지침 제공.
