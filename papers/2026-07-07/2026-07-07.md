## 1. Steal the Patch Size: Adversarially Manipulate Vision-Language Models  🆕

- **저자**: Kai Hu, Akash Bharadwaj, Weichen Yu, Matt Fredrikson
- **키워드**: `model stealing`, `side-channel attack`, `vision-language model`, `patch size`
- **출처**: arxiv recent
- **arxiv**: [2607.00174](https://arxiv.org/abs/2607.00174) (v1)
- **PDF**: [`./pdfs/2607.00174.pdf`](./pdfs/2607.00174.pdf)

**핵심 요약**:
배포된 VLM의 비공개 비전 토크나이저 설정(패치 크기·입력 전처리 파이프라인)을 블랙박스에서 복원할 수 있는지 다룬다. 핵심은 ViT 패치화가 만드는 태스크 수준 부채널로, 합성 격자 이미지를 숨겨진 패치 격자에 정렬하면 토큰화 단계에서 경계 단서가 사라져 주기적 정확도 저하가 발생한다. 격자 셀 크기를 스윕하며 이 붕괴 지점을 측정해 패치 크기를 추론하고, 패딩과 일관성 검사를 더해 동적/고정 해상도 전처리와 리사이즈 해상도까지 알아낸다. Qwen-VL 계열뿐 아니라 GPT·Claude 같은 상용 모델에서도 토크나이저 파라미터를 안정적으로 복원했으며, 이 유출이 전처리 인지형 전이 공격과 모델 특화 적대적 조작으로 이어짐을 보인다.

## 2. WARP: Weight-Space Analysis for Recovering Training Data Portfolios  🆕

- **저자**: Tzu-Heng Huang, Aditya Goyal, John Cooper, Frederic Sala
- **키워드**: `training data extraction`, `data mixture recovery`, `weight-space analysis`, `foundation model`
- **출처**: arxiv recent
- **arxiv**: [2607.01686](https://arxiv.org/abs/2607.01686) (v1)
- **PDF**: [`./pdfs/2607.01686.pdf`](./pdfs/2607.01686.pdf)

**핵심 요약**:
공개된 파운데이션 모델의 학습 데이터 레시피, 특히 소스별 샘플링을 결정하는 도메인 혼합 비율은 거의 공개되지 않는다. 기존 멤버십 추론은 개별 샘플 단위 탐지라 코퍼스 전체의 구성을 특징화하지 못한다. WARP는 공개된 가중치만으로 파인튜닝 모델의 학습 혼합 비율을 복원하는 프레임워크로, 베이스와 파인튜닝 모델을 모델 머징으로 보간해 누락된 학습 궤적을 근사하는 유사 체크포인트를 만들고 가중치 공간에 남은 학습 데이터의 기하학적 흔적에서 특징을 추출한 뒤 파라미터-프리 softmax 또는 합성 혼합으로 학습한 MLP로 도메인 비율에 매핑한다. BERT·GPT-2 통제 실험에서 평균 MAE 0.046·0.104로 도메인 혼합을 복원해, 멤버십 추론은 물론 실제 학습 궤적에 접근한 변형까지 능가했다.

- **PDF**: [`./pdfs/2607.00089.pdf`](./pdfs/2607.00089.pdf)

- **PDF**: [`./pdfs/2607.00576.pdf`](./pdfs/2607.00576.pdf)

**핵심 요약**:

## 6. Position: The Term "Machine Unlearning" Is Overused in LLMs  🆕

- **저자**: Sangyeon Yoon, Yeachan Jun, Albert No
- **키워드**: `machine unlearning`, `position paper`, `data deletion`, `LLM`
- **출처**: arxiv recent
- **arxiv**: [2606.27379](https://arxiv.org/abs/2606.27379) (v1)
- **PDF**: [`./pdfs/2606.27379.pdf`](./pdfs/2606.27379.pdf)

**핵심 요약**:
규제상 삭제 의무, 저작권·라이선스 분쟁, 안전·정책 요구로 LLM이 데이터·지식·행동을 "잊게" 하라는 요구가 늘고 있다. 이 포지션 페이퍼는 'machine unlearning'이 용어로 남용되고 있으며, 명시된 forget set의 학습 영향을 제거해 그 데이터 없이 재훈련한 모델과 근사적으로 구별 불가능하게 만드는 '데이터셋 정의 삭제'에만 한정해야 한다고 주장한다. 유해 요청 거부, 엔티티·지식 제거, 표적 억제 등은 정렬·억제·편집·난독화라는 서로 다른(대개 정책 의존적) 목표이므로 다른 용어와 베이스라인이 필요하다. 이 혼란은 표면적이지 않은데, 같은 라벨 아래 서로 다른 암묵적 보장을 내세우면 지표·벤치마크가 의도 밖에서 재사용돼 재훈련 등가성을 검증하지 않은 채 표면적 비공개(낮은 ROUGE·forget 정확도)를 보상하기 때문이다. 명시적 보장과 참조 모델에 묶인 엄격한 용어, 주장한 목표에 부합하는 평가를 촉구한다.

## 8. C²R: Cross-sample Consistency Regularization Mitigates Feature Splitting and Absorption in Sparse Autoencoders  🆕

- **저자**: Haoran Jin, Xiting Wang, Shijie Ren, Hong Xie, Defu Lian
- **키워드**: `sparse autoencoder`, `feature splitting`, `feature absorption`, `consistency regularization`
- **출처**: arxiv recent
- **arxiv**: [2606.30609](https://arxiv.org/abs/2606.30609) (v1)
- **PDF**: [`./pdfs/2606.30609.pdf`](./pdfs/2606.30609.pdf)

**핵심 요약**:
SAE는 LLM 활성화를 희소하고 사람이 이해 가능한 피처로 분해해 해석에 널리 쓰이지만, 사전(dictionary)을 키우면 근본적 문제가 드러난다. 일관된 개념을 비원자적 잠재로 쪼개는 피처 분할과 일반 피처에 임의의 예외를 만드는 피처 흡수가 만연해 잠재의 신뢰성을 심각하게 훼손하는데, 이는 샘플 간 일관되지 않은 잠재 할당에서 비롯된다. 저자들은 방향이 유사한 잠재들의 동시 활성을 페널티해 각 의미 피처가 배치 전반에서 하나의 통합된 잠재로 일관되게 표현되도록 유도하는 C²R(교차 샘플 일관성 정규화)을 제안한다. 종합 평가에서 C²R은 재구성 충실도를 보존하면서 분할과 흡수를 모두 완화해, 성능 저하 없이 잠재 해석가능성을 높이는 원리적 해법을 제공한다.

## 9. SurrogateShield: Beyond Redaction for High-Utility, Privacy-Preserving LLM Interactions  🆕

- **저자**: Sherwin Vishesh Jathanna
- **키워드**: `PII`, `privacy-preserving`, `surrogate substitution`, `LLM proxy`
- **출처**: arxiv recent
- **arxiv**: [2606.29567](https://arxiv.org/abs/2606.29567) (v1)
- **PDF**: [`./pdfs/2606.29567.pdf`](./pdfs/2606.29567.pdf)

**핵심 요약**:
LLM 어시스턴트는 사용자 쿼리를 그대로 제3자 API 엔드포인트로 전송하는데, 여기에 PII가 포함되면 유출·소환·정책 변경에 노출된 원격 인프라에 데이터가 남는다. 지배적 완화책인 플레이스홀더 리댁션은 PII를 억제하는 대신 의미 일관성을 해쳐 쿼리와 응답 품질을 함께 떨어뜨린다. SurrogateShield는 탐지된 PII를 로컬에서 생성한 타입 일치 대체값으로 치환해 전송하고 응답에서 원본을 복원하는 클라이언트 측 프록시로, 실제 PII가 네트워크 경계를 넘지 않게 한다. 3단계 캐스케이드(PatternScan·EntityTrace·ContextGuard)로 22종 PII와 준식별자 조합을 탐지하고, 대체-원본 매핑은 기기를 벗어나지 않는 AES-256-GCM 암호화 ShadowMap에 봉인한다. 1,124개 쿼리 평가에서 탐지 F1 98.87%를 달성하고, 대체 치환이 리댁션 대비 BERTScore를 81.59%→94.85%(+13.26pp)로 끌어올렸으며, 100쿼리 적대 시험에서 LLM 공격자가 원본 값을 하나도 복원하지 못했다.

**핵심 요약**:
ROS 2 기반 LLM 제어 로봇의 센서 파이프라인을 통해 전달되는 프롬프트 인젝션을 다중 채널로 체계적으로 실증한 첫 연구다. 4B~284B 규모의 5개 LLM(DeepSeek-V4-Flash, Llama-3-8B, Llama-3.3-70B, Qwen2.5-7B, Gemma-3n-E4B)에 인젝션 변형별 100회 독립 실행을 수행하고, 시각(OCR)·오디오(Whisper STT)·LiDAR 센서 컨텍스트 오염이라는 세 가지 감각 채널을 도입한다. 취약성은 규모가 아니라 모델별이라는 점이 드러나는데, Llama-3.3-70B는 모든 변형에서 ASR 100%인 반면 일부 소형 모델은 직접 override 인젝션에 0%로 저항했고 가장 작은 4B Gemma가 70B와 동일한 취약 프로파일을 보였다. 저자들이 제안한 하이브리드 시맨틱 방화벽은 알려진 패턴에 ASR 0%(오탐 0)를 달성하지만 적대적으로 난독화된 공격에는 10.2% 우회율을 보여 규칙 기반과 시맨틱 방어 계층 사이의 결정적 격차를 노출한다. LiDAR 채널이 로봇 환경 상태 표현에 허위 장애물 데이터를 주입하면 DeepSeek에서 ASR 100%를 기록했으며, 19개 난독화 페이로드에 걸친 방화벽 우회 분류체계도 함께 기여한다.
