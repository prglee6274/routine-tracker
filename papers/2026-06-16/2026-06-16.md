## 1. Adversarial Concept Search: Predicting Compositional Errors From Feature Geometry  🆕

- **저자**: Jennifer Meng Lu, Ruochen Zhang, Isabelle Lee, David Alvarez-Melis, Ellie Pavlick, et al.
- **키워드**: `mechanistic interpretability`, `representation geometry`, `compositionality`, `feature interference`, `failure prediction`
- **출처**: arxiv recent (cs.AI)
- **arxiv**: [2606.13934](https://arxiv.org/abs/2606.13934) (v1)
- **PDF**: [`./pdfs/2606.13934.pdf`](./pdfs/2606.13934.pdf)

**핵심 요약**:

입력을 일일이 돌려보지 않고도 LLM이 어떤 개념 조합에서 실패할지 미리 알 수 있을까? 저자들은 모델 내부의 표현 기하(representational geometry)만으로 이를 예측한다. 두 개념의 선형 인코딩 방향이 거의 직교(near-orthogonal)하면 모델이 둘을 안정적으로 합성(compose)하지만, 방향이 가까워 서로 간섭(interference)하면 합성에 실패한다는 규칙성을 발견했다. 토이 프로그래밍, 멀티홉 추론, 다국어 사실 회상 등 체계적 합성이 필요한 과제 전반에서 이 기하 기반 신호가 실제 실패 모드를 신뢰성 있게 예견함을 보였다. 특정 입력을 평가하지 않고도 고위험 사례를 식별·스트레스 테스트 구성·능동 학습에 쓸 수 있는 확장 가능한 토대를 제시한 해석성 연구다.

## 2. Compressed Computation is (probably) not Computation in Superposition  🆕

- **저자**: Jai Bhagat, Sara Molas-Medina, Giorgi Giglemiani, Stefan Heimersheim
- **키워드**: `superposition`, `compressed computation`, `mechanistic interpretability`, `toy model`, `residual stream`
- **출처**: arxiv recent (cs.LG)
- **arxiv**: [2606.14673](https://arxiv.org/abs/2606.14673) (v1)
- **PDF**: [`./pdfs/2606.14673.pdf`](./pdfs/2606.14673.pdf)

**핵심 요약**:

"50개 뉴런으로 100개 ReLU를 계산하는 것처럼 보이는" Compressed Computation(CC) 토이 모델(Braun et al., 2025)이 정말 superposition 상의 계산(computation in superposition)의 사례인지 검증한다. 저자들은 모델이 노이즈 섞인 residual stream을 통해 입력을 섞고 있으며, 이것이 레이블 쪽의 의도치 않은 mixing matrix에 대응함을 보인다. 학습 목적함수를 ReLU 항과 mixing 항으로 분리하면 성능 이득이 mixing matrix의 크기에 비례해 커지고 그 행렬을 제거하면 사라지며, 학습된 뉴런 방향이 mixing matrix 상위 50개 고유값 부분공간에 집중됨을 확인했다. mixing matrix만으로 만든 SNMF 베이스라인이 손실 곡선의 정성적 형태를 재현한다는 점까지 더해, CC는 superposition 계산의 적절한 토이 모델이 아니라고 결론짓는다. 해석성 커뮤니티의 핵심 토이 모델 해석을 정면으로 반박한 negative-result 논문이다.

WebArena 기반 실제 UI 관찰 실험에서 과제 필수 정보와 상호작용 가능성을 보존하면서 과제 무관 민감 정보 유출을 크게 줄였다.

**핵심 요약**:

프롬프트 인젝션·탈옥을 막는 LLM 가드레일의 바로 그 추론·과제수행 능력이 새로운 취약점이 된다. 공격자가 조작된 데이터를 주입해 가드레일을 장시간 추론 루프에 가둬 서비스 거부(DoS)를 일으킬 수 있다는 것이다. 저자들은 LLM 제안기와 전략 뱅크로 가드레일의 추론 길이를 극대화하는 자연어 페이로드를 만드는 beam-search 최적화 프레임워크와, 가드레일의 스키마-추종 성질을 노린 구조적 변이 기반의 더 가벼운 공격을 함께 제시한다. 단일 오픈소스 surrogate에서 최적화한 페이로드가 Claude·GPT·Gemini·DeepSeek·Qwen 등 8개 백본으로 전이되어 13~63배 토큰 증폭을, 실제 에이전트 배포(웹·데스크톱·코드·멀티에이전트)에서는 최대 148배 지연 증폭을 일으켰다. 단 하나의 오염 문서가 공유 가드레일 인프라를 포화시켜 동거 에이전트를 마비시킬 수 있음을 보이며, 비용 상한·추론 견고성을 갖춘 가드레일의 필요성을 강조한다.

- **PDF**: [`./pdfs/2606.14530.pdf`](./pdfs/2606.14530.pdf)

## 8. SMSR: Certified Defence Against Runtime Memory Poisoning in Persistent LLM Agent Systems  🆕

- **저자**: Tarun Sharma
- **키워드**: `memory poisoning`, `RAG security`, `certified defense`, `agent security`, `provenance`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.12703](https://arxiv.org/abs/2606.12703) (v1)
- **PDF**: [`./pdfs/2606.12703.pdf`](./pdfs/2606.12703.pdf)

**핵심 요약**:

세션을 넘어 누적되는 영속 메모리를 가진 RAG 에이전트는, 정상 채널로만 상호작용한 공격자가 조작된 메모리를 심어 이후 사용자의 응답을 조종하는 새로운 공격면(Multi-Session Memory Poisoning, MSMP)에 노출된다. 기존 정적 코퍼스 방어(RobustRAG 등)는 고정 지식베이스를 가정하고 휴리스틱 필터는 유창한 기업 문서풍 텍스트에 뚫린다. 저자는 이 설정에서 최초로 인증된 견고성 한계(certified robustness bound)를 갖는 방어 SMSR을 제안한다. 쓰기 시점 HMAC-SHA256 출처(provenance)로 미서명 주입을 차단(공격 성공률 93–100%→0%)하고, 질의 시점에는 무작위 메모리 절제 + 판정 기반 다수결로 인증된 공격자의 영향을 한정(단일 주입 성공률 8.0%)한다. 출처 없는 검색 시점 필터로는 적응적 주입을 인증 방어할 수 없음을 증명하고, 초기하분포 인증서와 Consistent Minority Effect를 형식화했다.

## 10. A Privacy-Preserving Framework Using Remote Data Science for Inter-Institutional Student Retention Prediction  🆕

- **저자**: John Fields, K M Sajjadul Islam, Ruchitha Thota, Victor Chen, Praveen Madiraju
- **키워드**: `privacy-preserving ML`, `remote data science`, `synthetic data`, `FERPA`, `federated alternative`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.12845](https://arxiv.org/abs/2606.12845) (v1)
- **PDF**: [`./pdfs/2606.12845.pdf`](./pdfs/2606.12845.pdf)

**핵심 요약**:

여러 대학이 민감한 학생 데이터에 직접 접근하지 않고 학생 잔존(retention)을 협력 예측할 수 있도록, PySyft 기반 프라이버시 보존 머신러닝(PPML)을 적용한 원격 데이터 과학(RDS) 프레임워크를 제안한다. high-side/low-side 서버로 구성된 준-에어갭 구조에서 세 대학 연구자가 원격으로 모델을 구축하며, 소규모 사립대 데이터(N=720)로 세 가지 합성 데이터 생성 방식을 평가했다. FERPA를 엄격히 준수하면서 기관 간 분류 성능(Macro F1 0.690–0.695)을 일관되게 유지했고, 분포 충실도보다 프라이버시를 우선하는 Data-Type-Aware Templates 합성 기법을 새로 제안한다. RDS 기반 PPML이 소규모 기관 간 협력에서 연합학습의 실용적 대안이 될 수 있음을 보였다.
