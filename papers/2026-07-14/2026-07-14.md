## 1. Statistically Undetectable Backdoors in Deep Neural Networks  🆕

- **저자**: Andrej Bogdanov, Alon Rosen, Neekon Vafa
- **키워드**: `backdoor`, `undetectable`, `cryptographic hardness`, `adversarial examples`, `power asymmetry`
- **출처**: arxiv recent
- **arxiv**: [2607.09532](https://arxiv.org/abs/2607.09532) (v1)
- **PDF**: [`./pdfs/2607.09532.pdf`](./pdfs/2607.09532.pdf)

**핵심 요약**:
악의적 학습자가 심층 피드포워드 신경망에 심을 수 있는 "통계적으로 탐지 불가능한" 백도어를 이론적으로 구성한다. 백도어가 심긴 모델과 정상 학습 모델은 전체 변분 거리(total variation distance)로 매우 가까워, 모든 가중치를 다 아는 화이트박스 상황에서도 둘을 구분할 수 없다. 이 백도어는 모든 입력에 대해 불변성 기반 적대적 예제(멀리 떨어진 입력을 비정상적으로 가까운 출력으로 매핑)를 생성하게 해주지만, 백도어 없이는 표준 암호학 가정 하에서 그런 예제를 다항 시간에 만드는 것이 증명 가능하게 불가능하다. 결과적으로 모델 학습자와 사용자 사이에 근본적인 "권력 비대칭"이 존재함을 이론·초기 실험으로 보인다.

## 2. Forget Narrowly, Retain Broadly: Unlearning as an Asymmetric Generalization Problem  🆕

- **저자**: Amit Peleg, Naman Deep Singh, Naama Pearl, Bibhabasu Mohapatra, Matthias Hein
- **키워드**: `machine unlearning`, `LLM`, `forget-retain`, `benchmark`, `JensUn++`
- **출처**: arxiv recent
- **arxiv**: [2607.09236](https://arxiv.org/abs/2607.09236) (v1)
- **PDF**: [`./pdfs/2607.09236.pdf`](./pdfs/2607.09236.pdf)

**핵심 요약**:
LLM 머신 언러닝(특정 지식만 지우고 나머지 능력은 보존)의 기존 벤치마크가 신뢰할 수 없다는 문제를 제기한다. 패러프레이즈·간접 질의에서 지식이 되살아나는 "under-forgetting"과 무관한 지식까지 손상되는 "over-forgetting"을 모두 비대칭 일반화 문제로 정식화한다 — 잊기 평가는 같은 사실의 다양한 질의 형태를 포괄해야 하고, 보존 평가는 forget 대상과 분리된 훨씬 큰 암묵적 집합을 탐침해야 한다. 이를 측정하도록 forget-retain 경계를 세밀히 주석한 평가 프로토콜·학습 코퍼스 SUITE를 제안하며, SUITE로 학습하면 성능이 크게 개선돼 학습 데이터가 알고리즘 설계만큼 중요함을 보인다. 나아가 세 LLM에서 순차·동시 언러닝 모두 최고의 forget-retain 트레이드오프를 내는 알고리즘 JensUn++를 제시한다.

## 3. Present but Rescaled: Chat-to-Agent Transfer of Additive Activation Steering  🆕

- **출처**: arxiv recent
- **arxiv**: [2607.09156](https://arxiv.org/abs/2607.09156) (v1)
- **PDF**: [`./pdfs/2607.09156.pdf`](./pdfs/2607.09156.pdf)

**핵심 요약**:
가법적 활성화 스티어링(잔차 스트림에 스케일된 방향 벡터를 주입)은 거의 단일턴 채팅에서만 보정되지만, 대상 모델은 점점 도구 사용 ReAct 에이전트로 배포된다. 저자는 동일 항목을 채팅 vs ReAct 에이전트로 렌더링한 정보 정합 설계(matched-norm 무작위 방향 대조 포함)로 채팅→에이전트 전이를 최초로 체계 분석한다. 주입된 방향은 모든 모델·설정에서 후반 레이어까지 거의 온전한 강도로 도달하지만(에이전트/채팅 비율 0.83–1.16), 행동적 결합은 모델·문맥마다 재설정되는 "해리(dissociation)"가 나타난다. 특히 거부(refusal) 우회 벡터가 어떤 모델(Gemma-2-9B)에서는 최대 2.00배 증폭되고 다른 모델(Yi-1.5-9B)에서는 감쇠(0.43)돼, 에이전트 배포가 스티어링 기반 안전성을 예측 불가능하게 만든다는 즉각적 안전 시사점을 던진다.

## 4. Not All Refusals Are Equal: How Safety Alignment Fails Cybersecurity at Scale  🆕

- **출처**: arxiv recent
- **arxiv**: [2607.02714](https://arxiv.org/abs/2607.02714) (v2)
- **PDF**: [`./pdfs/2607.02714.pdf`](./pdfs/2607.02714.pdf)

**핵심 요약**:
안전 정렬(safety alignment)은 도메인·위험 수준을 구분하지 않아, 정당하고 인가된 사이버보안 작업에서 모델이 불필요하게 제약되는 문제를 지적한다. 24개 오픈소스 LLM에 대한 대규모 abliteration 실험으로, 1T 파라미터 Kimi K2를 예로 사이버보안 도메인에 국한한 도메인 특화 abliteration이 표준 방법론으로 가능함을 보인다. 거부(refusal)가 레이어 내 다차원 부분공간뿐 아니라 레이어 전반(특히 조 단위 MoE 아키텍처)에 널리 분산돼 있음을 확인하고, 안전 학습 유형과 아키텍처가 abliteration 효과의 가장 신뢰할 만한 예측 인자임을 밝힌다. 마지막으로 모델을 3개 abliteration 취약도 등급으로 분류하고 그 원인에 대한 가설을 제시한다.

## 6. ConceptSMILE: Auditing the Trustworthiness of Concept-Based Explainable AI  🆕

- **저자**: Mohadeseh Mollapour, Koorosh Aslansefat, Zeinab Dehghani, Bhupesh Kumar Mishra, Tejal Shah, Zhibao Mian
- **키워드**: `concept-based XAI`, `auditing`, `perturbation`, `trustworthiness`, `surrogate fidelity`
- **출처**: arxiv recent
- **arxiv**: [2607.09649](https://arxiv.org/abs/2607.09649) (v1)
- **PDF**: [`./pdfs/2607.09649.pdf`](./pdfs/2607.09649.pdf)

**핵심 요약**:
개념 기반 설명가능 AI(concept-based XAI)는 모델 추론을 인간이 이해하기 쉽게 만들지만, 개념 수준 출력이 자동으로 신뢰할 만한 것은 아니다. ConceptSMILE은 개념 설명의 신뢰성을 평가하는 모델 불가지·섭동 기반 감사(auditing) 프레임워크로, 기존 SMILE의 섭동 논리를 특징·영역 귀속에서 인간 이해 가능 개념 설명의 감사로 확장한다. 입력 영역을 섭동해 개념 반응 변화를 측정하고 지역성 가중치를 적용한 뒤 XGBoost 대리 모델로 국소 개념 거동을 근사하며, 귀속 정확도·대리 충실도·faithfulness·안정성·일관성으로 신뢰성을 평가한다. 망막 안저 영상에서 MedSAM 시각 개념과 VLM 의미 개념을 비교해 신뢰성이 개념·경로마다 다름을 보이며, 개념 XAI에 독립적 감사 계층을 제공한다.

## 7. Overloading Large Vision-Language Models for Jailbreaking  🆕

- **저자**: Haoyu Zhang, Yangyang Guo, Mohan Kankanhalli
- **키워드**: `jailbreak`, `vision-language model`, `information overloading`, `multimodal attack`, `transferability`
- **출처**: arxiv recent
- **arxiv**: [2607.02961](https://arxiv.org/abs/2607.02961) (v1)
- **PDF**: [`./pdfs/2607.02961.pdf`](./pdfs/2607.02961.pdf)

**핵심 요약**:
대형 비전-언어 모델(LVLM)은 이중 모달 공격면 때문에 탈옥에 취약하지만, 기존 탈옥은 짧은 텍스트·분포 밖 이미지 등 단순 설계라 최신 LLM 백본·멀티모달 메커니즘에서 전이성이 떨어진다. 저자는 방대한 텍스트와 다차원 이미지 공격을 재귀 기반 이미지-타이포그래피 레이아웃으로 배치해 멀티모달 정보 복잡도를 지수적으로 키우는 "정보 과부하(information overloading)" 공격을 제안한다. 이 과부하가 교차 모달 처리를 증폭시켜 LVLM의 안전 정렬을 무너뜨린다. 오픈소스 평균 ASR 88.6%, 상용 LVLM 84.0%로 최고 베이스라인을 48.7%p 앞서는 새 SOTA를 달성하고, 대리 모델에서 최적화한 프롬프트가 모델 계열 간 효과적으로 전이됨을 보인다.

## 8. POPS: Recovering Unlearned Multi-Modality Knowledge in MLLMs with Prompt-Optimized Parameter Shaking  🆕

- **저자**: Zhangheng Li, Jianing Zhu, Junyuan Hong, Sungmin Eum, Shuowen Hu, Suya You et al.
- **키워드**: `machine unlearning`, `MLLM`, `recovery attack`, `prompt optimization`, `privacy robustness`
- **출처**: arxiv recent
- **arxiv**: [2607.06649](https://arxiv.org/abs/2607.06649) (v1)
- **PDF**: [`./pdfs/2607.06649.pdf`](./pdfs/2607.06649.pdf)

**핵심 요약**:
멀티모달 LLM(MLLM)은 프라이버시 민감 예제를 의도치 않게 학습할 수 있어 멀티모달 머신 언러닝(MMU)이 완화책으로 제안됐지만, 모델이 공개돼 악의적 사용자가 접근할 때의 강건성은 충분히 검증되지 않았다. 저자는 언러닝된 멀티모달 지식을 복구하는 적대적 전략 POPS(Prompt-Optimized Parameter Shaking)를 제안한다. 프롬프트 접미사 최적화로 피해 MLLM이 잠재적 프라이버시 예제를 생성하게 유도한 뒤, 그 합성 출력으로 모델을 파인튜닝해 실제 프라이버시 정보를 노출시킨다. 여러 MMU 벤치마크에서 지워졌다고 여겨진 민감 정보를 거의 완전히 복구해, 대표적 MMU 기반 프라이버시 보호의 근본적 취약성을 드러낸다.

## 9. LLMs Silently Correct African American English: Auditing and Mitigating Dialect Bias via Activation Steering  🆕

- **키워드**: `dialect bias`, `activation steering`, `auditing`, `causal tracing`, `AAE`
- **출처**: arxiv recent
- **arxiv**: [2607.06845](https://arxiv.org/abs/2607.06845) (v1)
- **PDF**: [`./pdfs/2607.06845.pdf`](./pdfs/2607.06845.pdf)

**핵심 요약**:
3천만 명 이상이 쓰는 규칙 지배적 방언인 아프리카계 미국 영어(AAE)를 LLM이 일상적으로 오해·"교정"하는 문제를 다룬다. 14B~70B 6개 instruction-tuned LLM에서, 앞 문맥이 AAE여도 모델이 체계적으로 표준 미국 영어(SAE) 연속을 선호해 AAE를 SAE로 재작성함을 보인다. 감사(auditing)를 위해 번역기 유발 아티팩트에서 진짜 모델 편향을 분리하는 조건부 방언군 불변성(cDGI)과 특징 수준 국소화 분석을 도입해, 부정 일치("ain't nobody") 같은 통사 구성이 모든 모델의 보편적 트리거임을 찾는다. 완화책으로는 인과 추적으로 방언 방향을 추출해 편향 관련 레이어에 주입하는 활성화 스티어링을 방언 편향에 최초 적용해, 프롬프팅보다 5~20배 큰 편향 감소를 SAE 유창성을 보존하며 달성한다(17,479쌍 REAL-AAE 코퍼스 공개).

## 10. Knowledge Base Poisoning Attacks and Defense for Policy-Aware LLM-RAG Framework  🆕

- **저자**: Om Solanki, Lopamudra Praharaj, Deepti Gupta, Maanak Gupta
- **키워드**: `RAG poisoning`, `knowledge base`, `retrieval`, `LLM-RAG`, `defense mechanism`
- **출처**: arxiv recent
- **arxiv**: [2607.04379](https://arxiv.org/abs/2607.04379) (v1)
- **PDF**: [`./pdfs/2607.04379.pdf`](./pdfs/2607.04379.pdf)

**핵심 요약**:
전장 사물인터넷(IoBT) 임무 통제용 정책 인식 LLM-RAG(PA-LLM-RAG) 프레임워크의 적대적 보안을 연구한다. 런타임 프롬프트를 몰라도 모든 질의 유형에서 높은 검색 순위를 얻도록 의미적으로 조작한 규칙을 지식베이스에 주입하는 Query-Agnostic Semantic Retrieval Poisoning 공격을 제안한다. 단일 규칙 주입(1.6% 오염률)만으로 LLM 문맥의 85%를 손상시키고 7.7%에서 포화돼, 최소한의 지식베이스 훼손으로도 임무 결정을 오염시킬 수 있음을 보인다. 방어책으로 One-Class SVM 경계 탐지와 새로운 멤버 기반 범주 확산(Member-Based Category Spread) 분석을 결합한 이중 탐지기 CLD-KB를 제안해, DBSCAN·LOF·K-Means·Isolation Forest 등 5개 베이스라인을 능가하며 임무당 7ms 오버헤드로 엣지 배포 가능한 방어를 제시한다.
