## 1. AutoDojo: Adaptive Attacks Expose Superficial Defenses and User-Underspecification Limits in LLM Agents  🆕

- **저자**: Xinhang Ma, Taoran Li, Chaowei Xiao, Zhiyuan Yu, Ning Zhang, Yevgeniy Vorobeychik
- **키워드**: `indirect prompt injection`, `LLM agent`, `adaptive attack`, `agent safety`
- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.15057](https://arxiv.org/abs/2606.15057) (v1)
- **PDF**: [`./pdfs/2606.15057.pdf`](./pdfs/2606.15057.pdf)

**핵심 요약**:
간접 프롬프트 인젝션(IPI) 방어를 평가하는 AgentDojo 같은 벤치마크는 공격 분포가 고정된 정적 벤치라, 적응형 공격에 대한 방어 견고성을 제대로 측정하지 못한다는 문제를 제기한다. 저자들은 주어진 방어에 맞춰 인젝션을 최적화하는 적응형 확장판 AutoDojo를 만들어, 프론티어 LLM으로 저비용 블랙박스 공격을 반복 최적화한다. 정적 공격을 0%로 막는 필터에 대해서도 AutoDojo는 전체 28%, action-open 작업에서는 64%까지 공격 성공률(ASR)을 회복시킨다. 특히 사용자가 행위 자체를 공격자 통제 콘텐츠에 위임하는 "action-open" 작업에서는 인젝션이 명시적 지시문이 아닌 평범한 데이터로 위장할 수 있어 탐지 기반 방어를 구조적으로 우회한다는 점을 보인다.

## 2. PreUnlearn: Auditing Collateral Knowledge Damage Before Large Language Model Unlearning  🆕

- **저자**: Bo Su, Ankit Shah, Thai Le
- **키워드**: `machine unlearning`, `collateral damage`, `forget-set auditing`, `data-centric`
- **출처**: arxiv recent (cs.CL)
- **arxiv**: [2606.18473](https://arxiv.org/abs/2606.18473) (v1)
- **PDF**: [`./pdfs/2606.18473.pdf`](./pdfs/2606.18473.pdf)

**핵심 요약**:
LLM 언러닝은 특정 지식만 제거하고 나머지 능력은 보존하려 하지만, 잊을 지식과 남길 지식의 경계가 모호해 관련·원거리 지식까지 얽혀 손상되는 문제가 있다. 저자들은 데이터 중심 관점에서 언러닝의 부수 피해가 forget set에서 어떻게 전파되는지 측정해, 손상이 forget set 근처에서 가장 강하고 의미 거리가 멀어질수록 약해지지만 도메인 경계에서도 사라지지 않는 일관된 감쇠 패턴을 발견한다. 나아가 언러닝 실행 전에 이 손상을 예측·감사할 수 있는지를 "사전 예측 과제"로 정식화하고, forget set과 평가 set 사이의 상호작용 피처가 다운스트림 손상을 가장 잘 예측함을 보인다. 즉 부수 피해가 모델 업데이트 이전 데이터 기하 구조에 이미 부분적으로 반영돼 있어, 위험한 언러닝 실행을 조기 경보하는 도구로 활용할 수 있다.

- **PDF**: [`./pdfs/2606.19603.pdf`](./pdfs/2606.19603.pdf)

**핵심 요약**:

Qwen3-Embedding-0.6B·BGE-M3에서 세 벤치마크로 평가해 악성 문서를 검색 결과에 대거 끌어올리며 배치 단위 공격이 가능함을 보였고, 대부분 RAG가 오픈소스 리트리버 위에 구축된다는 점에서 실질적 공격면을 드러낸다.

- **출처**: arxiv recent (cs.CR)
- **arxiv**: [2606.20470](https://arxiv.org/abs/2606.20470) (v1)
- **PDF**: [`./pdfs/2606.20470.pdf`](./pdfs/2606.20470.pdf)

**핵심 요약**:
에이전트형 AI가 지시 해석·외부 데이터 처리·툴 호출·에이전트 협업에 언어모델을 쓰면서, 공격자가 모델로 프로빙·프롬프트 정제·응답 평가를 자동화·확장할 수 있게 돼 프롬프트 인젝션·탈옥의 파급력이 커졌다. 저자들은 대상 시스템·방어·공격자의 자동 심판을 확률 모형으로 분석해, 통상적인 "탐지-차단" 방어는 예측 가능한 거절이 자동 탐색에 유용한 피드백을 주기 때문에 질의 예산이 커질수록 공격 성공률이 1에 근접할 수 있음을 보인다. 대안으로 탐지된 악성 상호작용에 비작동성의 통제된 응답을 줘 공격자 심판의 위양성을 유도하는 "탐지-오도(detect-and-misdirect)"를 제시하며, 이는 공격자 선택 후보의 양성 예측도를 낮춰 ASR 상한을 유계화한다. 개념 증명 CMPE는 탈옥 벤치마크에서 ASR 상한을 최대 두 자릿수(10²배) 낮추고 PAIR·GPTFuzz 종단 공격에서 검증된 성공을 거의 제거한다.

LLM은 강력하지만 적대적 프롬프트 공격에 취약해 안전성이 핵심 우려로 남아 있다. 저자들은 방어 지향 관점에서 효과적인 블랙박스 공격 프롬프트를 체계적으로 구성하는 적대 테스트 프레임워크 UNIATTACK을 제시한다. 정적 템플릿이나 모델별 반복 튜닝에 의존하던 선행 기법과 달리, 다양한 기존 공격에서 최소하지만 고임팩트한 공격 피처를 추출해 전용 공격자 LLM으로 최적화하고 자동 정제로 유연한 템플릿에 조합한다. 이 피처 중심 구성은 여러 모델·안전 범주에 일반화되는 원샷 공격을 가능케 하며, 다층 방어가 적용된 모델에서 베이스라인 대비 평균 ASR을 64.63%~248.82% 끌어올리면서 비용은 베이스라인의 0.03%~4.96%에 불과하다.
