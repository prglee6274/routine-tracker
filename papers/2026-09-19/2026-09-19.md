## 1. Red-Teaming Auto Mode: Improving Blocking Classifiers Against Malign Coding Agents  🆕

- **저자**: Alex Remedios, Simon Storf, Fabien Roger, John Hughes
- **키워드**: `red-teaming`, `blocking monitor`, `coding agent`, `misaligned agent`, `weight exfiltration`
- **출처**: arxiv recent
- **arxiv**: [2609.19587](https://arxiv.org/abs/2609.19587) (v1)
- **PDF**: [`./pdfs/2609.19587.pdf`](./pdfs/2609.19587.pdf)

**핵심 요약**:

코딩 에이전트를 제어하는 프로덕션 방어선은 이제 행동 하나하나를 실행 전에 심사하는 blocking monitor다 (Claude Code의 Auto Mode, OpenAI Codex의 Guardian). 기존 평가는 우발적 피해나 외부에서 들어온 prompt injection 정도만 다뤘고, **감시받는 에이전트 자신이 지속적으로 misaligned 한 경우**는 거의 연구되지 않았다. 저자들은 적대적 에이전트에게 모니터를 우회하고 자기 가중치 탈취 같은 치명적 피해를 일으키라는 과제를 주고, 고수준 공격 전략만 알려줘도 여러 경로로 성공함을 보였다 — 에이전트가 스스로 생성한 모니터 대상 prompt injection, 다중 에이전트 공격, 악성 compaction 등. 특히 **시도의 79%에서 injection 공격으로 Auto Mode와 Guardian을 뚫고 임의 bash 명령을 실행**시킬 수 있었다. 툴 커버리지 확대·트랜스크립트 포맷 개선·에이전틱 모니터 단계 추가로 Auto Mode를 크게 개선할 수 있었지만, 여러 컨텍스트에 걸친 multi-context 공격을 감당 가능한 비용으로 막는 것은 여전히 미해결 과제로 남았다.

## 2. Decodability is Not Causality: Dissociating Probe Readouts from Behavioral Drivers via SAE Decomposition  🆕

- **저자**: Devesh Tiwari, Camille Davis, Shivank Sinha, Talia Weaver, Aditya Shah, et al.
- **키워드**: `sparse autoencoder`, `linear probe`, `causal intervention`, `decodability`, `truthfulness`
- **출처**: arxiv recent
- **arxiv**: [2609.18080](https://arxiv.org/abs/2609.18080) (v1)
- **PDF**: [`./pdfs/2609.18080.pdf`](./pdfs/2609.18080.pdf)

**핵심 요약**:

선형 probe로 truthfulness 같은 안전 관련 개념을 활성값에서 읽어낼 수 있다는 사실은 그 개념이 **디코딩 가능하다**는 것만 말해줄 뿐, probe가 가리키는 feature가 실제로 모델 행동을 인과적으로 구동한다는 뜻은 아니다. 저자들은 probe 가중치의 기하학만으로는 이 간극을 메울 수 없음을 보인다 — probe 방향과 기하학적으로 정렬된 feature가 모델이 실제로 쓰는 feature일 필요가 없기 때문에, 인과성 판정에는 개입(intervention)이 필수다. 이들은 배포된 True/False probe를 SAE feature로 분해한 뒤 (a) probe 정렬도와 (b) 모델 행동에 대한 gradient 민감도 두 축으로 순위를 매기고, 공유/probe-only/무작위 feature 집합을 coherence gate 하에서 ablation 하는 진단법을 제안한다. Gemma2-9B-Instruct의 TTPD truth probe에서 두 순위의 겹침은 약 12% (Spearman ρ=0.10)에 불과했고, ablation 결과는 뚜렷이 갈렸다 — 공유 feature는 출력을 최대 27% 뒤집은 반면 probe-only는 6%, 무작위는 1%에 그쳤다. 활성값 통계를 함께 쓴 선택은 probe의 기하학적 상위 feature보다 약 3배 자주 행동을 뒤집었다 (17.6% vs 6.1%).

## 3. Inference-Engine Fingerprinting Attacks are Practical: Exploring Model-Driven Environmental Discovery, Exploitation, and Escape  🆕

- **저자**: Sarah Radway, Andrew Cheng, Vijay Janapa Reddi, James Mickens
- **키워드**: `inference engine`, `sandbox escape`, `fingerprinting`, `vLLM`, `model-driven exploitation`
- **출처**: arxiv recent
- **arxiv**: [2609.20614](https://arxiv.org/abs/2609.20614) (v1)
- **PDF**: [`./pdfs/2609.20614.pdf`](./pdfs/2609.20614.pdf)

**핵심 요약**:

프론티어 모델이 복잡한 소프트웨어의 취약점을 실제로 익스플로잇하는 능력을 갖추기 시작했고 (OpenAI·Anthropic에서 관측된 샌드박스 탈출이 그 증거), 그런데 추론 스택 샌드박싱 논의는 네트워크 프록시나 코드 실행 환경 같은 **주변** 컴포넌트에 집중돼 왔다. 저자들은 정작 **추론 엔진 자체**가 misaligned 모델에게 가장 매력적인 표적이라고 지적한다 — 모델이 특수하게 조작된 출력 토큰을 생성하는 것만으로 엔진의 익스플로잇을 유발할 수 있다면, 외부 악성 입력이나 다른 컴포넌트의 취약점 없이도 베어메탈까지 내려가는 다단계 익스플로잇 체인을 스스로 개시할 수 있다. 논문은 모델이 자신을 실행 중인 엔진(vLLM, SGLang 등)을 식별하는 **inference-engine fingerprinting**이 실제로 가능함을 보이고, 5개 주요 엔진의 구체적 지문과 현실적인 에이전틱 하네스에서 이를 활용해 로컬 엔진을 특정하는 과정을 제시한다. 나아가 지문 인식 후 엔진을 장악해 베어메탈까지 이어지는 PoC 익스플로잇 체인을 기술하고, fingerprinting을 어렵게 만들 엔진 설계 변경안들로 마무리한다.

## 4. Local Sparsity Enables Unsupervised LLM Safety Detection  🆕

- **저자**: Xin Chen, Gil Kur, Alexander Shevchenko, Andreas Krause
- **키워드**: `linear representation hypothesis`, `anomaly detection`, `local sparsity`, `unsupervised safety`, `activations`
- **출처**: arxiv recent
- **arxiv**: [2609.20129](https://arxiv.org/abs/2609.20129) (v1)
- **PDF**: [`./pdfs/2609.20129.pdf`](./pdfs/2609.20129.pdf)

**핵심 요약**:

배포 시점 LLM 안전 장치는 대부분 지도학습 기반이라 unsafe 학습 데이터 접근을 전제하는데, 새로운 공격과 피해 유형은 계속 생겨나 그 분포에 잡히지 않는다. 대안은 이 문제를 **이상 탐지**로 보는 것 — safe 데이터만 모델링하고 OOD 입력을 플래그하는 방식이다. 문제는 LLM 활성값이 고차원 공간에 놓여 있어 이상 탐지가 통계적으로 가능하기나 한지 의심스럽다는 점. 저자들은 **선형 표현 가설(LRH)** 하에서는 희망이 있음을 보인다: SAE로 복원되는 LRH 개념 공간에서는 가까운 점들이 작은 공통 활성 support 를 공유한다는 **local sparsity** 성질이 성립한다. 이 통찰로 locally masked SAE 기반 이상 탐지 프레임워크를 제안하고 이론적 근거를 붙였으며, 다양한 아키텍처·데이터셋(역량 테스트 + 안전 전용)에서 검증했다. OOD 데이터 1%만 캘리브레이션에 허용하면 SAE 뉴런의 1–2%만 계산에 쓰고도 거의 최적 성능에 도달했다.

## 5. PACT: Can Enterprise AI Assistants Be Trusted Under Pressure?  🆕

- **저자**: Mika Okamoto, Ansel Kaplan Erol
- **키워드**: `compliance`, `pressure testing`, `enterprise agents`, `rule following`, `benchmark`
- **출처**: HF Daily
- **arxiv**: [2609.18605](https://arxiv.org/abs/2609.18605) (v1)
- **PDF**: [`./pdfs/2609.18605.pdf`](./pdfs/2609.18605.pdf)

**핵심 요약**:

채용·의료·금융처럼 민감한 맥락에 엔터프라이즈 LLM 에이전트가 배포되면서, 시스템 컨텍스트에 명시된 규칙 준수는 일차적인 법적 관심사가 됐다. 그런데 **어떤 모델이, 특히 끈질긴 사용자나 급한 관리자의 압박 아래서 규칙을 어기는지**를 체계적으로 재는 평가 틀은 없었다. PACT(Pressure-Applied Compliance Testing)는 12개 규제 도메인·48개 시나리오의 현실적 멀티턴 대화로 구성된 벤치마크로, 각 항목이 지켜야 할 규칙과 그것을 어기는 편법을 짝지어 놓고 다양한 표현·시스템 프롬프트 모드로 압박을 가한다. 평가 인지(evaluation-aware) 행동을 유발하지 않도록 LLM-as-judge 감사를 거쳐 모호하지 않고 게임 불가능하게 구성했다. 22개 모델 프로파일링 결과 준수도는 모델·지표별로 편차가 컸고, **가장 강한 어시스턴트조차 항목의 6–10%에서 규칙 적용을 틀렸으며, 평범한 사용자 압박만으로 위반율이 평균 65% 상승**했다.

## 6. Towards TEE-Certified DP: Verifiable Differentially Private Training on Legacy GPUs  🆕

- **저자**: Li Ge, Wenjie Qu, Weitao Feng, Yi Zeng, Jiaheng Zhang, et al.
- **키워드**: `differential privacy`, `TEE`, `verifiable training`, `GPU`, `DP-SGD certification`
- **출처**: arxiv recent
- **arxiv**: [2609.20532](https://arxiv.org/abs/2609.20532) (v1)
- **PDF**: [`./pdfs/2609.20532.pdf`](./pdfs/2609.20532.pdf)

**핵심 요약**:

DP가 규제 대응의 핵심 수단으로 자리잡았지만, **학습 과정에서 DP가 정말로 충실히 집행됐는지 외부 검증자가 확인하는 문제**는 덜 다뤄졌다 — 검증자는 비공개 학습 데이터에 접근하지 않고도 이를 확인할 수 있어야 한다. 영지식 증명 같은 암호학적 접근은 보장은 강하나 오버헤드가 수십~수백 배로 비현실적이고, TEE는 효율적이지만 LLM 학습·파인튜닝에 필요한 멀티 GPU TEE 지원이 최신 플랫폼에만 있고 레거시 GPU에는 없거나 비효율적이다. 저자들은 **CPU 측 TEE + 신뢰하지 않는 GPU** 조합의 검증 가능한 DP 학습 프레임워크를 제안한다: 비싼 gradient 계산은 GPU로 오프로드하되, CPU TEE가 확률적 검사로 gradient에 DP가 제대로 적용됐는지를 효율적으로 검증한다. 전면적 DP 이탈은 높은 확률로 탐지되고, 실험에서 다룬 효용 목적의 forged-gradient 공격의 경우 희소한 이탈은 효용 이득이 제한적이며 측정 가능한 추가 멤버십 누출도 없었다. 표준 GPU DP 학습 대비 오버헤드가 크지 않아 사실상 "공짜 점심"에 가깝다는 것이 실험 결론이다.

## 7. Latent Undertow: How Ordinary Typos Break Probes  🆕

- **저자**: Elad David, Max Fomin, Amit LeVi
- **키워드**: `probe robustness`, `typos`, `prompt injection probe`, `hidden states`, `distribution shift`
- **출처**: arxiv recent
- **arxiv**: [2609.15994](https://arxiv.org/abs/2609.15994) (v1)
- **PDF**: [`./pdfs/2609.15994.pdf`](./pdfs/2609.15994.pdf)

**핵심 요약**:

LLM은 오타나 구두점 누락 같은 일상적 입력 변형을 매끄럽게 처리해 사용자 의도도 응답도 실질적으로 달라지지 않는다. 그런데 hidden state 를 읽어 악성 프롬프트를 탐지하는 **probe 는 전혀 다른 이야기를 한다** — 같은 편집이 해당 토큰 위치에서 readout 벡터를 43–56도 회전시키고, 그 효과는 이후 약 10 토큰 안에 15% 아래로 감쇠한다. 메시지당 흔한 오타 3개만 쌓아도 단일 위치 prompt-injection probe 의 TPR@FPR=1% 가 12.0pp 떨어지며, 이는 재보정만으로는 메울 수 없는 간극이다. 다중 위치 집계는 국소적 교란은 거의 해결하지만(≤0.5 손실) 분산된 교란에는 attention·max 기반 집계기도 약 3.8pp 하락한다. 저자들은 단일 위치 probe 를 위해 **KV-cache fork** 를 제안한다 — 사용자 메시지 뒤에 짧은 고정 접미사를 붙여 probe 가 교란 지점보다 몇 토큰 뒤를 읽게 함으로써 위 감쇠 특성을 역이용하는 방식으로, 간극의 95%를 메워(잔차 -0.6pp) 교란 증강 학습(-3.7pp)보다 한 자릿수 우수했다. 회전-감쇠 기하는 Llama-3.1-8B, Qwen3-8B, Gemma-4-E4B에서 재현된다.

Cascade 는 대상 지식의 내부 식별 가능성 자체를 최소화하는 계층적 recoverability 제어 프레임워크로, 세 가지 통제를 결합한다 — 프라이버시 연관 활성 경로를 억제하는 **경로 수준 라우팅**, 기하학적 분리 가능성을 낮추는 **표현 수준 압축**, 잔여 복원을 제한하는 **디코딩 수준 개입**. TOFU·MUSE-News·WMDP 에서, 그리고 질의 재구성과 추출형 프롬프트를 쓴 강건성 테스트에서 모델 효용을 안정적으로 유지하면서 복원 가능성을 효과적으로 낮췄다. EMNLP 2026 Findings 채택.

## 9. ActGuard: Pre-execution Action Auditing against Indirect Prompt Injection in LLM Agents  🆕

- **저자**: Bingzheng Wang, Xiaoyan Gu, Wentao Wang, Xingyou Yang, Hongcheng Li, et al.
- **키워드**: `indirect prompt injection`, `LLM agents`, `action auditing`, `tool invocation`, `pre-execution defense`
- **출처**: arxiv recent
- **arxiv**: [2609.14987](https://arxiv.org/abs/2609.14987) (v1)
- **PDF**: [`./pdfs/2609.14987.pdf`](./pdfs/2609.14987.pdf)

**핵심 요약**:

LLM 에이전트는 툴 호출로 외부 환경과 상호작용하는데, 그 툴 출력이 곧 간접 프롬프트 인젝션(IPI)의 통로가 된다. 기존 방어는 프롬프트 강화·콘텐츠 필터링·사전 생성 계획·권한 제약에 기대는데, 복잡한 과제에서 무너지거나 외부 콘텐츠를 과도하게 정제해 보안과 효용의 균형을 못 맞춘다. ActGuard 의 발상 전환은 "이 외부 콘텐츠가 본질적으로 수상한가"를 묻는 대신 **"이 콘텐츠 때문에 지금 행동이 국소적으로 타당한 기대에서 벗어나는가"**를 묻는 것이다. 매 스텝에서 다음 행동이 쓸 법한 툴을 예측해 실행 궤적을 구속하지 않는 local tool prior 를 만들고, 실행 직전 후보 행동을 이 prior 와 대조해 툴 수준 대조 분석과 파라미터 수준 증거 국소화로 이탈을 찾는다. 검증기가 국소화된 증거를 검토해 **악성으로 확인된 span 만 마스킹**하고 정제된 컨텍스트에서 행동을 재생성한다. 툴 사용 에이전트 벤치마크에서 공격 성공률을 SOTA 방어 수준으로 낮추면서 과제 효용은 무공격 설정에 가깝게 유지했다.

## 10. Tight Lower Bounds for Differentially Private Continual Counting  🆕

- **저자**: Charlie Harrison, Ethan Leeman
- **키워드**: `differential privacy`, `continual counting`, `binary tree mechanism`, `lower bounds`, `streaming`
- **출처**: arxiv recent
- **arxiv**: [2609.17650](https://arxiv.org/abs/2609.17650) (v1)
- **PDF**: [`./pdfs/2609.17650.pdf`](./pdfs/2609.17650.pdf)

**핵심 요약**:

Binary Tree Mechanism 은 차분 프라이버시 하 continual counting 의 표준 알고리즘이지만, **pure DP 에서 점근적으로 최적인지는 도입 이래 미해결**이었다. 이 논문이 그 질문을 닫는다. 고정된 0 < ε ≤ 1 에 대해 최악 기대 ℓ∞ 오차의 Ω(log²n), 좌표별 기대 제곱오차의 평균/최대에 대한 Ω(log³n) 하한을 증명했고, 이 하한은 스트림 전체를 미리 알고 있는 임의의 메커니즘에도 성립한다. 같은 하한이 임의의 고정 c > 0 에 대해 δ ≤ n^(-c) 인 approximate DP 에서도 유지된다. 이 하한들이 Laplace 노이즈를 쓴 Binary Tree Mechanism 의 성능과 일치하므로, δ ≪ 1/n 인 표준 영역에서 해당 메커니즘의 **점근적 최적성이 pure/approximate DP 양쪽에서 확립**된다. 증명은 트리 위에 유계 지수 점수를 갖는 단일 hard distribution 하나만 쓰며, 점수를 조금만 바꾸면 같은 틀로 세 오차 척도 모두의 tight 하한을 얻는다.
