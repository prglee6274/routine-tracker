## 1. SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection  🆕

- **저자**: Woosang Lim, Yeseul Chang, Jaewoo Lee
- **키워드**: `prompt injection`, `tool-using agents`, `typed fields`, `deterministic sanitizer`
- **출처**: arxiv recent
- **arxiv**: [2611.07222](https://arxiv.org/abs/2611.07222) (v1)
- **PDF**: [`./pdfs/2611.07222.pdf`](./pdfs/2611.07222.pdf)

**핵심 요약**:
툴을 쓰는 에이전트는 웹페이지·문서에 숨은 지시 때문에 메일/결제 대상이 공격자 쪽으로 바뀔 수 있고, 기존 런타임 방어는 허용 여부 판단에 LLM을 끼워 넣어 공격 텍스트에 의존하거나 호출 비용이 늘어난다. SPILLWAY는 행동 대상 값(수신자·계좌)이 읽기 전용 툴의 타입 필드로 반환됐거나 고정 위임 규칙에 포함될 때만 호출을 허용하는 결정론적 하한선과, 지시문처럼 보이는 영역을 사전에 제거하는 sanitizer를 결합한다. 3개 백본과 7개 태스크 스위트에서 표준 템플릿 인젝션은 공격자 대상으로 행동을 돌리지 못했고, RL 공격자에 대해서도 평균 ASR이 0.007이며 추가 모델 호출은 거의 없다.

## 2. The Long Con on the Web: Earn-then-Exploit Fraud Attacks against Coding Agents  🆕

- **저자**: Xingling Xu, Zhengwei Jiang, Zheng Zhi, Fangming Dong, LingJia Guo et al.
- **키워드**: `coding agents`, `web fraud`, `trust exploitation`, `action authorization separation`
- **출처**: arxiv recent
- **arxiv**: [2611.00725](https://arxiv.org/abs/2611.00725) (v1)
- **PDF**: [`./pdfs/2611.00725.pdf`](./pdfs/2611.00725.pdf)

**핵심 요약**:
코딩 에이전트가 웹 접근과 높은 권한을 갖게 되면서, 악성 사이트가 먼저 검증 가능한 도움을 여러 번 제공해 신뢰를 쌓은 뒤 권한 경계를 넘는 지시를 내리는 'Earn-then-Exploit(EtE)' 사기 공격을 제안한다. 56개 조직 환경에서 3개 코딩 에이전트를 평가해 평균 시나리오 단위 공격 성공률 71.4%(Codex-GPT-5.5 85.7%)로 기존 인젝션 baseline을 크게 능가했고, 에이전트가 과거에 도움이 된 웹 출처에 신뢰 비슷한 의존을 보임을 확인했다. 방어로 웹 콘텐츠가 특권 행동을 직접 승인하지 못하게 하는 action-authorization separation(AAS)을 제안, 작업 완료율 100%를 유지하며 ASR을 0%로 낮췄다.

## 3. MemHarmBench: Evaluating Cross-Session Prompt Injection in Memory-Persistent AI Agents  🆕

- **저자**: Zhihua Wang, Yunhao Feng, Yifeng Gao, Rui Pan, Baiheng Zhao et al.
- **키워드**: `cross-session prompt injection`, `agent memory`, `benchmark`, `victim-centric`
- **출처**: arxiv recent
- **arxiv**: [2611.01700](https://arxiv.org/abs/2611.01700) (v1)
- **PDF**: [`./pdfs/2611.01700.pdf`](./pdfs/2611.01700.pdf)

**핵심 요약**:
영속 메모리를 쓰는 에이전트는 메시지·문서·웹의 악성 지시가 메모리에 저장되어 원본이 사라진 뒤에도 이후 작업에 영향을 줄 수 있는데, 기존 공격 성공률 지표는 누가 어떤 피해를 입는지 담지 못한다. MemHarmBench는 사용자·워크스페이스 소유자·외부 이해관계자라는 세 부류의 피해자를 기준으로, 악성 지시 노출→메모리 보존 여부 확인→공격 콘텐츠 제거 후 정상 작업 수행의 흐름으로 교차 세션 인젝션을 평가한다. 여러 에이전트 시스템에서 에이전트가 정상적으로 작업을 끝내면서도 눈에 띄는 이상 징후 없이 공격자 의도에 맞는 핵심 결정을 내리는 은밀한 공격이 가능함을 보였고, 벤치마크를 공개했다.

## 4. JailBound: FOL-Guided Jailbreak Evaluation for Exploring LLM Behavioral Boundaries  🆕

- **저자**: Fazong Wu, Xin Wang, Ming Yang, Zhenyong Zhang, Xiaoming Wu
- **키워드**: `jailbreak evaluation`, `first-order loss`, `benchmark construction`, `behavioral boundary`
- **출처**: arxiv recent
- **arxiv**: [2611.07530](https://arxiv.org/abs/2611.07530) (v1)
- **PDF**: [`./pdfs/2611.07530.pdf`](./pdfs/2611.07530.pdf)

**핵심 요약**:
기존 탈옥 벤치마크는 수작업 프롬프트에 의존해 새 위협 조건으로 확장하기 어렵고, ASR 최적화 중심 공격은 안전 거절과 위험 응답 경계에서 모델 행동이 어떻게 바뀌는지 알려주지 못한다. JailBound는 위험 범주·응용 도메인·공격 유형 분류 체계 위에서 파인튜닝된 메타 공격 생성기로 평가 프롬프트를 만들고, first-order loss(FOL)를 국소 민감도 신호로 쓰는 이중 분기 탐색으로 고가치 공격 상태와 행동 민감 상태를 찾는다. 13개 모델 계열 46개 LLM을 평가해 High-Value 분기가 ZOL 단독 baseline 대비 평균 ASR을 약 5%p 높였고, Safety-Sensitivity 분기 상태가 국소 섭동에서 더 높은 행동 전환율을 보였다.

- **출처**: arxiv recent
- **arxiv**: [2611.07756](https://arxiv.org/abs/2611.07756) (v1)
- **PDF**: [`./pdfs/2611.07756.pdf`](./pdfs/2611.07756.pdf)

**핵심 요약**:
SAE 학습에서는 활성값 저장이 병목인데, 총 학습 예산이 고정일 때 고유 활성값이 얼마나 필요한지를 조사한다. 버퍼 크기를 늘리면 품질이 빠르게 오르다 plateau에 도달하고, 그 이후엔 버퍼를 재사용해도 신선한 활성값을 쓰는 것과 거의 차이가 없다는 점을 보이며 다양성-반복 트레이드오프를 제한 데이터 스케일링 법칙으로 기술한다. Llama-3.1, Qwen3 여러 크기와 BatchTopK/TopK/JumpReLU SAE, 여러 레이어에서 설명 분산·재구성 MSE·feature absorption·자동 해석·sparse probing으로 검증했다. 결과적으로 plateau에 닿는 가장 작은 버퍼를 재생하면 품질 손실 거의 없이 활성값 저장을 8-64배 줄일 수 있다.

- **arxiv**: [2611.08089](https://arxiv.org/abs/2611.08089) (v1)
- **PDF**: [`./pdfs/2611.08089.pdf`](./pdfs/2611.08089.pdf)

**핵심 요약**:
MoE 전문가가 각각 무엇을 담당하는지는 기존에 도메인 라벨 코퍼스에서 선택 빈도를 세는 방식으로만 분석되어 거칠고 기여가 아닌 선택만 기록했다. 이 논문은 MoE 레이어 출력(라우터 가중합)에 SAE를 학습시키면 SAE 인코더가 아핀이므로 각 latent의 pre-activation이 전문가별로 정확히 분해된다는 점을 이용해 전문가별 지배 latent 집합을 얻는다. Qwen3-30B-A3B의 4/30/46번 레이어에서 기여가 게이팅보다 훨씬 집중되고 대부분의 latent는 1-2개 전문가가 지배하며, 자동 해석 결과 Java와 프런트엔드 웹 코드, 기하와 산술·다항식처럼 도메인 아래 수준의 세분화된 분업이 드러난다.

## 8. An Information Bottleneck for Post-hoc Memorization Mitigation in LLMs  🆕

- **출처**: arxiv recent
- **arxiv**: [2611.07669](https://arxiv.org/abs/2611.07669) (v1)
- **PDF**: [`./pdfs/2611.07669.pdf`](./pdfs/2611.07669.pdf)

**핵심 요약**:
LLM이 저작권 학습 데이터를 암기·재생산하는 문제가 프라이버시와 지식재산 이슈를 낳는데, 모델을 재학습하거나 수정하지 않고 완화할 수 있는지를 묻는다. 동결된 LLM 백본과 LM head 사이에 비모수 변분 정보 병목(NVIB)을 끼우는 모듈형 plug-and-play 프레임워크로, 최종 은닉 표현을 압축해 일반 언어 지식은 보존하고 특정 암기 시퀀스는 걸러내도록 한다. 책 구절 추출 과제와 표준 언어 모델링 벤치마크에서 추출 가능성은 크게 줄고 다운스트림 성능은 경쟁력 있게 유지되어, 아키텍처에 무관한 사후 암기 완화 방향을 제시한다.

## 9. Sample-Grained Approximate Unlearning with Provable Per-Sample Bounds  🆕

- **저자**: Yaxin Xiao, Yulin Jin, Li Tang, Haoyang LI, Huadi Zheng et al.
- **키워드**: `machine unlearning`, `approximate unlearning`, `per-sample guarantee`, `SALA`
- **출처**: arxiv recent
- **arxiv**: [2611.04501](https://arxiv.org/abs/2611.04501) (v2)
- **PDF**: [`./pdfs/2611.04501.pdf`](./pdfs/2611.04501.pdf)

**핵심 요약**:
근사 unlearning은 대개 데이터셋 수준 집계 지표로 평가되어 재학습 대비 개별 샘플 수준의 편차를 가린다. 이 논문은 각 샘플을 올바른 목표 분포로 유도하는 플러그인 최적화 프레임워크 SALA(Sample-grained Likelihoods ALignment)와, 근사 unlearning과 정확한 재학습 출력 분포의 샘플별 차이를 재는 sample-grained distribution gap 지표를 제안한다. 이 gap을 수축시키고 재학습 대비 샘플별 불일치를 유계로 만든다는 이론 보장을 제공하며, 멤버/비멤버 목표 분포의 저비용 추정법도 개발했다. 분류·생성 과제에서 기존 baseline과 결합 시 gap을 최대 86.67% 줄이고 하이퍼파라미터 강건성도 개선했다.

## 10. A Novel Federated Learning Framework for Defending Against Gradient Inversion Attacks  🆕

- **저자**: Pengxin Guo, Ziying Huang, Shuang Zeng, Xiaodan Zhang, Weihong Ren et al.
- **키워드**: `federated learning`, `gradient inversion attack`, `hypernetwork`, `HyperFL++`
- **출처**: arxiv recent
- **arxiv**: [2611.02412](https://arxiv.org/abs/2611.02412) (v1)
- **PDF**: [`./pdfs/2611.02412.pdf`](./pdfs/2611.02412.pdf)

**핵심 요약**:
연합학습은 직접 데이터를 공유하지 않아도 공유되는 기울기에서 민감 데이터를 복원하는 Gradient Inversion Attack(GIA)에 취약하고, SMC·HE·DP 같은 기존 방어는 프라이버시와 유틸리티 사이의 큰 트레이드오프를 낳는다. HyperFL++는 하이퍼네트워크가 로컬 모델 파라미터를 생성하고 서버는 하이퍼네트워크 파라미터만 집계하게 해 공유 파라미터와 로컬 비공개 데이터의 직접 연결을 끊는다. 하이퍼네트워크의 메모리·통신 오버헤드는 Row-wise Kronecker Decomposition(RKD)으로 줄이며, 이론 분석과 실험으로 높은 모델 유틸리티를 유지하면서 데이터 프라이버시를 보호함을 검증했다.
