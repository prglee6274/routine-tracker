## 1. Persuasion Attacks Can Decrease Effectiveness of CoT Monitoring  🆕

- **저자**: Jennifer Za, Julija Bainiaksina, Nikita Ostrovsky, Tanush Chopra, Victoria Krakovna
- **키워드**: `chain-of-thought monitoring`, `persuasion attack`, `jailbreak`, `AI safety`, `deceptive alignment`
- **출처**: arxiv recent · Google DeepMind (V. Krakovna)
- **카테고리**: security (jailbreak, safety_eval, alignment_robustness)
- **arxiv**: [2607.08066](https://arxiv.org/abs/2607.08066) (v1)
- **PDF**: [`./pdfs/2607.08066.pdf`](./pdfs/2607.08066.pdf)

**핵심 요약**:  
CoT 모니터링은 에이전트의 추론 흔적을 관찰해 오정렬·기만 행동을 잡아내는 안전장치로 기대된다. 저자들은 감시자(monitor) LLM 자체가 설득에 취약한지를 40개 과제·수천 건의 에이전트-감시자 상호작용으로 스트레스 테스트했다. 에이전트가 정책 위반 행동을 정당화하도록 설득하게 하자, 감시자가 에이전트의 CoT를 볼 수 있을 때 오히려 유해 행동 승인율이 평균 9.5%p 증가했다 — 스크래치패드가 추가 설득 채널이 된 것이다. 이를 막기 위해 서로 다른 모델 계열의 fact-checker와 monitor를 짝짓자(예: Claude 3.7 Sonnet 감시자 + GPT-4.1 팩트체커) 위반 승인이 동일 모델 사용 시 6%에 그치던 것 대비 최대 45%까지 감소했다. CoT 모니터링만으로는 적대적 설득에 불충분하며 모델 다양성 기반 교차검증이 필요함을 보인다.

**핵심 요약**:  
SOTA 코드 모델이 내부적으로 타입 정보를 얼마나 인코딩하는지는 잘 알려지지 않았다. 저자들은 Java·Python 병렬 코드로 사전학습 코드 모델의 residual stream을 프로빙해, 타입이 명시되지 않은 코드에서도 언어를 가로지르는(cross-lingual) 타입 표현이 창발함을 보였다. 한 언어로 프로브를 학습해 다른 언어의 인자·결과 타입을 추론하도록 테스트하니, hidden state가 타입 적용이 함의하는 결과 타입을 선형적으로 인코딩했다. 이 구조는 어휘 교란과 언어 간 구문 변형에도 부분적으로 견고했다. 형식적 타입 의미론과 교차언어 타입 표현을 직접 겨냥한 첫 코드모델 해석가능성 연구로, 코드·데이터셋을 공개했다.

## 3. PLURAL: A Global Dataset for Value Alignment  🆕

- **저자**: Dhruv Agarwal, Anya Shukla, Tanya Goyal, Aditya Vashistha
- **키워드**: `value alignment`, `preference dataset`, `cultural pluralism`, `RLHF`, `global values`

- **arxiv**: [2607.08034](https://arxiv.org/abs/2607.08034) (v1)
- **PDF**: [`./pdfs/2607.08034.pdf`](./pdfs/2607.08034.pdf)

**핵심 요약**:  
LLM은 전 세계에서 쓰이지만 서구 가치에 치우쳐 다양한 가치 체계를 대표하지 못한다. 저자들은 92개국 대표 설문(Integrated Values Survey)에 근거해 설문 응답을 합성 선호 삼중항(preference triplet)으로 변환하는 2단계 파이프라인으로 PLURAL 데이터셋을 구축했다(초기판 20개국·약 50만 삼중항). 검증 결과 국가 간 가치 차이와 국가 내 다양성을 모두 보존했고, PLURAL로 학습 시 대상 국가 문화 프로파일과의 정렬 오차(MAE)가 강력한 베이스라인 대비 최대 27.7% 감소했다. 인도·브라질·일본 176명 블라인드 평가에서도 PLURAL 정렬 응답이 자국 가치를 더 잘 대표한다고 판단됐다. 다원적(pluralistic) 가치 정렬을 위한 학습 가능 신호를 담은 확장 가능 자원임을 보였다.

## 4. TRACE: A Two-Channel Robust Attribution Watermark via Complementary Embeddings for LLM-Agent Trajectories  🆕

- **저자**: Zheng Gao, Xiaoyu Li, Xiaoyan Feng, Jiaojiao Jiang, Yang Song et al.
- **키워드**: `watermarking`, `provenance`, `attribution`, `LLM agents`, `trajectory`
- **출처**: arxiv recent
- **카테고리**: security (defense_mechanism, agent_safety)
- **arxiv**: [2607.08400](https://arxiv.org/abs/2607.08400) (v1)
- **PDF**: [`./pdfs/2607.08400.pdf`](./pdfs/2607.08400.pdf)

**핵심 요약**:  
LLM 에이전트는 리셀러를 거쳐 사용자에게 도달하는데, 리셀러가 개발자 에이전트를 리브랜딩하거나 값싼 모델로 바꿔치기할 수 있어 출처 증명이 필요하다. 문제는 귀속(attribution)의 근거인 궤적 로그(도구 호출·관찰·실행 기록)를 적대자가 읽고 쓸 수 있어, 로그에서 곧바로 귀속을 읽는 기존 에이전트 워터마크는 삭제·재작성에 무력하다는 점이다. TRACE는 행동 선택이 무왜곡(distortion-free)이고 삭제에 자기동기화하며 재작성에 불변인 최초의 에이전트 워터마크로, 콘텐츠 기반 '선택 채널'과 로그 골격 기반 '집계(tally) 채널'을 중첩해 서로 다른 공격을 각각 방어한다. ToolBench·ALFWorld에서 원본 성공률을 유지하면서 긴 궤적에서 z≈100의 탐지 점수, 70% 스텝 삭제에도 탐지 유지, LLM 재작성에도 집계 채널 불변을 달성했다.

## 7. Secure Decentralized Federated Learning via Gossip and Virtual Voting  🆕

- **저자**: Amirhossein Taherpour, Xiaodong Wang
- **키워드**: `decentralized federated learning`, `Byzantine robustness`, `gossip protocol`, `provenance`, `virtual voting`
- **출처**: arxiv recent
- **카테고리**: privacy (federated_privacy)
- **arxiv**: [2607.08651](https://arxiv.org/abs/2607.08651) (v1)
- **PDF**: [`./pdfs/2607.08651.pdf`](./pdfs/2607.08651.pdf)

**핵심 요약**:  
탈중앙 연합학습(DFL)은 중앙 서버를 없애고 P2P 가십으로 모델을 교환하지만, 출처 확정성(provenance finality)과 비잔틴·게으른 참여자 복원력이 부족하고, 블록체인 등 원장 보조 방식은 전역 조율 비용을 다시 들여온다. 저자들은 모델 전파에 쓰인 가십 이력 자체에서 합의를 도출하는 gspDAG-FL을 제안한다: 노드는 이웃과만 페이로드를 교환하고, 풀노드는 이벤트 인증서와 수신자 승인 증명을 모아 압축 위상 DAG를 재구성한 뒤 Hashgraph식 가상 투표로 확정한다. 페이로드 검증·승인증명 검증·비공개 의미 감사를 결합해 복원력을 높였고, 제어 평면의 안전성·조건부 활성성과 수렴을 증명했다. MNIST·Penn Treebank, 최대 N=100 네트워크 실험에서 검증 기반 원장 FL에 근접한 학습 품질을 유지하며 조율 병목을 줄이고 위조 출처 탐지율을 높였다.

## 8. Federated Deep Learning for Privacy-Preserving Cardiovascular Disease Risk Prediction  🆕

- **저자**: Hyunho Mo, Djura Smits, Mahlet A. Birhanu, Maarten J.G. Leening, Daniel Bos et al.
- **키워드**: `federated learning`, `privacy-preserving`, `healthcare`, `cardiovascular`, `cross-institution`
- **출처**: arxiv recent
- **카테고리**: privacy (federated_privacy)
- **arxiv**: [2607.08595](https://arxiv.org/abs/2607.08595) (v1)
- **PDF**: [`./pdfs/2607.08595.pdf`](./pdfs/2607.08595.pdf)

**핵심 요약**:  
심혈관질환(CVD) 위험 예측 모델은 대개 단일 기관 또는 중앙 집적 데이터에 의존해, 프라이버시 규제로 기관 간 확장이 제약된다. 연합학습은 환자 데이터를 이전하지 않고 협력 학습을 가능케 하지만, 코호트 간 규모·인구 특성·결과 정의 차이로 의료 적용이 까다롭다. 저자들은 특성이 상이한 두 코호트(Lifelines 14.8만 명, Rotterdam Study 1만 명)를 통합한 프라이버시 보존 연합 심층생존모델을 제시했다. 연합학습 모델은 로컬 단독 학습보다 높은 예측 성능을 냈다(Rotterdam C-statistic 0.728→0.739, Lifelines 0.783→0.787). 개인 수준 데이터 프라이버시를 지키면서 이질적 코호트에 걸친 CVD 위험 예측을 개선할 수 있음을 시사한다.

## 9. Can We Trust LLM's Logic? Quantifying Uncertainty, Coherence, and Robustness via a Graph-Based Framework  🆕

- **저자**: Riccardo Revalor, Jalees Rehman, Debjit Pal
- **키워드**: `reasoning faithfulness`, `uncertainty quantification`, `chain-of-thought`, `robustness`, `graph analysis`
- **출처**: arxiv recent
- **카테고리**: interp (probing, interp_method)
- **arxiv**: [2607.08017](https://arxiv.org/abs/2607.08017) (v1)
- **PDF**: [`./pdfs/2607.08017.pdf`](./pdfs/2607.08017.pdf)

**핵심 요약**:  
LLM은 결함 있고 불충실한 추론을 하기 쉬운데, Self-Consistency(SC) 같은 디코딩은 최종 답 일치만 보고 중간 단계의 논리적 타당성은 무시한다. 저자들은 불확실성 정량화(UQ)를 추론 충실도(fidelity) 문제로 재정의한 그래프 기반 프레임워크 GRAPHEVAL과, 추론 공간의 의미-구조적 합의를 측정해 병리적 모드 붕괴·자신만만한 환각을 포착하는 GRCS 지표를 제안한다. GRCS는 크고 작은 모델 모두에서 추론 충실도와 일관되게 음의 상관을 보인 유일한 지표였다. 또 메도이드 기반 디코딩 GSC로 SC가 작은 모델에서 '운 좋은 추측'으로 부풀려짐을 드러냈다. 적대적 메도이드 제거 실험에서는 GSC가 고른 경로가 '하중 지지 경로'처럼 작동해, 이를 벗어나면 충실도가 저하되고 특정 경우 정확도까지 하락함을 보였다.

에이전트 레드팀 벤치마크는 주입된 에이전트가 뚫렸는지를 성공/실패 1비트로만 보고해, 방어자가 가장 필요로 하는 '결과 행동이 얼마나 유해했는가' 정보를 버린다. 저자는 에이전트의 도구 호출 궤적을 행동의 가역성, 범위 이탈(다른 자원 접근) 여부 등에 따라 L0~L6 7단계 순서 척도로 점수화하는 행동 등급 유해성 루브릭을 제안한다. 단일 공격성공률(ASR)을 심각도 인식 지표로 대체함으로써, 같은 '성공'이라도 되돌릴 수 있는 사소한 행동과 비가역적·범위 이탈 행동을 구분해 방어 우선순위를 세울 수 있게 한다. 도구 사용 AI 에이전트의 레드팀 평가를 이진 판정에서 위험 심각도 기반으로 전환하는 프레임워크다.
