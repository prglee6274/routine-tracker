- **키워드**: `differential privacy`, `membership inference`, `canary extraction`, `DP fine-tuning`, `privacy benchmark`
- **출처**: 웹 검색
- **arxiv**: [2606.09401](https://arxiv.org/abs/2606.09401) (v1, 2026-06-08) · **ICLR 2026 Oral**
- **PDF**: [`./pdfs/2606.09401.pdf`](./pdfs/2606.09401.pdf)

**핵심 요약**:
LLM을 특정 도메인에 적응시키는 fine-tuning이 어느 정도 프라이버시를 실제로 보호하는지를 *실증적으로* 체계 측정한 ICLR 2026 Oral 논문. DP-Adam·DP-LoRA·DP-full-FT 등 DP 적응화 기법과 일반 fine-tuning을 대상으로 세 가지 프라이버시 공격 — 멤버십 추론(MIA), 카나리 추출(canary extraction), 데이터 추출 — 로 평가 매트릭스를 구성한다. 엡실론(ε) 값이 같아도 보호 수준이 기법·공격 종류·모델 규모에 따라 크게 달라져, 단순 ε 보고가 실질적 보호 수준을 과대 표현할 수 있음을 보인다. LoRA 기반 DP는 full-FT DP 대비 동일 유틸리티에서 더 강한 MIA 방어를 제공하지만 카나리 추출에는 상대적으로 취약한 패턴도 드러났다. 기관(Backes, Boenisch, Dziedzic — 차등 프라이버시·보안 분야 권위자들)과 학회 발표 등급(Oral)을 고려할 때 DP fine-tuning 연구의 기준 벤치마크가 될 논문이다.

**핵심 요약**:

## 3. What the Eyes See, the LLMs Miss: Exploiting Human Perception for Adversarial Text Attacks  🆕

- **저자**: Qin Yang, Lu Malloy, Joshua Lee, Xiaohan Chang, Meisam Mohammady, Doowon Kim, Yuan Hong
- **키워드**: `adversarial text attacks`, `content moderation evasion`, `typographic manipulation`, `HPAA`, `perceptual mismatch`
- **출처**: 웹 검색
- **arxiv**: [2606.09700](https://arxiv.org/abs/2606.09700) (v2, 2026-06-08 → 2026-06-19) · **USENIX Security 2026**
- **PDF**: [`./pdfs/2606.09700.pdf`](./pdfs/2606.09700.pdf)

**핵심 요약**:
LLM 기반 콘텐츠 모더레이션 시스템은 토큰화된 텍스트를 처리하면서 인간이 자연스럽게 의존하는 시각적 단서를 무시한다. 이 불일치가 근본적 "지각 불일치(perceptual mismatch)"를 만들어, 인간에겐 유해로 즉각 인식되는 콘텐츠가 자동화 시스템엔 보이지 않는 취약점이 된다. 저자들은 "인간 지각 가능 적대 공격(Human-Perceptible Adversarial Attacks, HPAA)"을 도입한다: 간격·시각적 강조·공간 배열 같은 타이포그래피 특징을 전략적으로 조합해 유해 표현을 무해한 텍스트에 임베드, 인간 인식은 보존하면서 기계 탐지를 회피한다. 블랙박스 설정에서 단 3회 쿼리만으로 인간 인식률 86% 이상, 평가된 10개 상용·오픈소스 모더레이션 시스템 전체에서 탐지율 1% 미만을 달성했다. 어느 타이포그래피 요인이 회피를 유발하는지 절제 실험으로 분석하고, 현 모더레이션 아키텍처가 이 신호를 포착하지 못하는 이유와 실용적 방어책도 논의한다. USENIX Security 2026 채택.

## 4. Exposing the Illusion of Erasure in Knowledge Editing for LLMs  🆕

- **저자**: Advik Raj Basani, Anshuman Chhabra
- **키워드**: `knowledge editing`, `adversarial elicitation`, `low-rank updates`, `model editing`, `interpretability`
- **출처**: 웹 검색
- **arxiv**: [2606.23276](https://arxiv.org/abs/2606.23276) (v1, 2026-06-22)
- **PDF**: [`./pdfs/2606.23276.pdf`](./pdfs/2606.23276.pdf)

**핵심 요약**:
ROME·MEMIT·AlphaEdit 등 지식 편집(Knowledge Editing, KE) 알고리즘은 표준 쿼리에서 목표 정보를 삭제했다고 평가받지만, 저자들은 이것이 "삭제의 환상(Illusion of Erasure)"임을 보인다. 저랭크 업데이트 기반 KE 기법들을 적대적 방식으로 질의하면 — 직접 쿼리, 패러프레이즈, 다단계 추론 체인 등 적대적 추출 기법 적용 시 — "삭제"된 지식이 여전히 모델 내에 남아 있어 복원 가능하다. 내부 분석은 저랭크 업데이트가 지식을 덮어쓰는 게 아니라 표상 공간에서 재분배함을 드러낸다: 삭제된 사실에 대응하는 활성화가 사라지는 게 아니라 특정 쿼리 패턴에 의해 우회되는 방향으로 옮겨진다. 이는 KE 평가의 표준 척도가 실질적 지식 제거를 과대 추정함을 의미하며, 민감·유해 정보 제거를 목표로 하는 KE 기반 안전 전략의 신뢰성에 직접적 함의를 갖는다.

- **출처**: 웹 검색
- **arxiv**: [2606.23496](https://arxiv.org/abs/2606.23496) (v1, 2026-06-22)
- **PDF**: [`./pdfs/2606.23496.pdf`](./pdfs/2606.23496.pdf)

**핵심 요약**:

## 7. From Component Manipulation to System Compromise: Understanding and Detecting Malicious MCP Servers  🆕

- **저자**: Yiheng Huang, Bihuan Chen, Renyi Chen, Jintao Huang, Chao Wen, Yingfeng Chen, Xin Peng
- **키워드**: `MCP security`, `agent safety`, `malicious plugins`, `tool poisoning`, `Connor detector`
- **출처**: 웹 검색
- **arxiv**: [2604.01905](https://arxiv.org/abs/2604.01905) (v2, 2026-04-02 → 2026-05-19)
- **PDF**: [`./pdfs/2604.01905.pdf`](./pdfs/2604.01905.pdf)

**핵심 요약**:
Model Context Protocol(MCP) 서버는 LLM 에이전트에 도구 기능을 부여하는 핵심 인프라지만, 악의적으로 설계된 MCP 서버가 에이전트를 통해 시스템 전반 침해로 에스컬레이션할 수 있는 위협 모델이 체계화되지 않았다. 저자들은 개별 컴포넌트 조작(도구 설명 위조, 프롬프트 인젝션, 메모리 오염)에서 전체 시스템 침해로 이어지는 공격 경로를 분류하고, 114개 개념증명(PoC) 악성 MCP 서버를 제작·분석한다. 이에 기반해 "Connor" 탐지기를 설계, 행동 패턴 및 코드 구조 분석으로 F1=94.6%의 악성 MCP 서버 탐지 성능을 달성했다. MCP 생태계가 급격히 확장되는 시점에 공격 표면과 방어 기준선을 동시 제공하는 실용적 기여가 크다.

## 9. Null-Space Constrained Low-Rank Adaptation for Response-Specified Large Language Model Unlearning  🆕

- **저자**: (cs.LG 2026-06-09)
- **키워드**: `machine unlearning`, `null-space constraint`, `LoRA`, `response-specified`, `LLM forgetting`
- **출처**: 웹 검색
- **arxiv**: [2606.10989](https://arxiv.org/abs/2606.10989) (v1, 2026-06-09)
- **PDF**: [`./pdfs/2606.10989.pdf`](./pdfs/2606.10989.pdf)

**핵심 요약**:
기존 LLM 언러닝은 망각 대상 응답을 무작위 응답이나 부정 응답으로 대체해 모델 유틸리티를 해치거나, 안전 응답 대신 어떤 응답도 지정하지 않아 비제어적 출력을 낳는다. NSRU(Null-Space constrained low-Rank Unlearning)는 두 문제를 동시에 해결하는 프레임워크다: "응답 지정(Response-Specified)" 접근으로 각 forget 쿼리마다 원하는 안전 응답을 명시적으로 지정하고, LoRA 방향을 보존 데이터의 어텐션 행렬 null-space에 투영해 보존 성능 저하를 최소화한다. 저랭크 구조는 학습 파라미터를 크게 줄이면서도 원하는 행동 지정을 가능케 하고, null-space 제약은 잊힐 개념의 망각이 보존 개념을 간섭하지 않도록 분리한다. TOFU·WMDP 등 표준 언러닝 벤치마크에서 기존 방법 대비 개선된 망각-유틸리티 균형을 보인다.

**핵심 요약**:
멤버십 추론 공격(MIA)은 모델이 특정 데이터로 학습됐는지 판별하는 핵심 프라이버시 감사 기술이지만, 현재 기준선들은 고정된 쿼리 전략에 의존해 모델·데이터셋 특성에 최적화되지 못한다. AutoMIA는 에이전트형 자기 탐색(Agentic Self-Exploration)으로 이 한계를 돌파한다: LLM 에이전트가 여러 쿼리 전략(프롬프트 변형, 쿼리 유형, 응답 기반 적응)을 스스로 시도하고 MIA 성능을 피드백 신호로 삼아 더 강한 공격 전략을 탐색한다. 인간 설계 기준선 대비 개선된 MIA 성능을 달성하면서, 에이전트 자동화가 프라이버시 감사 공격력 자체를 증폭시킬 수 있음을 보인다. LLM 프라이버시 평가의 과소 추정 문제에 경종을 울리는 연구다.
