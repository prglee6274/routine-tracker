## 1. PlanFlip: Attacking Multi-Agent LLM Systems via Planning-Phase Prompt Injection  🆕

- **저자**: Yuhang Wang
- **키워드**: `prompt injection`, `multi-agent`, `planning attack`, `defense`
- **출처**: arxiv recent
- **arxiv**: [2607.16199](https://arxiv.org/abs/2607.16199) (v1)
- **PDF**: [`./pdfs/2607.16199.pdf`](./pdfs/2607.16199.pdf)

**핵심 요약**:
멀티에이전트 LLM 시스템은 Planner가 목표를 하위작업으로 쪼개고 Executor·Critic이 실행·감사하는 구조인데, 저자는 이 계획 단계가 한 번의 주입으로 모든 하위작업을 동시에 오염시키는 '캐스케이드 증폭' 공격 표면임을 지적한다. 도구 출력으로 위장해 키워드 필터를 피하는 4종 공격(GoalSubstitution·PriorityInversion·ContextPollution·RoleConfusion)을 제안하고 9개 프런티어 LLM·3,479 에피소드로 평가했다. 능력이 높을수록 더 취약하고(GPT-5 ASR 0.68), 동일 백본으로 구성된 파이프라인은 Critic이 같은 약점을 공유해 계획이 변조돼도 "정렬됨"이라 보고하는 '상관 에이전트 맹점'을 드러냈다. 방어책으로 GoalAnchorCheck·CrossAgentConsensus를 제시하며, 이질적 모델 다양성이 멀티에이전트 보안의 전제조건이고 동일 백본 내 중복은 계획 단계 공격에 무력하다고 결론짓는다.

## 2. Data Leakage Prevention in Agentic Applications via Preemptive Hardening  🆕

- **저자**: Akansha Shukla, Emily Bellov, Parth Atulbhai Gandhi, Yuval Elovici, Asaf Shabtai
- **키워드**: `data leakage`, `agentic systems`, `prompt injection`, `hardening`
- **출처**: arxiv recent
- **arxiv**: [2607.18847](https://arxiv.org/abs/2607.18847) (v1)
- **PDF**: [`./pdfs/2607.18847.pdf`](./pdfs/2607.18847.pdf)

**핵심 요약**:
에이전트 시스템은 LLM 기반 계획과 외부 도구 호출을 결합하면서 명령/데이터 경계 실패와 프롬프트 인젝션을 통해 데이터 유출·도구 오남용에 노출되지만, 여러 코드베이스·이질적 에이전트에 일관된 통제를 거는 일이 어렵다. 저자들(벤구리온대 Elovici·Shabtai 그룹)은 배포 전에 프롬프트 템플릿·도구 인터페이스·호출 코드를 스캔해 유출 유발 패턴을 찾고, 스키마 강화·경계 정화·allowlist 도구 게이팅·최소권한 검사 등 최소 침습 패치를 자동 생성한 뒤 적대적 인젝션과 정상 입력으로 검증하는 파이프라인을 제안한다. 5개 실제 에이전트 앱과 AgentDojo 벤치마크에서 기본 jailbreak·명령 오버라이드 공격에 대해 유출을 100% 제거하고, 스트레스성 조작에서도 91% 감소시키면서 정상 기능은 유지했다. 런타임 정책 강제 없이 사전 하드닝만으로 방어가 가능함을 보인 점이 기여다.

## 5. Stochastic Meta-Unlearning: Bridging Language Backbone and Multimodal Unlearning  🆕

- **저자**: Zijie Liu, Jinhao Duan, Gaowen Liu, Sijia Liu, Tianlong Chen
- **키워드**: `machine unlearning`, `vision-language models`, `multimodal`, `meta-learning`
- **출처**: arxiv recent
- **arxiv**: [2607.18615](https://arxiv.org/abs/2607.18615) (v1)
- **PDF**: [`./pdfs/2607.18615.pdf`](./pdfs/2607.18615.pdf)

**핵심 요약**:
비전-언어 모델(VLM)의 머신 언러닝은 미탐구 영역인데, 언어 백본만으로 잊은 대상도 전체 VLM에 이미지 정보를 주면 다시 복원되는 놀라운 현상이 있어 텍스트 전용 피드백으로는 신뢰할 수 없다. 이 관찰에서 출발해 SMU(Stochastic Meta-Unlearning)라는 이중 수준(bilevel) 프레임워크를 제안한다. 내부 루프에서는 텍스트 데이터로 언어 백본에 몇 스텝 언러닝을 적용하고, 외부 루프에서는 갱신된 백본을 동결된 VLM과 재결합해 VLM 수준에서 망각·유용성을 평가함으로써 '언러닝하기 좋은 초기화'를 학습한다 — 갱신은 언어 백본에 국한하되 최종 멀티모달 행동을 인식하게 만드는 설계다. 2개 VLM·2개 밈 데이터셋에서 최고의 forget-retain 절충을 달성하고(최강 베이스라인 대비 Forget 정확도 10.5p↓, Retain·Test 각각 20.1p·17.0p↑), 새 망각 대상과 다른 언러닝 기법으로도 전이됨을 보인다.

## 6. How Jailbreak Attacks Inform Safety Alignment: A Defender-Centric, Shapley-Based Evaluation  🆕

- **저자**: Yukai Zhou, Feiyang Lu, Xiaokai Mao, Jinfei Liu, Wenjie Wang
- **키워드**: `jailbreak`, `safety alignment`, `Shapley`, `red-teaming`
- **출처**: arxiv recent
- **arxiv**: [2607.17152](https://arxiv.org/abs/2607.17152) (v1)
- **PDF**: [`./pdfs/2607.17152.pdf`](./pdfs/2607.17152.pdf)

**핵심 요약**:
jailbreak 공격은 보통 공격 성공률(ASR) 같은 공격자 중심 지표로 평가되지만, 모델을 뚫는 공격이 곧 안전성 개선에 유용한 것은 아니다. 저자들은 공격을 안전 훈련용 red-teaming 데이터로 썼을 때 얻어지는 하위 안전성 향상으로 평가하는 방어자 중심 관점을 제안한다. 이를 위해 블랙박스 부분집합 유용성 관측으로 개별 공격에 한계 기여를 귀속시키는 Shapley 기반 점수 AttackSHAP와, 예산 제약하에서 최소 유효 공격 부분집합을 고르는 A-MESS 프레임워크를 도입한다. 실험 결과 ASR 순위는 방어자 중심 유용성과 약하게만 일치하고, AttackSHAP는 적은 질의로도 정확히 추정되며, 부분집합을 직접 최적화하면 공격자 중심·귀속만 하는 선택보다 강한 안전 유용성을 얻는다. jailbreak를 '모델을 깨는 도구'가 아니라 '안전성 개선 자원'으로 재평가하자는 제안이다.

## 7. Can We Break LLMs Out of Self-Loops? Fine-Grained Reasoning Control with Activation Steering  🆕

- **저자**: Sheldon Yu, Tong Yu, Xunyi Jiang, Rohan Surana, Gagan Mundada et al.
- **키워드**: `activation steering`, `reasoning control`, `steering vectors`, `latent states`
- **출처**: arxiv recent
- **arxiv**: [2607.18100](https://arxiv.org/abs/2607.18100) (v1)
- **PDF**: [`./pdfs/2607.18100.pdf`](./pdfs/2607.18100.pdf)

**핵심 요약**:
프런티어 LLM의 확장 추론은 표준이 됐지만 생성 궤적이 통제 불가능하고, 기존 프롬프트 기반 방법은 입력 수준에서만 작동해 추론 과정 자체를 세밀히 제어하지 못한다. 저자들은 추론 트레이스를 비정형 텍스트가 아닌 잠재 상태(latent state) 시퀀스로 보고, 실패 궤적이 진전 없이 토큰 예산만 소모하는 self-loop에 빠짐을 통계적으로 규명한다. 제안하는 SOPHIA는 모든 접두를 잠재 상태로 분류하고 단계별 전이를 기록해 상태 쌍으로 인덱싱된 steering vector 뱅크를 만든 뒤, 추론 시 현재 상태를 추정해 목표 상태로 가는 벡터를 검색·주입하고 전이 구조로부터 self-loop를 온라인 탐지·차단한다. self-loop 실패에 안정적으로 개입하고 steering vector가 다른 상태 쌍으로 일반화되며, 세밀한 제어가 최종 정확도와 토큰 효율을 함께 개선함을 보인다.

## 8. Optimal Domain-Aware Privacy Mechanisms for Synthetic Data Generation  🆕

**핵심 요약**:

## 9. Measuring Monosemanticity in Sparse Autoencoders via Latent Activation Coherence  🆕

- **저자**: Katarzyna Filus, Sebastian Pokuciński
- **키워드**: `sparse autoencoder`, `monosemanticity`, `mechanistic interpretability`, `feature quality`
- **출처**: arxiv recent
- **arxiv**: [2607.17770](https://arxiv.org/abs/2607.17770) (v1)
- **PDF**: [`./pdfs/2607.17770.pdf`](./pdfs/2607.17770.pdf)

**핵심 요약**:
기계적 해석성은 SAE로 신경 표현에서 더 해석 가능한 특징을 뽑지만, 그 단의미성(monosemanticity)—곧 설명 품질—을 평가하기가 어렵다. 기존 지표는 외부 개념 레이블이나 사전학습 임베딩 모델에 의존해 인코더 기하학에 민감하다. 저자들은 이진화된 SAE 잠재의 활성화 집합 일관성(activation-set coherence)으로 단의미성을 조작적으로 정의하는, 레이블·외부 임베딩이 필요 없는 Tversky Monosemanticity Score(TMS)를 제안한다. DINOv3·CLIP·BLIP2 특징으로 학습한 SAE와 두 SAE 방식(TopK·BatchTopK)·여러 sparsity·expansion 설정에서 평가한 결과, TMS는 임베딩 기반 대안보다 인코더 비등방성(anisotropy)에 덜 민감하면서 기존 단의미성 지표와 정렬되고, 비등방 조건에서 probe 기반 개념 삭제 효과를 더 잘 예측하며 SAE별 훈련 동역학 차이도 드러낸다.

폐쇄형 LLM을 쓰는 실제 애플리케이션은 기본 콘텐츠 필터를 넘는 안전장치가 필요하다. 독성·편향처럼 정의가 표준화된 필터와 달리, hallucination·주제 이탈·행동 일탈 같은 앱별 guardrail은 정의가 모호하고 사용처마다 달라지며 데이터 부족·주석 비용 탓에 만들기와 시험이 까다롭다. 이 논문은 합성 데이터로 학습한 소형 언어모델(SLM)을 앱별 guardrail로 쓰자는 접근을 제안하고, GAN 설계에서 착안한 새로운 합성 데이터 생성법으로 고품질 샘플을 만들어 SLM에 앱별 guardrail 정보를 인코딩한다. 실험에서 고품질 합성 데이터로 학습한 SLM guardrail이 프롬프트 기반 LLM guardrail보다 성능이 향상됨을 보인다.
