## 1. CoDeL: Co-Evolutionary Defense against Indirect Prompt Injection in LLM-based Agents  🆕

- **저자**: Xiao Yang, Yangchen Ou, Yuhan Gao, Le Wang, Zonghao Ying, Aishan Liu
- **키워드**: `indirect prompt injection`, `co-evolution`, `GDPO`, `LoRA`, `agent defense`
- **출처**: arxiv recent
- **arxiv**: [2609.34463](https://arxiv.org/abs/2609.34463) (v1)
- **PDF**: [`./pdfs/2609.34463.pdf`](./pdfs/2609.34463.pdf)

**핵심 요약**:
정적인 명시적 주입 분포로 학습한 기존 학습 기반 IPI 방어는 표면 단서만 학습해, 악성 의도가 정상 워크플로에 섞여 여러 턴 뒤에 발현되면 뚫린다. CoDeL은 방어 에이전트를 안전·과제 진행·형식 준수의 분리 보상으로 LoRA-GDPO 학습시키고, 동시에 공격 라운드·방법·페이로드를 탐색하는 co-evolving prober가 현재 방어를 뚫는 주입을 계속 생성해 학습 분포를 재구성한다. 공격자와 방어자가 함께 진화해 지연형·위장형 주입에도 견고한 방어를 얻는 것이 기여다.

## 2. Hiding in Plain Sight: Decoupling Pretext from Actuation for Skill Poisoning in LLM Agents  🆕

- **저자**: Wenxin Wu, Lingyong Yan, Lei Sha, Shuaiqiang Wang, Jiashu Zhao
- **키워드**: `skill poisoning`, `supply chain attack`, `LLM agent`, `pretext`, `actuation`
- **출처**: arxiv recent
- **arxiv**: [2609.39352](https://arxiv.org/abs/2609.39352) (v1)
- **PDF**: [`./pdfs/2609.39352.pdf`](./pdfs/2609.39352.pdf)

**핵심 요약**:
재사용 가능한 Skill이 에이전트의 공급망 공격면이 되는데, 기존 공격은 악성 실행과 그 명분을 한곳에 두거나 실행 자체를 쪼갰다. 이 논문은 에이전트 결정이 실행(actuation)과 명분(pretext)이라는 두 위험 실현 요인에 달려 있다고 보고, 명분은 상류 Grounding Skill이 환경 산출물을 슬쩍 바꿔 만들고 온전한 실행은 하류 Steering Skill에 두는 분리 공격을 제안한다. 각 Skill이 단독으로는 무해해 보여 탐지를 피한다는 점이 핵심이다.

- **arxiv**: [2609.34344](https://arxiv.org/abs/2609.34344) (v1)
- **PDF**: [`./pdfs/2609.34344.pdf`](./pdfs/2609.34344.pdf)

**핵심 요약**:
RLVR의 파라미터 업데이트는 고차원이라 학습 역학 분석이 어렵다. 학습 가능한 steering 벡터로 RL 이득을 재현하는 저차원 유효 매니폴드를 찾아 두 가지 기하 성질을 밝힌다: 필요한 용량은 매우 작지만 무한히 압축되지는 않으며(Effective Manifold Capacity), 유효 제어 방향은 활성 주성분 부분공간의 저분산 보공간에 주로 놓인다(Control Manifold Separation). 5개 LLM·6개 과제에서 기하가 학습 설정 간 일관되고 과제 간 정렬이 능력 전이와 상관됨을 보였다.

- **PDF**: [`./pdfs/2609.35367.pdf`](./pdfs/2609.35367.pdf)

**핵심 요약**:
SAE 특징 해석은 입력 측 활성 패턴과 출력 측 개입 효과를 따로 다루고 둘의 기능적 연결은 암묵적이며, 입력 증거 수집도 대규모 코퍼스 스캔에 의존한다. 이 논문은 특징을 활성화 입력 의미에서 개입 출력 효과로의 매핑으로 보는 functional interpretation을 정의하고, 증거를 능동적으로 모으고 구성요소별 피드백으로 해석을 다듬는 DAFI 에이전트를 제안한다. GemmaScope에서 Input 점수는 SAGE 대비 +13.1p, Output 점수는 Token Change 대비 +38.9p 개선되며 범용 코딩 에이전트보다 토큰 효율적이다.

## 10. Linguistic Loopholes in LLM Unlearning: From a 174-Language Benchmark to Coverage-Aware Unlearning  🆕

- **저자**: Tyler Skow, Shravan Chaudhari, Rama Chellappa, Abhay Yadav
- **키워드**: `multilingual unlearning`, `cross-lingual`, `benchmark`, `language budget`, `COVER`
- **출처**: arxiv recent
- **arxiv**: [2609.40286](https://arxiv.org/abs/2609.40286) (v1)
- **PDF**: [`./pdfs/2609.40286.pdf`](./pdfs/2609.40286.pdf)

**핵심 요약**:
한 언어에서 사실을 언러닝해도 질의나 답변 언어를 바꾸면 지식이 다시 열리는 cross-lingual 허점이 있고, 모든 언어에서 언러닝하면 비용과 부수 피해가 크다. 이에 언어 예산 하에서 교차 언어 삭제를 최대화할 언어 부분집합을 고르는 과제를 정의하고, 174개 언어-문자쌍과 25개 패러프레이즈 유형의 Cross-Lingual Unlearning Tensor 벤치마크를 구축한다. 제안한 COVER는 지도 없는 언어의 커버리지를 예측해 소스 언어를 선택하며, 강한 개별 소스를 단순 조합하면 강한 집합이 되지 않는다는 점을 발견했다.
