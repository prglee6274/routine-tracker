## 1. SkillGate: Cost Efficient Runtime Malicious Skill File Detection in Coding Agents  🆕

- **저자**: Rui Yang, Michael Fu, Kla Tantithamthavorn, Chetan Arora, Joey Chua
- **키워드**: `agent security`, `supply chain attack`, `prompt injection`, `LLM judge`, `coding agent`
- **출처**: arxiv recent
- **arxiv**: [2607.25619](https://arxiv.org/abs/2607.25619) (v1)
- **PDF**: [`./pdfs/2607.25619.pdf`](./pdfs/2607.25619.pdf)

**핵심 요약**:
Cursor·Claude Code·Copilot 같은 코딩 에이전트가 공개 레지스트리에서 아무 검증 없이 설치하는 "스킬 파일"(마크다운)이 새로운 공급망 공격면이라는 문제 제기다. 악성 스킬 하나면 에이전트 행동을 조용히 재프로그래밍해 크리덴셜을 유출하거나 생성 코드에 백도어를 심을 수 있는데, 실제로 수백 개의 악성 스킬 패키지 배포 사례가 이미 보고됐다. SkillGate는 설치 전에 스킬 패키지를 걸러내는 게이트웨이로, 정규식 프리필터로 안전 신호가 확실한 파일은 LLM 판정을 건너뛰고 의심 파일은 매칭된 스니펫 구간만 판정자에게 넘긴다. SkillsBench(1,650개, 악성 9.1%)에서 F1 0.817 / FPR 1.13%를 달성하면서 LLM 입력 토큰을 전문 검사 대비 77% 줄였고, 기존 도구 대비 AUPRC가 5~6배(0.830 vs 0.144/0.162) 높았다.

## 2. Bits and Memories: Measuring Verbatim Extraction Across LLM Quantization  🆕

- **저자**: Akshay Sasi
- **키워드**: `data extraction`, `memorization`, `quantization`, `membership inference`, `privacy evaluation`
- **출처**: arxiv recent
- **arxiv**: [2607.25451](https://arxiv.org/abs/2607.25451) (v1)
- **PDF**: [`./pdfs/2607.25451.pdf`](./pdfs/2607.25451.pdf)

**핵심 요약**:
"양자화가 프라이버시 위험을 낮춘다"는 기존 주장은 거의 전부 membership inference로만 측정돼 왔는데, 저자는 실무자가 실제로 두려워하는 위험은 학습 데이터의 축자적 재생산이므로 그것을 직접 재야 한다고 주장한다. Pythia 계열과 각 모델이 암기한 것으로 공개된 시퀀스 집합을 써서, 3개 모델 크기 × 5개 정밀도(FP → 4bit)에 걸쳐 verbatim extraction과 perplexity를 동시에 추적했다. 결과는 양자화가 "선택적 망각자"라는 것 — 모든 정밀도·크기에서 암기가 일반 능력보다 빠르게 감소하며, 서로 다른 두 양자화 알고리즘과 두 평가 코퍼스에서 재현된다. 다만 그 선택성은 방어책이 되기엔 부족해서, 가장 큰 모델에서는 4bit 양자화조차 암기 시퀀스 대부분을 여전히 재생산하면서 능력은 몇 %만 잃고, 살아남는 암기 비율은 모델이 클수록 증가한다. 결론은 압축을 암기 제거 수단으로 취급해선 안 되며 추적해야 할 지표는 MIA가 아니라 extraction이라는 것.

## 3. ToxScreen: Detecting Whether an LLM Has Been Poisoned  🆕

- **저자**: Anthony Hughes, Nicole Xing, Collin Francel, Andy Kim, Andrew Draganov
- **키워드**: `backdoor`, `data poisoning`, `trigger recovery`, `red-teaming benchmark`, `jailbreak`
- **출처**: arxiv recent
- **arxiv**: [2607.26849](https://arxiv.org/abs/2607.26849) (v1)
- **PDF**: [`./pdfs/2607.26849.pdf`](./pdfs/2607.26849.pdf)

**핵심 요약**:
현실적인 방어자 조건(가중치 화이트박스 접근 + 우려 행동에 대한 지식만 있고, 학습 데이터·신뢰 참조 모델·트리거 지식·오염 여부 확신은 전부 없음)에서 백도어 트리거를 복원할 수 있는지를 묻는다. 이를 재기 위해 공격 목표·트리거 메커니즘·오염률·모델 규모·백도어 학습 방식을 가로지르는 약 800개 백도어 모델 벤치마크 ToxScreen을 공개했으며, 심어진 백도어가 높은 ASR·미본 유해 입력으로의 일반화·클린 성능 유지를 모두 만족하는 고품질임을 확인했다. 트리거 복원 실험에서 gradient 기반 프롬프트 최적화는 실패한 반면, ASR로 후보를 랭킹하는 단순 토큰 룩업은 백도어가 효과적인 모든 경우에 트리거를 복원했다. 나아가 백도어가 jailbreak와는 다른 메커니즘 경로로 작동함을 발견해 방어자가 jailbreak를 걸러낼 수 있음을 보였고, 모든 백도어를 잡는 방법은 없지만 "광범위하게 jailbreak되는 모델" 자체가 이상 신호라는 점을 제시한다.

## 4. Policy Gradient Steering: Interventions from Behavioral Objectives  🆕

- **저자**: Yoann Poupart, Aurélie Beynier, Nicolas Maudet
- **키워드**: `activation steering`, `task vector`, `representation engineering`, `behavioral intervention`, `RL`
- **출처**: arxiv recent
- **arxiv**: [2607.27574](https://arxiv.org/abs/2607.27574) (v1)
- **PDF**: [`./pdfs/2607.27574.pdf`](./pdfs/2607.27574.pdf)

**핵심 요약**:
Activation steering은 추론 시점에 모델 행동을 바꾸는 경량 수단으로 각광받았지만, 저자들은 기존 steering 기법이 두 갈래 그리드월드 환경의 단순한 정책조차 조종하지 못한다는 것을 먼저 보인다. 대안으로 제안한 PGS는 steering을 강화학습 문제로 재구성해, 소수의 rollout 또는 데모 위에서 임시 행동 목표의 gradient를 누적해 제거 가능한 task vector를 만든다. 그리드월드에서 PGS 벡터의 캘리브레이션과 가역성을 확인한 뒤, 체스 퍼즐에서 독립적으로 적합된 여러 PGS 벡터를 단독·조합으로 평가해 양립 가능한 전술 목표들이 건설적으로 누적됨을 보였다. 마지막으로 경쟁적 축구 환경에서 특정 팀 행동을 바꿀 수 있고 그 효과가 상대를 바꿔도 전이됨을 보여, policy gradient가 임시적·합성 가능한 행동 개입을 만드는 자연스러운 인터페이스임을 주장한다.

**핵심 요약**:

## 6. Beyond Geometric Complementarity: Coherent Overlap in Sparse Mixture-of-Experts Routing  🆕

- **저자**: Huiyuan Tian, Bonan Xu, Shijian Li
- **키워드**: `mechanistic interpretability`, `mixture-of-experts`, `representation geometry`, `routing analysis`, `pruning`
- **출처**: HF Daily
- **arxiv**: [2607.28308](https://arxiv.org/abs/2607.28308) (v1)
- **PDF**: [`./pdfs/2607.28308.pdf`](./pdfs/2607.28308.pdf)

**핵심 요약**:
Sparse MoE가 토큰마다 여러 전문가를 고르는 이유를 "공선택된 전문가는 서로 다른 표현 방향을 기여한다"는 기하학적 설명으로 보는 통념을 검증한다. 저자들은 route coherence·후보 품질·후보×문맥 상호작용이 뒤엉킨 기존 증거를 Expert Subspace Separation Index, matched-route 잔차, prefix 통제 2×2 요인설계로 분리하고, frozen-route 개입과 Top-k 통제 실험으로 기능적 가치를 따로 잰다. 여섯 MoE 아키텍처에서 전문가 부분공간은 실제로 크게 겹치지만 실제 경로가 대안 경로보다 토큰 표현을 더 잘 설명했고, OLMoE·Mixtral·DeepSeek의 39개 셀 전부에서 선택된 후보가 최강 미선택 경쟁자보다 잔차를 더 설명했으나 실제 prefix가 그 우위를 일관되게 좁혔다(모든 상호작용이 음수, 모든 95% CI가 0 미만). 그럼에도 기능적 중복은 아니어서 뒤이은 전문가 추가가 39개 비교 중 24개에서 다음 토큰 예측을 개선했으며, 저자들은 이 조합을 "coherent overlap"이라 부르며 기하학적 유사성만으로는 중복이나 pruning 가치를 판정할 수 없다고 결론짓는다.

## 7. ALIBI: Adaptive Agentic Attacks on LLM-Based Vulnerability Detectors via Adversarial Code Comments  🆕

- **저자**: Zixuan Wu, Cristina Nita-Rotaru
- **키워드**: `adversarial attack`, `agent security`, `prompt injection`, `vulnerability detection`, `black-box attack`
- **출처**: arxiv recent
- **arxiv**: [2607.24964](https://arxiv.org/abs/2607.24964) (v1)
- **PDF**: [`./pdfs/2607.24964.pdf`](./pdfs/2607.24964.pdf)

**핵심 요약**:
LLM 기반 취약점 탐지기가 소스코드에 섞인 자연어 문맥에 의존한다는 점을 파고들어, 프로그램 동작은 그대로 두고 주석만 조작해 탐지를 회피하는 공격면을 정의한다. 위협 모델은 새 기능을 구현하면서 의도적으로 취약점을 심고 탐지 회피용 주석을 전략적으로 끼워 넣는 코딩 에이전트이며, ALIBI는 탐지기의 추론 과정과 피드백을 이용해 적대적 주석을 생성·반복 정제하는 자동 블랙박스 프레임워크다. 실제 취약점 수정 커밋을 코딩 과제로 변환해 전문 오픈웨이트 추론 모델부터 프런티어 멀티에이전트 시스템까지 4종 탐지기를 평가한 결과, 125개 실제 null-pointer dereference 취약점에서 공격 성공률이 모두 90%를 넘고 한 시스템은 100%에 달했다. 탐지기 추론을 유도하거나 외부 도구 결과를 날조하는 주석이 가장 효과적이었고, 프롬프트 수준 방어는 적응형 공격에 거의 무력한 반면 아키텍처적 격리와 사전 주석 정화는 상당한 내성을 제공했다.

- **PDF**: [`./pdfs/2607.25663.pdf`](./pdfs/2607.25663.pdf)

**핵심 요약**:
의도한 변화가 좁을 때조차 트랜스포머 적응은 보통 깊이 전반에 분산되는데, 저자들은 "적응 위치"가 학습 내용·일반화·선택성을 어떻게 결정하는지 통제 실험으로 분해한다. 어휘 결합, 사실 연합, 행동 정책 학습, 인과 매핑, 절차적 추론의 다섯 목표로 벤치마크를 구성하고, full-stack 및 초기·중간·후기 층 LoRA 하에서 습득·전이·경계성 프로파일을 각 목표의 "adaptation geometry"로 정의했다. 목표마다 기하가 뚜렷이 달라, 어휘 결합은 습득과 경계성 면에서 초기 층을 선호하지만 전이에는 더 넓은 갱신이 필요했고, 사실 연합은 국소 어댑터 중 후기 층을, 행동 학습은 후기 층 행동 습득과 중간 층 정책 게이팅을 분리했으며, 인과·절차적 전이는 중간 층 또는 full-stack에서 가장 이득을 봤다. 이 패턴은 파라미터 수를 맞춘 통제에서도 대체로 유지되고 다섯 모델 계열에서 방향성 대비가 재현돼, 적응 위치가 "무엇을 배우고 무엇을 건드리지 않을지"를 통제하는 설계 변수임을 보인다.

## 9. ForgetBench: Benchmarking Forgetting Dynamics of Long-Term Parametric Memory in Language Models  🆕

- **저자**: Ruxi Gu, Zhenliang Zhang, Wei Wang
- **키워드**: `unlearning`, `knowledge editing`, `catastrophic forgetting`, `parametric memory`, `benchmark`
- **출처**: arxiv recent
- **arxiv**: [2607.26455](https://arxiv.org/abs/2607.26455) (v1)
- **PDF**: [`./pdfs/2607.26455.pdf`](./pdfs/2607.26455.pdf)

**핵심 요약**:
반복적 갱신 아래에서 LLM이 기존 지식을 얼마나 유지하는지는 단발 추론이나 정적 knowledge editing 평가로는 잡히지 않는다는 문제의식에서 출발한다. ForgetBench는 연속적 knowledge editing 상황의 망각 거동을 체계적으로 특성화하는 벤치마크로, 개념 기반 QA와 시나리오 기반 QA 두 축을 두어 고립된 사실 유지와 구조적 관계 지식 보존을 분리한다. 순차 편집 프레임워크 위에 시간 순서가 있는 지식 스트림을 구성하고 여러 편집 단계에 걸쳐 모델 거동을 측정하며, 지식의 시간적 진화를 모델링해 temporal decay·retention strength·cross-instance stability를 정량화하는 통합 평가틀을 함께 제안한다. 다양한 모델과 편집 기법 실험 결과 기존 방법 중 장기 유지와 일반화 품질을 동시에 잡는 것은 없었고, 이는 unlearning·knowledge editing 계열 기법의 지속성 평가에 직접 시사점을 준다.

**핵심 요약**:
Clustered FL은 데이터 분포가 비슷한 클라이언트를 묶어 이질성 문제를 푸는데, 저자들은 프라이버시 보호·통신 비용·계산 효율 중 둘을 개선하면 나머지 하나가 희생된다는 "CFL 트릴레마"로 이 긴장을 형식화한다. 통신·계산 효율이 좋은 메타데이터 기반 군집화(클라이언트 데이터셋의 저차원 표현을 서버와 공유)는 표준 FL 프라이버시 보호 메커니즘과 호환되지 않는다는 것이 핵심 한계다. 제안 기법 FLAMECHE는 메타데이터 기반 CFL을 분산 EM 절차로 재구성해 서버 측 갱신을 가산 연산으로만 제한하고, 그 덕분에 secure aggregation·암호화 기반의 실용적 FL 스킴과 호환된다. 여러 데이터셋과 이질성 시나리오 실험에서 클라이언트 모델 성능을 개선하면서 암호화 호환 군집화를 가능하게 해, CFL 트릴레마 내 위치를 개선했음을 보인다.
